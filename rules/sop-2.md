# SOP 2：节拍 → 英文草稿 → 翻译入正文

内容边界见 `boundaries.md`，文风见 `style.md`，用词见 `wording.md`。另一套流程见 `sop-1.md`。

在已有、已审节拍的前提下使用本套（节拍如何产生与审核，可与 `sop-1.md` 前半段衔接，或由你另行指定）。

## 角色

| 角色 | 由谁 | 职责 |
| --- | --- | --- |
| **Agent A** | **本助手（Grok）** | 根据当前节拍写 **英文** 草稿 |
| **Agent B** | **Gemini** | 将英文草稿译为中文，并写入正文 `chapters/chxx.md` |

按 **SOP 2** 执行时：本助手只做 A，不做 B 的翻译入正文；B 侧由用户交给 Gemini 完成。

**生效范围：** Agent B（Gemini）**仅在 SOP 2 下生效**。走 **SOP 1** 时不启用 Agent B，无「英译中入正文」分工；SOP 1 由本助手按 `sop-1.md` 在节拍审核通过后直接写中文正文。

## 英文草稿规则

- 英文 **永远只写当前**（对应当前已审节拍 / 当前要落的这一笔）  
- 不保留、不累加「全书英文稿」；上一笔已译入正文后，英文侧只服务下一笔当前内容  
- 英文草稿服从节拍范围：节拍没有的，英文不写  

## 翻译与正文

- Agent B 翻译时遵守 `style.md` 与 `wording.md`（中文现代小说、生活气息、用词硬禁与分档）  
- 译文写入当前章节 `chapters/chxx.md`，**正文文件严禁包含任何 YAML frontmatter / 元数据块**，默认不分 SEC，连续推进（与 `sop-1.md` 落盘约定一致）  
- 正文以译入的中文为准；英文不是给读者看的成稿  

## 对话纪律

- 除非你明确要求，对话里不粘贴大段英文草稿或正文；只汇报已完成（例如：Agent A 已写好当前英文；Agent B 已译入 `chxx.md`）
