# SOP 2：节拍 → 英文草稿 → 翻译入正文

内容边界见 `boundaries.md`，文风见 `style.md`，用词见 `wording.md`。另一套流程见 `sop-1.md`。

当用户明确指定采用 **SOP 2** 时使用本套流程。

## 角色分工

| 角色 | 由谁 | 职责 |
| --- | --- | --- |
| **Agent A** | **本助手** | 根据当前提示词/节拍写 **英文** 草稿，并落盘至该故事目录下的 `draft.md` |
| **Agent B** | **Gemini** | 读取 `draft.md`，将英文草稿译为中文，并写入正文 `chapters/chxx.md` |

按 **SOP 2** 执行时：本助手只做 Agent A（产出英文草稿至 `draft.md`），不做 B 的翻译入正文；B 侧由用户交给 Gemini 完成。

**生效范围：** Agent B（Gemini）**仅在 SOP 2 下生效**。走 **SOP 1**（默认）时不启用 Agent B，无「英译中入正文」分工，由本助手按 `sop-1.md` 直接写中文正文。

## 英文草稿与落盘规则

- **统一落盘文件**：Agent A 将生成的英文草稿写入当前故事目录下的 **`draft.md`**（单次覆盖写入）。
- **英文永远只写当前**：只对应当前这一笔/节拍内容。不保留、不累加「全书英文稿」；上一笔已译入正文后，下一次直接覆盖 `draft.md`。
- **英文草稿服从提示词范围**：提示词与节拍没有的，英文不写。

## 翻译与正文

- Agent B 翻译时严格遵守 `style.md` 与 `wording.md`（中文现代小说、生活气息、去形容词化、用词硬禁与分档）。
- 译文写入当前章节 `chapters/chxx.md`，**正文文件严禁包含任何 YAML frontmatter / 元数据块**，默认不分 SEC，连续推进（与 `sop-1.md` 落盘约定一致）。
- 正文以译入的中文为准；英文草稿仅为中间媒介。

## 对话纪律

- 除非你明确要求，对话里不粘贴大段英文草稿或正文；只汇报已完成项（例如：Agent A 已将当前英文草稿写入 `draft.md`；Agent B 已译入 `chxx.md`）。
