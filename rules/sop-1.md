# SOP 1：提示词 → 直接写正文

内容边界见 `boundaries.md`，文风见 `style.md`，用词见 `wording.md`。另一套流程见 `sop-2.md`。

## 流程

1. **你给提示词** — 写到哪，范围就到哪。
2. **助手直接写正文** — 取消单独写节拍审核环节；严格在提示词范围内自由发挥细节与描写，直接写入当前章节 `chapters/chxx.md`。

## 范围对齐与执行边界

- **只做要求做的，不做未要求做的**：
  - 在提示词范围内，可以充分发挥动作、心理、环境与感官细节。
  - **严禁超出提示词范围**：提示词未给到的剧情转折、玩法、新登场人物，正文绝不擅自抢跑或增补。
  - 除非你明确要求，助手不主动生成、更新或推荐 `inspiration.md` 或 `beats.md`。

## 正文落盘与小节格式

- **严禁 YAML**：正文文件（`chapters/chxx.md`）**禁止包含任何 YAML frontmatter / 元数据块**，直接从正文（或小节标记）起笔。
- **默认不分 SEC**：写作时在当前章节文件 `chapters/chxx.md` 里 **连续推进** 正文。
- **若要求切分 SEC**：按 `rules/style.md` 规范，小节标识统一采用居中、Serif 衬线体、字号大于正文的纯数字格式（`<p align="center" style="font-family: serif; font-size: 1.4em;">1</p>`），不展示中文小节名。
- 一章写满或你明确要求再开下一章文件（`ch01.md` → `ch02.md` …）。

## 对话纪律

- **除非你明确要求**，对话里 **永远不要粘贴正文原文**。
- 只汇报已完成的动作（例如：已按提示词写入 `chapters/chxx.md`）。
- 请你直接打开对应章节文件查看。

## Git 纪律

- **默认不 commit**：正文落盘及日常文件修改后，助手禁止自行执行 `git commit`。
- 只有在你明确下达提交要求（如「提交修改」、「commit」）时，才执行 git 提交。

## 字数统计

- 仓库在 `scripts/count-chars.ps1` 维护汉字字数统计脚本。
- **当且仅当你明确要求统计字数时**，助手运行此脚本统计指定章节或目录的汉字字数并汇报；平时不主动执行或贴出字数统计。
