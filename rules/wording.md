# 用词

只管 **用哪个词**。内容边界见 `boundaries.md`；文风见 `style.md`；剧情走向与节奏见该故事的 `beats.md`；组句见句式（若尚未放入则暂缺）。

硬禁固定。**未列入硬禁的词视为可写**（脏度仍按上下文自判）。温存、商量、事后可以直白但不脏；操得狠、羞辱场用更脏的那档。脏度按场景选档。

故事级只能加禁，不能把下面禁用词放回来。

## 硬禁（不看上下文，出现就改）

阴茎、阳具、假阳具、柱身、阴阜、花心、爱液、肉褶、硅胶棒、骚水、后穴、卵蛋、甬道、白沫。

**贱：** 不要「贱」，也不要任何「贱x / x贱」（下贱、贱货、贱逼、贱人等）。

**羞辱称呼硬禁：** 浪货、浪逼、荡妇、淫妇、淫货、精壶、肉套子、精马桶、母猪、婊子、破鞋、公用、洞、操穴。不要单独写「婊子」。

**羞辱称呼可写：** 骚逼、骚货、母狗、马桶、反差、反差婊（「反差婊」必须整词，不能拆成婊子）、骚穴、欠操、肉便器、精盆、飞机杯、套子、鸡巴套子。

**臀：** 不要「臀」，也不要任何「臀x / x臀」（臀部、臀瓣、臀肉、臀缝、丰臀、拍臀等）。屁股可以。

**精液与白浆：** 男用液体只写 **精液**（不要白浊、浓白、精当名词；动作仍写射、射进去、内射）。抽插泛起的分泌物/摩擦泡沫用 **白浆**（或水 / 淫水），硬禁 **白沫**。

假的那根 **只写假鸡巴**，不准写成别的。

也不要：玉茎、肉刃、蜜穴、花径、春水（粉词）。

**部位 / 状态 / 动作代称硬禁（增补）：** 逼口、交合处、逼肉、水液、软肉、泥泞不堪、内里、硬物、死死。  
女用阴道或逼（后庭用屁眼 / 肛门）；男用鸡巴等可写表内词；湿用湿、水或淫水（按脏度）。  
**禁止一切代指与过度套路修饰：** 不要用「硬物」或任何笼统物称 / 模糊说法代替具体部位与器具；严禁「死死」这类套路副词，改用具体动作描写。该写鸡巴就写鸡巴，该写假鸡巴就写假鸡巴，该写振动棒就写振动棒。


**叙述夸张（词）：** 灭顶、欲仙欲死、灵魂出窍、升天、濒死、如遭雷击、电流窜遍全身、白光炸开、世界崩塌、狂暴、炸裂、浪潮、酥麻、几乎昏过去。

**极致、崩溃：** 仅当这场露骨场面里人物确实到了极限（连续高潮、撑不住、意识发飘那种）才能用，一场景最多点一下。没到这个程度不准出现，不准拿来给普通抽插加油。

## 非露骨叙述（已全部接受）

文风与生活气息见 `style.md`。部位和脏话以外的这些词 **都可以写**。怎么排布见句式（若尚未放入则暂缺），不要砌成套话墙。

**程度：** 微微 · 轻轻 · 不禁 · 忍不住 · 几乎 · 仿佛 · 宛如 · 竟是 · 更加 · 愈发 · 深深

**情绪：** 心头一颤 · 心口发紧 · 小鹿乱撞 · 眼眶发热 · 鼻尖发酸 · 没来由 · 说不清

**眼神 / 脸：** 眸 · 眼波 · 水光 · 薄红 · 飞红 · 耳根发烫 · 神色一暗 · 目光幽深

**呼吸 / 声音：** 气息不稳 · 嗓音沙哑 · 低喘 · 轻哼 · 溢出 · 逸出 · 破碎

**身体（非生殖器）：** 腰肢 · 纤细 · 修长 · 柔软 · 温热 · 滚烫 · 发软 · 发颤 · 绷紧

**气氛：** 暧昧 · 情欲 · 余韵 · 寂静被打破 · 空气仿佛凝固 · 时间变慢

**动作：** 不由自主 · 下意识 · 猛地 · 骤然 · 一把 · 狠狠

高潮夸张词仍按上文：灭顶等禁用；极致、崩溃仅极限场面。

## 可写（直白，脏度自判）

| | 偏叙述 / 没那么脏 | 黄网高频更脏 |
| --- | --- | --- |
| 男 | 鸡巴、龟头、阴囊、蛋、蛋蛋 | 鸡巴 |
| 女 | **阴道**、阴蒂、子宫、宫口 | 逼 |
| 湿 | 湿、水 | 淫水 |
| 胸 | 奶、奶子 | 奶子 |
| 屁股 | 屁股 | 屁股 |
| 后 | 屁眼、肛门 | 屁眼 |
| 动作 | 插、含、舔、射 | 操、干 |
| 液体 | 精液 | 精液 |
| 道具 | 假鸡巴、振动棒 | 假鸡巴 |

**阴道可写。** 温存或写清楚时用阴道；狠场、羞辱用逼。由助手按场景选。

肉棒、穴：可用，但不要拿它们躲硬禁。优先鸡巴 / 阴道或逼。

羞辱称呼的可写/已禁见上文硬禁与可写两条。其余未点名禁止的词一律可写。

## 自检（0-Token 本地脚本与静默约束）

- **静默自检**：助手落笔时内置避开，**严禁在对话中输出自检过程或审查清单**，不增加额外 Token。
- **本地扫描脚本**：仓库在 `scripts/check-wording.ps1` 维护 0-Token 静态扫描脚本，当且仅当用户明确要求时运行。
- **硬禁正则**：`阴茎|阳具|假阳具|柱身|阴阜|花心|爱液|肉褶|硅胶棒|骚水|后穴|卵蛋|白浊|白沫|臀|贱|浪货|浪逼|荡妇|淫妇|淫货|精壶|肉套子|精马桶|母猪|破鞋|公用|操穴|甬道|逼口|交合处|逼肉|水液|软肉|泥泞不堪|内里|硬物|死死|灭顶|欲仙欲死|灵魂出窍|升天|濒死|如遭雷击|电流窜遍全身|白光炸开|世界崩塌|几乎昏过去|狂暴|炸裂|浪潮|酥麻`。单独「婊子」不要（反差婊整词除外）。假的那根除「假鸡巴」以外都改。男用液体除「精液」以外的叫法都改；摩擦分泌物用「白浆」。禁止「硬物」及一切代指部位/器具的笼统物称。「极致」「崩溃」仅极限场面可用。
