- **Beat 1：进门与客厅安顿**
  叙事功能：建立别墅客厅的空间质感与阶层反差，交代两人久别后同处一室的初始状态——她松弛不设防，"我"带着对陌生空间的轻微局促。
  心理动机："我"被她妈叫来歇脚，进门后对这个不属于自己的大房子有点不自在；冯曦大大咧咧地招待，把"我"当自己人，不觉得有什么需要客气的。
  张力走向：陌生空间的局促 vs 她的自然松弛；两年没见的生疏感被她的热络压下去，但还没完全消。
  动线节奏：门铃/敲门 → 她来开门（居家打扮，没化妆）→ 进门换鞋 → 她带我到客厅 → 倒水/拿水果/开空调 → 两人坐下，有一搭没一搭说话。
  细节落点：客厅的样子（挑高、落地窗、遮光帘、空调温度、家具质感）；她的穿着（背心短裤/睡裙、头发夹着、趿拖鞋）；"我"坐下时的小动作（选哪个位置、手放哪、背挺不挺）；她招待时的语气和动作（把水果往"我"面前推、遥控器丢过来）。

- **Beat 2：她上楼换泳衣——客厅里的短暂独处**
  叙事功能：制造一个她不在场的空档，让"我"一个人在客厅打量这个空间，同时为她换泳衣下楼做铺垫。
  心理动机：她突然说要去游泳，上楼换衣服；"我"一个人待着，有点无所适从，开始不自觉地观察周围。
  张力走向：她离开后的安静 vs 刚才的热络；"我"对这个空间的好奇与局促并存。
  动线节奏：她说"我上去换个衣服" → 上楼 → 脚步声远去 → "我"一个人在客厅 → 目光扫过四周（照片、摆件、窗外）→ 听见楼上的动静。
  细节落点：楼梯的样子（木质/大理石、扶手）；她上楼的背影；客厅里能看到的细节（全家福？她小时候的照片？摆件）；空调风声、外面的蝉鸣；"我"拿起水杯又放下、换了个坐姿。

- **Beat 3：她下楼——游泳邀请与推辞**
  叙事功能：本节核心对话。她换了泳衣下来，自然地邀请"我"一起游泳；"我"以没带泳裤推辞，她提出借她爸的，"我"还是算了。
  心理动机：她穿泳衣在自己家走来走去毫不介意，对"我"完全不设防；"我"被她的随意弄得有点不自在，推辞时带着客气和一点慌乱。
  张力走向：她的毫无芥蒂 vs "我"的视线无处安放；邀请—推辞—再邀请—再推辞的小拉锯。
  动线节奏：下楼脚步声 → 她出现在楼梯口/走到客厅 → 说要去游泳 → 问"我"要不要一起 → "我"说没带泳裤 → 她随口说"我爸的借你啊" → "我"笑着推辞"算了算了" → 她也不勉强，转身去泳池。
  细节落点：泳衣的款式颜色（点到为止）；她走下来时的状态（擦头发？披毛巾？）；"我"看到她时的第一反应（眼神往哪放、有没有立刻移开）；对话的语气（她大大咧咧、"我"带点笑的推辞）；她转身离开时的背影。

- **Beat 4：她去游泳——客厅里隐隐约约的注意**
  叙事功能：她离开后，"我"在客厅的注意力被泳池那边吸引，建立"想看又不该看"的微妙张力，为后续铺垫。
  心理动机：她去游泳了，"我"一个人待着，忍不住注意泳池方向；但又觉得盯着看不礼貌，假装在做别的事。
  张力走向：视线的拉扯——余光/落地窗里的身影 vs 刻意移开的目光；安静客厅里只有水声和蝉鸣。
  动线节奏：她走向泳池 → 入水的水声 → "我"在客厅坐着（玩手机/看电视/发呆）→ 余光或透过落地窗瞥见她游泳的身影 → 忍不住多看一眼 → 又收回目光 → 反复。
  细节落点：泳池与客厅的位置关系（落地窗能不能直接看到？还是隔着玻璃/帘子？）；水声（划水、换气、脚拍水面）；她游泳的动作；"我"假装在做的事（刷手机但没看进去、电视频道换了又换）；空调风、蝉鸣、下午的光线变化；"我"的心跳或呼吸有没有变化。

**接续点**：她游完泳回来 / 她在泳池里喊"我" / 长辈们买菜回来打断。
