# 438 办公室

## 背景与舞台
- **地点**：大学物理学院 438 研究生办公室。
- **时间**：9 月初秋开学返校季。
- **空间布局**：「我」刚升入研二，分到了 438 的正式新工位；师姐王荩的工位在「我」的斜右后方。一转椅或侧头便能视线相对，存在 26cm 身高差带来的体型对比。

## 人物设定

### 我
- **年龄 / 身份**：22 岁，物理学院研究生二年级（研二师弟）。
- **外貌 / 身材**：身高 181cm。
- **性格特质**：大方、幽默，心思细腻，善于观察身边的微小细节与情绪变化。

### 王荩
- **年龄 / 身份**：23 岁，物理学院研究生三年级（研三师姐）。
- **外貌 / 身材**：身高 155cm，戴眼镜，普通女生长相，娇小身材。
- **性格特质**：大方、幽默，相处自然没架子，在 438 已经坐了一年多。

## 两人关系
- 课题组师姐弟，平时关系融洽，性格投契，彼此非常聊得来。
- **称呼习惯**：「我」对王荩日常直接称呼「师姐」（不加姓氏），亲切自然。
