# 《总谱》剧情节拍

> **适用范围：新世界线第一学期，2021 年 9 月开篇至 2022 年 1 月期末大课设验收。** 本文件是剧情规划，不是已写正文；未讨论的细节保留空间。第一章已按节拍 01—02 写成初稿；后续节拍仍是规划，不得从旧稿继承具体事件。行业型号与发布日期以 `lore.md` 为准。

## 一、叙事起点与课程安排

- **时间与人物**：2021 年 9 月，孙博作为海洋工程类新生进入西安未央大学，后续培养方向为水声工程。他喜欢游戏和折腾电脑，善用大众 AI 与互联网搜索，却从未真正独立写过程序。
- **AI 认知**：孙博经常使用国产与海外网页端 AI，知道 EpochAI、Epistemic、Aleph 三家国际前沿厂商（可作为普通用户口中的“御三家”），能凭实际体验挑选聊天工具；了解 VS Code、听说过 AI IDE，但没用过专业编程 Agent，不知道 Harness 概念。
- **同龄人分布**：许多普通新生用网页聊天生成代码再复制粘贴，少数人已接触 AI IDE，极少数技术爱好者实际使用 CLI Agent。专业开发者圈中成熟 Harness 已是实用工具；行业成熟不等于大一学生普遍会用。
- **课程结构**：C 语言程序设计采用平时 OJ 在线评测作业、**11 月个人中期小课设**以及后续期末大课设。期末由教师提供不同的适龄 C 语言选题，孙博选择个人完成的**迷宫探索游戏**；具体课程细则与确切验收日期仍待定。

## 二、剧情节拍（2021 年 9—11 月）

### 01｜9 月：OJ 平时作业与第一次真正编程

孙博认识 VS Code，但此前没有真正写过程序。老师开始布置 C 语言 OJ 作业，他按自己熟悉的方法在 **EpochChat** 或 **Norbert 官方网页聊天端**询问题目，复制代码到本地编辑器，尝试编译运行，再向 OJ 提交；若编译或评测失败，便把错误与题意贴回网页修改。

起初任务规模小，这种方法足够实用。叙述重点是新手实际操作、理解题目与基本运行环境，不渲染模型能写出基础 C 语言代码是惊天突破，也不强行让他提前使用 Harness。OJ 的具体首题尚未确定。

### 02｜10 月：形成网页端编程的惯常工作方式

随着 OJ 作业继续，孙博逐渐熟悉编辑、运行、提交和依据 OJ 反馈修改代码。他已知道不同聊天模型在解释、代码质量、速度或使用成本上的体验不同，会按需求选择，但依旧谈不上理解大型工程与模型技术架构。

这段以少量有代表性的场景带过，不逐题流水账，也不预先指定某次模型失误或课程排名。此时没有足够复杂的个人项目推动他改用专业开发 Agent。

### 03｜11 月：个人中期小课设发布

教师布置**学生成绩管理系统**，由每位学生独立完成。它是大一 C 语言控制台程序，基本功能包括学生信息和成绩录入、显示、学号查询、平均分计算、按成绩排序及循环菜单；提交源代码、简短说明和演示材料，接受现场测试。具体评分细则与课堂所授内容不提前写死。

孙博起先利用 EpochChat / Norbert 网页端较快完成基础版本，又想完善修改删除、文件保存读取与必要的输入检查。项目开始涉及不同函数、多个文件与反复编译修改，手工维护越来越吃力。这些扩展功能可以借 AI 学习实现，但不写成课堂此前已经完整讲授所有知识点。

### 04｜网页聊天的瓶颈来自项目上下文

不同聊天窗口看到的代码片段与本地实际文件版本逐渐脱节。某次跨文件修改出现函数声明、参数或调用不一致的编译问题；孙博需要反复复制头文件、源文件和错误消息才能说清当前状态。

这里的核心冲突是**上下文传递和实际项目状态难以同步**，不是前沿模型突然连简单 C 语言都不会写。具体函数名称、编译器报错文本和代码片段留待写正文时按技术正确性设计。

### 05｜主动寻找更方便的工具

孙博搜索能否让 AI 直接读取、修改本地代码并运行测试，先了解到 AI IDE，再看到开发者社区对 **Kybernetes** 与 **Encoder** 等终端编程 Agent 的推荐。技术社区中的 Harness 推荐声量较高，不代表 AI IDE 没有 Harness；二者可在交互入口与执行工作流上存在不同体验。

孙博现阶段只认识到“工具能直接操作当前项目，不用反复复制文件”，不突然领悟模型与 Harness 的全部工程分层，也不把社区宣传当作必然真实的性能排名。

### 06｜首次使用 Kybernetes

孙博在小课设的本地目录中尝试 **Kybernetes**。首次实用任务可围绕定位并修复跨文件接口不一致：Agent 读取相关文件、修改调用或声明、运行编译并反馈结果。孙博在 VS Code 里看到**当前项目文件已直接改变**，直观体会到与网页复制粘贴不同的工作方式。

这是一件在成熟 Harness 能力范围内的普通工程操作，不必设计离奇高难故障或夸大自主性。孙博仍需运行、检查结果，不能把编译通过直接等同于需求全部正确。

### 07｜免费额度压力与 Encoder

孙博继续用 Kybernetes 修改或检查功能，很快受到**官方免费额度有限**的限制。他查看订阅，发现约 **20 美元/月** 的付费门槛；对依靠生活费的大一新生，这笔钱值得犹豫，于是暂不升级。

他随后转向 **Encoder**，使用该工具提供的**另一份有限免费额度**继续完善课设。这不是账户无限切换，也不意味着两家的额度互通。两家额度先后趋紧后，他继续依靠 **EpochChat 与 Norbert 网页端**处理简单问题，把有限的 Agent 调用留给最需要直接访问项目的跨文件修改、编译与检查。

**既定交付路径：Kybernetes 免费额度 + Encoder 免费额度 + EpochChat 网页端 + Norbert 网页端，再加本人操作和测试；不借助 Aleph/Atlas API Studio 的免费额度完成本次小课设。** Aleph 是开篇就已知道的“御三家”之一，并非此处才首次发现。$20 是剧情中的大致订阅档位价格，暂不进一步指定复杂计费规则。

### 08｜11 月末：独立交付与约 93 分的正反馈

孙博在额度有限、手动操作仍多的情况下完成学生成绩管理系统：基础功能可用，并有合理的扩展、测试与演示准备。现场验收时程序主要功能运行顺利，能够应对教师的常见检查；他能说明自己理解的基本结构和检验过程，但不必冒充完全掌握全部实现细节。

**最终成绩约 93 分，属于优秀，明确给孙博带来开心与成就感。** 高分来自实际交付的正确性、完整度和演示表现，不是教师因为他使用 AI 而额外奖励；不写成全班震惊、突然获导师赏识，也不必机械植入重大失败。他因此对利用 AI 完成软件项目更有兴趣，同时记住了额度与工作流的现实约束。

## 三、创作约束与尚未锁定事项

- **11 月后已规划至 2022 年 1 月的期末验收**。不预设第二学期经历。
- 叙事以**网页聊天 → 真实项目中的复制粘贴瓶颈 → 初次 Kybernetes → Encoder 补充额度 → 混合工作流交付 → 优秀成绩**为主线，压缩无关校园日常和 OJ 题目流水账。
- 孙博的领先不是天才式能力，其他学生也在使用 AI；他从熟悉的网页端方法出发，因现实需求才探索 Agent。不能提前熟悉 Harness 底层原理。
- `lore.md` 的发布日期要尊重：GRM-4 在 8 月下旬；GRM-4-Byte 与 Encoder 在 9 月上旬；Kybernetes 在 8 月；Norbert-Delta: Treatise 在 9 月，Dialogue/Aphorism 在 10 月。故事中选择型号须符合对应日期，不默认 9 月初已能用 10 月发布的型号。
- 小说第三人称行业 Interlude 与孙博第一人称认知独立；不为介绍每个产品强行安排人物体验。
- **未锁定**：首次 OJ 题目、学生成绩管理系统精确文件数量与接口、教师详细评分表、确切验收日与最终个位分数、订阅的精确定价及计费机制。


## 四、期末大课设剧情节拍（2021 年 12 月—2022 年 1 月）

> 已确认的剧情方向；具体日期、工程实现和教师姓名未定。行业型号及开放状态以 `lore.md` 为准。2021 年 12 月**没有** Epsilon 正式发布。

### 09｜12 月：开放选题，选中迷宫游戏

计算机学院任课教师为海洋工程类新生开设《C语言程序设计》，提供多个适合大一 C 语言能力的期末课设题目。孙博个人选定**迷宫探索游戏**。课程必做范围仍是二维数组表示迷宫、基本输入与移动、墙壁碰撞、终点判定、菜单及适当的函数拆分；具体选题表、评分标准和截止日待定。GUI 不是教师要求，也不是额外评分的必做项。

孙博利用网页聊天和有限的免费 Agent 先做出能玩的控制台版本，陆续加入多关卡、钥匙锁门、存档读取与步数统计。扩展出于游戏兴趣，而非追求高级软件工程结构。

### 10｜2022 年 1 月：Epsilon 上线，第一次购买会员

Epistemic 在 **2022 年 1 月**推出 **Norbert-Epsilon: Treatise**（现实能力参照 Claude Opus 4.6；具体日待定），付费优先接入 Norbert 网页端、API 和 Kybernetes。孙博此前从社区了解到新模型，既想试试顶级 AI，又觉得课设逐渐复杂、免费工具反复切换麻烦，于是**项目进行一段时间后咬咬牙购买约 20 美元的首月 Epistemic 会员**。

会员同时提供 Norbert 网页端和 Kybernetes 使用权益，两者有各自的用量限制。孙博不是熟练的 Harness 用户，不掌握系统的任务分解、上下文管理与工程验收方法；他只是发现 Agent 能直接改文件、执行构建，用起来省事。新模型与付费额度让体验明显更顺畅，但不应让旧旗舰在简单 C 语言任务上无故失效。

### 11｜模糊审美要求引出 GUI，超额完成

孙博试玩字符地图后随口提出“能不能弄得好看一点”一类要求。Kybernetes 提出图形界面方案，他觉得不错便同意，未意识到引入 GUI 的工程工作量。Agent 在 Epsilon 的协助下完成技术选型、图形窗口、地图渲染、输入与界面组织，并可能因需求模糊而作出一些超出课程所需的设计。**使用 C 语言可调用的图形库**，不偷偷换为其他主语言；具体库、依赖及平台待技术校验后确定。

成品是一款质量明显高于普通控制台课设的**完整 GUI 迷宫小游戏**，保留已确认的多关卡、钥匙锁门、存档与步数统计，并具备连贯的界面操作和运行体验。孙博的需求和试玩反馈参与塑形，但大量 GUI 代码和工程结构由 Agent 实现。他对功能和课堂范围内的二维数组、判断逻辑有基本理解，对渲染循环、图形库接口、构建与模块细节理解浅，交付能力明显超过独立编码知识水平。不要把全部扩展写成孙博事先设计好的工程蓝图。

### 12｜1 月验收：教师看出端倪，却保留分寸

期末验收安排在 **Epsilon 发布及项目图形化完成之后的 2022 年 1 月**，确切日期待定。孙博演示独立 GUI 游戏窗口、关卡、钥匙、存档恢复等功能，完成度在班级作品中非常突出，**GUI 是其区别于同班其他作品的直观亮点**，可呈现为班上唯一采用 GUI 的作品，不因此虚构全班震惊或将技术难度神化。

授课教师是一位**计算机学院的年轻教师兼科研工作者**。授课与职业考核、职称发展有关，但他有教学热情，也是较早拥抱 Vibe Coding、AI Agent/Harness 的实践者。老师请孙博打开源码，注意到代码组织、风格、图形库使用及其与学生经验之间的落差，**怀疑有成熟 Agent 深度参与**；代码风格只是线索，不能断言识别出具体的 Kybernetes。老师不在公开验收中点破，也不当众逼他解释不属课程要求的 GUI 底层实现；仍可检查课程基础知识和实际运行效果。

老师问为何连非必做功能也做得如此完整，孙博有意只称**用网页端 AI 对话，结合课堂所学，自己慢慢搭建**；他不愿分享更有效率的 Agent 使用方式，潜意识中想保留自己的优势，也确实讲不清 GUI 的许多实现。这个回答淡化了真正的开发路径，叙事不替他粉饰。老师听后心里有判断，孙博以为自己已经应付过去。

期末取得**约 97—98 分**，并成为课程优秀课设案例之一；靠功能、稳定性与演示质量获得评价。教师因作品产生兴趣，提出**课下单独聊聊**，想了解孙博是否有兴趣探索更深的软件开发或研究问题。先搭建师生联系，不直接安排加入课题组、被教授赏识或后续研究成就。教师的姓名、具体研究方向、谈话结果及优秀案例的展示形式待定。

### 13｜从作品交付到发现 AI 能力富余

孙博在付费 Epsilon、连续使用 Kybernetes 的过程中逐渐发现：AI 所能处理的工程问题，远超自己手头大一 C 语言课设的难度。他不需要先掌握某项技术的全部知识，就能让 Agent 帮助尝试，进而产生更多主动提问、测试想法的冲动。这个认识以 GUI 成品及随后实际探索为起点，**不在验收当天突然获得完整理论洞见**；长期能力差距由后续多个兴趣驱动的故事逐步证明。

## 五、后续连续性与待定事项

- **时间顺序**：12 月开始期末项目；Epsilon 于 **2022 年 1 月**发布；付费、GUI 扩展和验收发生在发布之后；**寒假 Minecraft 开源贡献发生在课设结束之后**。
- 教师姓名、准确年龄职称、科研方向、私下交流的具体展开与未来关系结果待定；此处只锁定性格、现场克制判断和关系线。
- GUI 的具体框架、可运行平台、构建及验收方式待技术设计；写作时遵守 C 语言课程的合理范围。
- 最终分数在 97—98 之间、具体验收日期未定；教师对 Agent 的判断是推测而不是有证据的 AI 代码鉴定。
- Minecraft 开源贡献及 AGI/RSI 长期方向另见 `docs/future-arcs.md`；只锁定已讨论的故事链条，不提前写入第一学期正文。
