## 二、各章细化摘要（Agent 按需速查）

### 第一章（ch01.md · 2,564 汉字）
- **场景与地点**：未央校区六号楼宿舍三层西侧、阶梯教室大机房；
- **核心出场要素**：黑色磨砂拯救者笔记本、VS Code、GCC 编译器、学院自建内网 OJ 系统、EpochChat（GRM-4）、Norbert 网页端（Delta 系列）；
- **代表性事件**：
  1. 第一道温度转换题遭遇 `Presentation Error`，由 Norbert 网页端协助排查出行末多余空格；
  2. 10 月数组与字符串题进阶，对比出 EpochChat 的速度优势与 Norbert 的细致边界提示；
  3. 身边普通同学普遍开着 AI 网页对话框写代码，孙博保持手测与对账习惯。
- **章末节点**：10 月底平时 OJ 满分通过，11 月初专业课老师切出中期小课设任务书。

### 第二章（ch02.md · 4,088 汉字）
- **场景与地点**：宿舍书桌、大阶梯教室、专业机房；
- **核心出场要素**：学生成绩管理系统任务书、多文件结构（`main.c`, `student.c`, `student.h`）、CLI Agent **Kybernetes**（Epistemic 旗下）、CLI Agent **Encoder**（EpochAI 旗下，搭载 GRM-4-Byte）、约 $20/月订阅门槛；
- **代表性事件**：
  1. 单文件扩充至 400 行后拆分多文件，遭遇 `conflicting types`、`undefined reference` 严重接口脱节，网页端手动搬运上下文彻底失效；
  2. 社区检索发现 CLI Agent，本地配置 Kybernetes，首次体验到 Agent 自主读取三文件、修复签名并自动编译通过的闭环；
  3. Kybernetes 免费额度见底，看 $20 订阅犹豫不决，切到 Encoder 使用另一份免费额度；
  4. 总结出实战工作流：网页端问简单疑难，终端 Agent 留给跨文件对齐与编译；
  5. 现场测试承受住老师的 120 / -5 越界输入刁难及存盘重启测试，获评 93 分。

### 第三章（ch03.md · 6,564 汉字）
- **场景与地点**：十二月供暖宿舍、一月考试周期末机房、计算机学院教师办公室、校门外车站；
- **核心出场要素**：迷宫探索游戏任务书、多关卡与钥匙铁门状态、**Norbert-Epsilon: Treatise**（2022 年 1 月上线旗舰）、Epistemic Fellow 付费会员、**Raylib** 纯 C 轻量图形库、独立 800x600 GUI 窗口、抓绒冲锋衣年轻任课教师、大创与萌创；
- **代表性事件**：
  1. 控制台迷宫跑通后，孙博出于玩家心态主动扩展多关卡、钥匙锁门与存档读取；
  2. 2022 年 1 月 Epsilon 上线，长链条调试能力与 Agent 可靠性大幅跃升，孙博咬牙自费订阅首月会员；
  3. 随口提出“黑框简陋能不能弄得好看点”，Kybernetes 自动选型 Raylib 并构建出完整抗锯齿图形游戏窗口；
  4. 现场答辩引来同学围观与 CSDN 猜测，老师当场试玩通关第二关并测读档，打出 98 分；
  5. 下午教研室谈话，老师主动点破“Vibe Coding”，指出工具能力不等于个人编码水平，但高度认可孙博提出需求、试玩验证与调试兜底的工程直觉；引出大创与萌创课题机会；孙博从尴尬戒备转为好奇期待；
  6. 离校时孙博意识到 AI 能力储备远超大一课程池塘，产生跃跃欲试的探索冲动。
