# 第六章｜顺手改了个工具

四月初，校园主干道两旁的法国梧桐总算泛起了一层毛茸茸的浅绿。

清明刚过，西安的气温窜得很快。去实验楼的那段斜坡背阴处还留着点湿气，向阳的路面却已经被午后的太阳晒得发干。三月中旬那份申报书交上去之后，如同泥牛入海，整整半个月都没什么动静。科创群里偶尔有研究生学长发几份设备使用登记表，或者问谁在东区能帮忙去学院教务办盖个章，我有空就骑车过去跑一趟。大部分日子，我的生活依然由高数课上昏昏欲睡的求导、二食堂午饭时排成长龙的砂锅面，以及晚上回宿舍连麦打游戏拼凑而成。

那天下午，我是去二楼那间水声微弱信号实验室还两本借来的英文专著。

推开厚重的木门，走廊里的风声立刻被隔绝在外。屋子里拉着半截百叶窗，空气里弥漫着工科机房特有的微温臭氧味。靠墙的长条实验台上散落着几台老款泰克示波器、剥开外皮的同轴电缆和几个用透明胶布贴着标签的铝合金屏蔽盒。屋里没人说话，只有靠窗那台联想台式机的机箱风扇发出持续而沉闷的低吼。

上次在实验室给电脑接线的那位研二学长坐在转椅里，左手压在鼠标垫上，右手握着一截蓝色的圆珠笔，正在一张沾着茶渍的白纸上飞快抄写数据。

屏幕上开着个灰白色的独立程序界面。界面右半边挤满了密密麻麻的文本框与下拉菜单，左半边则是用 Matplotlib 绘图库生成的四个纵向排列的子图，正显示着四道上下错开的连续波形。学长用鼠标在通道列表里勾了两下，点了一记「导出图像」，随后切到桌面点开生成的图片扫了两眼，嘴里含糊地骂了一声，顺手按下了 Alt+F4。

「又得去画图板里重新改标签。」他揉了揉眉心，长长吐出一口气。

我把那两本厚书轻轻码在进门处的空桌上，凑过去看他的屏幕：「学长，什么标签错了？」

「通道号。」学长把转椅往后滑了半步，指着屏幕上刚关掉的那个灰白窗口。刚才四路采集信号里，他勾选的是第二路和第四路，窗口里画出的两组正弦脉冲波形清清楚楚，可导出的图片右上角，图例旁却整整齐齐印着「通道 1」和「通道 2」。

「这不是张冠李戴了吗？」我脱口而出。

「谁说不是呢。」学长拿起桌上的水杯抿了一口残茶，「平常用的时候四路全开，导出来的图例从一排到四，看着一点毛病没有。只要中途单挑两路对比，它就自作聪明从头排号。我们早就知道这个毛病，每次发周报或者贴进论文，都得在绘图软件里把字迹扣掉重新打一遍。赶时间的时候极其烦人。」

他把桌面上的图片改名归档，拿起桌角的打标机准备去给电缆换标签。我站在主机旁，目光在那个略显粗糙的软件界面上停了几秒。

「这个工具是咱们自己做的？」

「好几年前毕业的一个研三师兄留下的。用 Python 拼的界面，后面几届同学又往里添过东西。」他转过头，手里的圆珠笔在铁皮桌面上轻轻磕了两下，「读二进制采集文件、带通滤波、看原始波形、算互相关时延、出图，功能全乎得很。界面排版挤了点，几个按钮字号也不匀称，但底下的算法流我们用熟了，平时连哪个参数在第几个框里闭着眼都能填对。」

我顺着他的指尖看过去。界面的确带着浓厚的自制工具气息，按钮边缘连抗锯齿都没做平滑，打开文件还得先在下拉菜单里手动输入三四个采样参数。但学长的鼠标在上面滑动极快，快捷键按得像盲打。

「既然天天用，怎么没顺手把那个图例修了？」我问。

学长看了我一眼，嘴角扯出一抹带着熬夜痕迹的苦笑：「平时忙着跑水池、调硬件、赶开题报告，哪有空专门给它开膛破肚。这代码十几个文件拼在一块，谁敢保证改了画图会不会把底下的互相关函数给带偏？反正多花两分钟在画图板里描一下也能糊弄过去，多一事不如少一事。怎么，你有兴趣弄？」

他大概只当是大一新生的好奇打听，我却感觉脑子里的某根神经被轻轻拨动了一下。

「学长，能拷个副本给我回去看看吗？我保证不动你们平时用的这台机器。」

学长迟疑了两秒，目光在我脸上停了停，随后伸手抓过鼠标：「行，我给你找个能带走的历史版本。不过丑话说在前头：第一，实验记录和涉密的外场测试数据千万不能拷，我给你几段脱敏的旧水池噪声样例；第二，别在公共电脑上改，改完的代码也别直接往这台机器上覆盖；第三，先把现象老老实实复现出来，别一上来就瞎动。」

他在内网共享盘里翻找了一会儿，把一个命名为 `WaveViewer_v2.3_clean` 的压缩包和两组后缀为 `.dat` 的测试数据拷进了我的 U 盘。趁着解压的功夫，他顺手拿草稿纸画了张草图，把几个关键参数的物理意义讲了一遍。

讲到采样率 200kHz、四通道排列间距时，我还勉强能用大物课上的波动知识对接；等他说到互相关包络峰值查找和到达时间差估计的阈值设置，我的眼神就开始发直，脑袋像敲木鱼一样机械地上下点动。

学长一眼就瞧破了我的底细，伸手在桌上敲了敲：「行了，别装懂了。你这次要做的事跟声学算法没半毛钱关系，只准看界面显示和绘图导出，千万别碰后面那些数学矩阵。」

「明白。」我答得飞快。这一点我心里比谁都清楚——不懂的领域，最好的办法就是离它的核心逻辑远一点。

回宿舍的路上，天色有点阴。

推开宿舍门，下铺的室友正戴着大头戴式耳机在连麦打排位，键盘敲得噼啪乱响。我把书包往上铺一扔，拉开椅子坐下，先用记事本建了个 `notes.txt`，把学长交代的三条红线原原本本抄在最顶头。

插上 U 盘，解压。双击运行，那个灰白色的窗口在我的拯救者笔记本屏幕正中弹了出来。

我载入那份脱敏的测试数据，先点选「全通道」，四个子图稳稳当当画了出来；接着取消第一路和第三路，只勾选第二路和第四路，点击导出。打开生成的图片一看，右上角果然老老实实印着「通道 1」和「通道 2」。

我又试着倒过来选，先勾第四路，再勾第二路。这回不仅标签依然从一开始数，连画面上的两条波形顺序也跟着颠倒了，红蓝曲线互换了位置。更让人头大的是，当我修改参数连着导出第二张图时，系统弹出的保存框里赫然挂着一模一样的默认文件名 `export_figure.png`，连着操作时稍不留神，就可能把上一张图覆盖掉。

我关掉程序，在 VS Code 里把这个工程目录展开。

里面横七竖八散落着十几个 Python 文件：`main_window.py`、`reader.py`、`filter_core.py`、`export_helper.py`……代码行数倒不算夸张，但函数命名风格五花八门，显然经过好几届师兄的手。有些地方用驼峰，有些地方用下划线，注释里甚至还夹杂着几行写于 2018 年的拼音备注。

平心而论，大一上学期刚学 C 语言那会儿，遇上这种项目我连碰都不敢碰，最多把满屏报错截成图片贴进网页聊天框，乞求 AI 施舍几行代码。但寒假在 GitHub 上给 Nexalogic 模组修过一趟兼容性 Bug 之后，我至少长了个记性：改动老旧项目，最要紧的是先给自己的手脚圈一道铁丝网，千万别瞎折腾。

我在便签本上列了几项死规矩：
1. 涉及滤波、傅里叶变换、互相关的计算模块，碰都不准碰；
2. 保持四路全选时的默认逻辑和输出像素比例维持原样；
3. 只修正部分通道被选中时的图例文本对应关系；
4. 导出文件名自动追加通道后缀，并增加文件重名检测，禁止静默覆盖；
5. 原版代码打成 zip 归档存底，一旦改崩随时原地复原。

把规矩理顺，我切到了浏览器的后台页面。

寒假给 Nexalogic 提的 PR 合并后，我赶在下一次扣款前关掉了 Epistemic 的自动续费，二月没再续。三月份给老师写科创申报书，主要靠 Atlas 的网页端整理框架。可眼下这种跨文件修改，还要在本地不断执行脚本验证，网页端拷来拷去不仅慢，还极其容易把上下文参数给弄混。

我打开 Kybernetes 的订阅管理页面，光标在那个二十美元的结账按钮上悬停了半天。

一百三十块人民币。算起来差不多够我在二食堂连续吃上一整周的土豆烧牛肉加冰可乐。尤其这事儿本来就不是导师分派的正式科研任务，纯粹是我在实验室闲逛时自己揽下来的私活。万一折腾到半夜没弄通，这笔钱就等于打了水漂。

我盯着屏幕发了半分钟呆，还是掏出手机扫了码。

「就当是给自己的工具箱交学费了。」我嘟囔了一句。扣款短信跳出来的那一秒，我熟练地直接点进用户中心，把下个月的自动扣费开关按灭，这才重新拉开系统的终端界面。

当那行熟悉的 CLI 提示符在终端里亮起来时，我心里莫名踏实了一点。

我把整个工程复制到一个独立的沙箱文件夹里，给 Kybernetes 输入了第一段提示词。第一句话就加上了硬约束：【只准读取分析，不准擅自修改文件】。随后把我记录下来的现象原原本本输入进去：「在 `main_window.py` 中选择通道 2 和 4 时，界面渲染正常，但通过 `export_helper.py` 导出的图像中，图例被强制写成了通道 1 和通道 2。找出相关代码链路，解释根因。」

终端光标飞快闪烁了十几秒，打印出一串干净的调用链分析。

它的判断非常精准：界面在处理选定通道时，维护了一个名为 `checked_channel_ids` 的整型列表，里面存的是真实的物理编号 `[1, 3]`（代码内部从零索引）；但在调用 Matplotlib 执行离线画布绘制的循环体中，前人图省事，直接写了一句：
```python
for idx, data in enumerate(selected_signals):
    ax.plot(time_axis, data, label=f"通道 {idx + 1}")
```
绘图逻辑直接拿 `enumerate` 的自增循环下标生成了标签文本。只要传入的数据不满四路，生成的标签就永远是从「通道 1」开始自嗨。

我切回源码，按照它给出的行号翻了过去。白纸黑字，那行代码安安静静躺在两段复杂的样式配置中间，确实就是这么回事。

紧接着，Kybernetes 在控制台下方吐出了一个推荐补丁，甚至还附带了一份洋洋洒洒的优化建议：建议把界面渲染函数和导出函数合并为一个通用的视图引擎，顺便把绘图控件从旧版的后端适配器迁移到面向对象的类结构上，一口气省掉重复代码。

我看着它列出的那串涉及六个文件的修改预演，越看越觉得不对劲。

「赶紧停下。」我双手重重敲在机械键盘上，「别动架构，别重构绘图引擎，更别碰数据结构。你只要在导出循环里把 `idx + 1` 换成对应的物理通道映射；顺便在保存对话框生成默认路径时，把文件名做成包含通道组合的形式，发现同名就自动在末尾累加三位序号。只改动实现这个功能的最少代码，改完用我给的脱敏数据跑一次自检。」

Agent 在终端里停顿了一瞬，重新吐出了一份极度克制的修改方案。这次只有 `export_helper.py` 内部的两处局部调整。

修改落实，我按下运行键。

黑色的调试终端闪过两行日志，灰白界面弹了出来。我熟练地勾选第二路、第四路，导出。切换到输出目录，图片的名字变成了清清爽爽的 `Waveform_Ch2_Ch4_001.png`；点开图片，右上角的蓝红折线旁，标注赫然变成了「通道 2」和「通道 4」。

我靠在椅背上长长舒了口气。端起手边的凉水喝了一大口，顺手掏出手机点开微信，找到了那位学长的头像。

输入框里的「学长，我搞定了」刚打完，我的大拇指在发送键上方硬生生悬住了。

寒假里 Nexalogic 维护者针对性能开销和加载顺序提出的那些审查意见，冷不丁又在脑海里冒了出来。别人天天用的工具，哪能拿一组顺手测试就当做万事大吉？

我把手机反扣在桌上，重新坐直身子。

「给脚本准备一组专门的边界覆盖测试。」我给 Kybernetes 下令，「用程序原本支持的文件结构，合成一份包含四种截然不同特征波形的测试数据：第一路方波、第二路正弦波、第三路三角波、第四路高斯脉冲。我们要按顺序验证四种边界情况：全选通道、只选单通道、非连续跳选，以及——用户在界面上故意逆序勾选的情况。」

逆序勾选是很多 GUI 工具的噩梦。有些界面框架在分发勾选事件时，是按照用户的点击先后记录列表，而不是物理排布。

十秒钟后，合成测试数据就位。

我先测了前三种，一切如常。可当我故意先勾选第四路（脉冲波）、再勾选第二路（正弦波）点击导出后，生成的图片当场露了馅：右上角的图例确实显示着「通道 4」和「通道 2」，但对应的曲线颜色却全拧巴了——代表通道 4 的那道红线，画出来的形状赫然是一段平缓的正弦曲线！

数据列表是按点击顺序压栈的，而图例读取又走了排好序的通道集合，数据与标签在半道上脱节了。

我盯着屏幕上的那张废图，刚才那点得意一下子没了。

刚才要是头脑发热把那条微信发出去，明天到了实验室当面演示，当场就得被抓现行。

这回不用我多废话，Kybernetes 顺着失败用例重新检查了导出函数，只调整了这条链路里的数据传递方式：每条待导出的波形都和原始通道编号组成一对，再按同一顺序传给绘图函数，免得数据与标签分别排序、半路走散。

它还补了一个测试脚本：直接从 Matplotlib 的绘图对象里读取各条曲线对应的数值序列和标签，与待绘制的各通道数据逐项对照；再用相同输入比较原版和修改版的基础处理结果。导出的图片适合肉眼看图例，却不能反过来当作浮点数据的精确凭据。

再次运行全量用例。单路、多路、跨路、乱序。

屏幕上的十几道测试日志接连打出了绿色的 `PASSED`。为了保险起见，我又把修改前后生成的四路基准图并排打开，看曲线形状、坐标轴和图例有没有异样；至于数值是否一致，还是以刚才对数组和处理结果的检查为准。

看着屏幕上那个丑陋而稳定的灰白界面，我揉了揉发胀的眼眶。

其实我中间不是没动过心思。看着那简陋如 Windows 98 风格的控制面板，我甚至一度让 Agent 给排了个基于现代扁平风格的暗色主题，按钮圆润，曲线带荧光，看着比原版高档了十倍。

但看着那张炫酷的预览图，我脑海里忽然浮现出那位研二学长右手拿笔、左手连头都不抬就能盲点到滤波配置框的熟练动作。

对于天天靠它出数据的人来说，习惯就是效率。一个大一新生跑过来，自作聪明把按钮位置全挪了，看着是现代了，实际上只是给真正干活的人添堵。

我随手把那个暗色主题方案扔进了回收站，只保留了最克制的修改。

第二天下午，春风吹得实验楼外面的杨树哗哗作响。

我背着笔记本再次敲开了二楼那扇沉重的木门。学长正和另一位同组的研究生围在示波器前记录波形，桌上摊着厚厚的实验记录本。见我进来，他拉开身边一把空椅子：「带了？」

「改好了个副本。」我把笔记本从包里拿出来放在桌角，电源线插上，「我自己造了点特征数据跑通了，但具体的，得用你们这儿允许测试的历史数据试一次。」

学长把圆珠笔夹在耳朵上，拖过转椅坐到我旁边。我先当着他的面，把昨天那套方波、正弦波、三角波的合成数据跑了一遍，特意演示了乱序跳选和重复导出的自增编号。

学长看着屏幕上自动生成的那列带通道标识的文件名，眼睛明显亮了一下：「这个好，以前每次连着测两组，总得手动去文件名后头敲 `_1`、`_2`。」

随后，他在实验室电脑的公开脱敏库里挑了一组去年的水池试验记录，拷进我的机器。他也不看代码，双手搭上键盘，凭着肌肉记忆连续选了几组他平时最头疼的非连续通道组合，切换采样频率，导出，切回桌面，双击看大图。

连着点了五六次，他把几张图排在一起对比，图例上的通道号与波形特征对应得严丝合缝。

他盯着屏幕看了几秒钟，没有立刻夸奖，而是从容地拉开抽屉，翻出了半年前用原版程序处理过的一份标准波形图，两边对照着看坐标轴上的时延基准。

那几分钟里，机房里只有风扇的声音在响。我坐在旁边，看他对照旧图上的坐标轴和峰值，心里也在盘算是不是还有哪种用法没测到。虽说滤波那几个文件我没动过，最后还得看实际用它的人怎么检查。

又核对了两个峰值，学长才把身子往椅背上一靠，转头看着我：「行啊，改得挺干净。底下那几个数学函数没碰吧？」

「真没碰。」我赶紧把昨晚生成的差异报告（Diff）调出来给他看，「改动全在 `export_helper.py` 的画图循环和保存命名里，一共动了不到三十行。原来的核心算法我原封不动，连注释都没删。」

学长接过鼠标，扫了扫我那份格式规范的修改清单，看到后面附着的乱序用例说明时，忍不住笑了一声：「你小子还知道测乱序？之前有个本科毕业设计的同学帮我们改过界面，刚交差那会儿看着挺好，结果一换数据顺序，直接把第四通道当成触发源了，坑了我们半个月才排查出来。」

「昨晚第一版我也栽在这儿了，」我不好意思地挠了挠头，「测试跑崩了才发现数据列表和图例没对齐，又抓回来重写了一遍。」

「这才是写工具的样子。」学长伸手拍了拍我的肩膀，「软件不怕有毛病，就怕写代码的人自己不知道毛病在哪儿。这副本先拷给我，我放到自己机器上用一阵子。要是稳当，开组会我跟老师提一嘴；公共测试机上的版本先别急着换。」

听到这句话，我悬在嗓子眼的一口气才总算落了地。

一周后的周三下午，实验室开科创项目的例行碰头会。

申报材料已经正式送审学院，大家聚在三楼的小研讨室里核对下阶段的水池试验计划。我坐在靠门的塑料折叠椅上，手里拿着笔记本，主要是负责记录会议纪要和学长们列出的采购清单。

会议开到后半段，讨论到以往试验数据的归档效率问题，那位学长顺嘴提了一句：「对了李老师，上回波形工具导出图例错位的老毛病，孙博抽空给改了个稳当的补丁。我们在几组旧数据上试了一个星期，跳选通道的标签现在全对得上了，导出的文件也不会不小心覆盖。挺顶用的。」

坐在会议桌顶头的指导教师从手头的项目书里抬起头，视线越过几位研究生，落在我身上。

「你改的？」老师推了推无框眼镜。

我握着手里的黑色水笔，下意识把腰挺直了一点：「用 Agent 辅助改的。就修了绘图导出那几行，底下几位学长写的滤波和互相关算法我没敢动。」

老师没问我用了什么模型，也没问我写了多少行代码，只是平和地看着我：「改之前留底了没有？你们现在测的都是四通道数据吧？要是以后来了八通道的数据，还能保证没问题吗？」

「原版打包归档了。现有四通道样例的处理结果我们比对过，数值没变；输入接口也没动。但八通道我没测过，原程序支不支持都还没确认，不能保证。」

老师微微点了点头，脸上的神色没有太多波澜，语气沉稳如常：「做工科工具就该是这个路子。实验室的小程序不讲究什么华丽架构，最要紧的是稳定，改了哪里要心里有数，千万别为了修个皮毛把前人验证过的核心逻辑给弄漂移了。」

他把手里的材料翻过一页，目光在全场扫了一圈，接着对我说道：「既然对软件和数据这一块有兴趣，以后下午没课的时候，多来二楼坐坐。水声学的数据采集和预处理有很多杂活，光看书是摸不透的。跟着他们几位多上手跑跑实测，专业基础慢慢学，不着急一下子出成果。」

「好，谢谢老师。」我轻声应下。

会议的焦点很快又转回到了下周向学院申请消声水池排期的琐事上，没人再继续讨论那个几十行的小补丁。项目最终能不能立项批钱依然没有准信，我也依然只是个刚读完大一第一学期、连专业课都没正式开齐的海工新生。

但那天散会的时候，我把椅子轻轻推回桌肚底下，心里那种漂浮无着的感觉，不知不觉淡了许多。

三月份我抱着申报书来找老师时，大家只知道我是个在文字材料上能把语句理顺的大一新生；而现在，在这个由繁复的声学理论、庞大的换能器和灰暗的机箱堆砌起来的小天地里，终于有一件实实在在的小事，是因为我的存在而运转得顺畅了一点点。

虽然这不过是帮学长们修了个边缘脚手架。真正的水声阵列该怎么解算、海底多途信道该怎么建模，那座庞大幽深的知识冰山，我连山脚下的一块碎石都还没搬开。

从实验楼走出来时，天色擦黑，四月的晚风吹在身上微微有些凉意。

手机在兜里接连震动了好几下。掏出来一看，宿舍开黑群里已经被刷了屏，室友连发了三条语音，催我回宿舍上线。说我不在的这两天，《方块纪元》重度工业包里的矿石传送带又卡住了，粗铁矿在转接箱外堵了整整四箱，流水线全面停摆。

我把手机揣回兜里，踩着脚踏车穿过亮起路灯的校园林荫道。

路灯把车轮的影子拉得很长。我心里盘算着，实验室那边的大工程且得慢慢学，但眼下宿舍电脑里那根被齿轮卡死的帆布传送带，今晚回寝室，我还真得赶紧给它顺过来。
