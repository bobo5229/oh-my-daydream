# 第六章｜顺手改了个工具

四月初，学校里的树总算见了点绿。

我去实验楼的次数比三月多了几趟。申报书已经按老师的批注改过一轮，交上去之后暂时没了消息。偶尔在群里看到学长发文件、问谁方便去取个材料，我有空就过去搭把手。更多时候，我还是正常上课，晚上跟室友打游戏，日子没什么特别的变化。

那天下午，我去实验室还一份借来的论文。屋里没人说话，只有靠窗那台电脑的风扇一直在响。上次给设备接线的学长坐在屏幕前，左手扶着鼠标，右手拿着一张记满数字的纸。

屏幕上开着个灰白色的程序窗口，底下是四道上下错开的波形。学长选了两条曲线，点了几下，把图导出到桌面，又打开图片看了一眼，随手关掉。

「又得改图例。」他嘀咕了一句。

我把论文放到他旁边的空桌上，凑过去看：「什么图例？」

「通道号。」他把程序窗口切回来，指给我看。采集记录里有四路数据，他刚才勾的是第二路和第四路，窗口里显示的也确实是这两条。可导出的图片右上角却老老实实写着「通道 1」「通道 2」。

「这不是对不上吗？」

「对啊，所以导出以后还得自己处理。平时四路一起看没事，单挑几路就容易这样。我知道这毛病，正式用的图都会重新核对。」

他把文件名改好，继续翻手边的记录。我却盯着那两个标签看了好一会儿。

「你们这个程序是自己写的？」

「以前一个研究生学长留下的。Python，后面我们也加过东西。」他指着菜单里的几个选项，「读采集文件、滤波、看波形、算相关、导出图，基本够用。别看界面不漂亮，里面不少处理流程我们已经用熟了。」

我点点头。程序看起来确实不像新东西，按钮排得有些挤，打开数据还要手动选好几个参数。但学长操作得很顺手，连哪个选项藏在下拉菜单里都不用找。

「那这个标签怎么没顺手修了？」

「之前也看过，没专门花时间弄。平时更急的是设备和数据，实在不行就把图重新标一下。你想试试？」

他是随口一问，我却一下来了精神：「能拿个副本回去吗？我不动你们正在用的。」

学长看了看我：「可以，我找个能给你用的版本。不过你先别碰原始数据，也别把改好的直接往公共电脑上盖。把问题复现出来再说。」

他从实验室的共享目录里拷了一份程序和去掉实验记录信息的旧样例给我，顺手把原来几个参数的含义讲了一遍。讲到采样率、通道顺序时，我还能勉强跟上；他说到互相关窗口和到达时间差估计的设置，我又开始点头装懂。

他很快看出来了：「没听懂就先别管那块。这回你要改的是显示和导出，不是改我们的定位算法。」

「明白。」我答得挺快，心里想的也是这个。能不碰的东西最好都别碰。

回宿舍后，我先把样例跑了一遍。

程序能正常启动，四通道数据画出来没问题。选第二路、第四路，导出图却写成第一路、第二路，确实和学长说的一样。我又试着倒过来选第四路、第二路，图上的两条线跟着顺序换了，标签还是从一开始往后数。更烦的是，连续导出同一份数据时，文件名总是默认成一个差不多的名字，稍不留神就会把上一张覆盖掉。

我翻开程序目录，里面有几个 .py 文件，名字倒挺直白：读文件的、画图的、导出的，还有一个负责窗口界面。代码我能看懂一点点，大段的数组处理和界面回调就吃力了。

这活儿要是去年刚开学的时候碰上，我大概会先把整个文件复制到网页聊天里，问它哪里写错了。现在至少知道，改之前得先想清楚哪些东西不能动。

我在便签里列了几条：原始数据不改；滤波、相关计算不改；原来的四路全选导出要保持一致；只修选择部分通道时的标签，顺便处理重复文件名。最后还加上一句：旧程序版本必须留着，改坏了能换回去。

便签写完，我才去看账号页面。

一月底关掉 Fellow 续费后，三月写申报书一直靠 Atlas 网页端。可这回得让 Agent 读本地文件、修改程序、反复运行，网页端来回复制恐怕又要折腾到半夜。我打开 Kybernetes 的订阅页面，犹豫了一会儿。

二十美元。说少不少，说多也不是付不起。尤其这问题本来就不是老师派给我的，万一忙一晚上也没修好，这钱岂不是买了个教训？

我盯着价格算了半天，还是重新开了一个月的 Fellow。付完款又立刻去看自动续费选项，打算这次也别忘了关。

终端重新连上时，我居然还有点高兴。寒假修 Nexalogic 那阵子，已经习惯了它能直接看工程文件的省事劲儿。

我把程序放到单独的工作目录里，让 Kybernetes 先读相关文件，不许直接改，问它「选了第二、第四通道，为什么导出的图例会变成第一、第二通道」。

它查了一会儿，指出显示窗口传下去的是选中的原始通道编号，而导出函数画图时又在循环里从一开始计数，拿循环序号当成了通道名。波形取的数据没错，写在图上的标签却换了另一套编号。

这解释听起来很合理，我还是照着它指出的位置去翻了代码。那个循环我看了几遍，确实像这么回事。

Kybernetes 随后给了一个修改方案，除了修标签，还建议顺手把窗口绘制和导出绘制合并成一套新流程，省掉重复代码。我一看涉及的文件和函数突然多了不少，赶紧叫停。

「别重做界面，也别动数据处理。」我重新敲字，「只修图例的通道编号和默认导出文件名。其他先别碰。改完先用我这份测试数据跑。」

它收窄了修改范围，把导出时用于图例的编号换成了实际被选择的通道编号，又让默认文件名带上数据文件名和通道组合，避免同一份记录连续导出时被无声覆盖。

第一轮改完，程序运行正常。我选第二、第四通道，图例终于写成了「通道 2」「通道 4」。

「这不就好了。」我靠在椅背上，正想给学长发消息，又觉得有点不放心。

以前给 Nexalogic 提 PR，维护者看的是各种加载顺序和重复调用；这次虽然只是画图，也不能只测我刚刚发现的那一种情况。

我让 Kybernetes 用程序原本支持的格式生成一份简单测试数据：四路信号各有明显不同的波形，便于肉眼区分；再分别测试全部通道、只选一条、选两条不相邻的，以及把选择顺序倒过来。图例、文件名和图上的曲线都得对得上。

结果倒序选择时又出了问题。图例虽然不再从一开始编号，导出时的曲线顺序却沿用了另一个列表。标签写着「通道 4」，下面画的却还是第二路的数据。

我盯着屏幕看了几秒，庆幸刚才没急着报喜。

这回 Kybernetes 把选中通道的编号和数据一起沿着同一份顺序传给绘图函数，避免分别排序。它还补了几个测试，让程序比较导出前后各条曲线对应的数据，而不光是检查图例文字。

等到全部通道、单通道、非连续通道和倒序选择都跑通，我把原版和修改版的默认四路导出结果放在一起对照。两边波形数据一致，图例和新文件名也没再打架。

我还想继续收拾那个挤得像旧手机设置菜单的窗口，甚至一度让 Agent 给我列了个更好看的布局方案。看着它给出的预览，我又想起学长不用抬头就能点到每个按钮的样子。

算了。别人天天用的东西，我第一次碰就给人把布局改了，说不定只是方便了自己。

第二天下午，我把修改后的副本和一页简短的说明带去了实验室。学长正在电脑前和另一位同学看设备参数，见我来了，腾出椅子让我坐。

「修好了？」

「我觉得修好了。」我把笔记本接上电源，「但得你们试试。」

我先用测试数据演示了一遍，又让学长挑了一份实验室允许用于验证的历史记录。他照平时的习惯选了几个通道，切换参数、导出图表，再打开看图例。连着试了三四次，他才点头。

「标签这下对了。这个文件名也比以前清楚。」

他没有就此把新版本拷回公共电脑，而是又拿出旧版处理过的一组记录，核对波形和分析结果。滤波和互相关那些部分我不敢说自己完全明白，只能在旁边解释，我要求 Agent 没有改动那些函数，也把实际改过的文件和差异列了出来。

「没改代码不等于没影响，」学长说，「好在你这次改的地方跟那几块隔得还算开。」

他又翻了翻说明，问我那个倒序选择的问题是怎么发现的。我把自己差点直接交第一版、后来补测才发现曲线顺序错位的事说了。

「那你还挺有耐心。」

「主要是怕第二天又被你抓回来。」我笑道。

「抓回来是肯定的。」他也笑了，「不过你留了旧版和测试样例，这样以后谁接手都知道该测什么。先放我这儿用几次，有问题再找你。」

我这才真正松了口气。

过了几天，实验室又有一次短会。申报材料已经送到学院，审批还要等消息。大家主要在讨论接下来能提前准备的事，我坐在靠门的地方，听他们核对设备借用和实验时间。

那位学长说到资料整理，顺便提了一句：「上次波形工具导出图例错位的问题，孙博帮我们修了个版本。现在挑通道出图省事多了，我们拿旧数据测过，常用处理结果也对得上。」

老师抬头看了我一眼：「你改的？」

「借助 AI 工具改的。」我说，「主要是导出那一块，原来的分析算法没碰。」

老师让我简单讲讲怎么发现的。我说起第二路、第四路被标成第一路、第二路的事，又解释了一下修改前后怎么做的测试。说到具体数据处理过程，我就让学长接着讲，没有硬撑。

老师问了两句旧版是否留存、后面换数据还能不能正常用。学长说他们保留了旧版本，新版也只在副本上试过，准备再用几批记录看一看。

「这样挺好。」老师点点头，「实验室的小程序不见得非要做得多漂亮，关键是改完得知道哪里变了，别影响以前的结果。」

他把材料合上，接着对我说：「你以后没课的时候可以常来。数据处理、程序这些事，跟着他们一起看看。你专业基础还在学，不着急一下子什么都懂。」

「好。」我答应下来。

老师很快又和学长讨论起设备的事，没再单独谈我。会议照常往下开，项目能不能批下来也仍旧没准信。

不过这回我在会议桌旁坐着，感觉跟上次抱着一摞申报材料来时稍微不一样了。之前大家知道我能把文献写得清楚；现在有人愿意把一个平时真正会用到的小工具交给我帮忙维护。

当然也就是「帮忙」而已。数据怎么采、图该怎么看、实验能不能据此下结论，还是学长们说了算。我连互相关那几个参数为什么这么取都没弄透。

散会后学长把我拉到电脑前，又教了我两个常用的数据处理操作。我听到一半，手机上跳出室友的消息，问晚上《方块纪元》要不要上线，说工厂里的自动熔炼又堵了。

我回了个「八点再说」，顺手把学长说的设置记进笔记。

走出实验楼时天还亮着。花坛边有几个学生正蹲着拍新开的花，我掏出手机，看见 Kybernetes 的对话还停在昨天那份修改记录上。

说起来，我这回并没写出什么了不起的程序。实验室原本就有工具，学长们也早知道怎么用，我只是把其中几个烦人的地方弄顺了。

可比起大一刚开始做 C 语言课设时，只会把报错贴给网页等回复，现在面对一个没见过的工程，我至少知道先留副本、先把问题复现出来，哪些地方该让 Agent 动，哪些地方得先问真正用它的人。

回宿舍以后，我把后续可能要改的地方记在文件末尾，没有立刻动手。八点一到，室友已经在语音里催了好几遍。

我戴上耳机登录游戏，心想实验室那个项目以后有空再说。眼前这条生产线卡住了，今晚还得先把它修通。
