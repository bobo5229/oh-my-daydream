# 《总谱》架空设定

本文档维护作品的架空技术世界，分为两部分：

- **第一部分：总设定介绍**——世界运行规则、公司与产品定位、社会普及状态，以及模型与工具的区别。
- **第二部分：各家模型代际时间线**——按厂商记录已确定的发布节点、在役型号、能力边界和后续待定事项。

**维护规则**：公司、产品与平台的静态定位放在第一部分；版本、发布日期、能力变化放在第二部分。已确定的设定与作者尚未决定的方向必须区分。人物实际经历以 worldview.md 的“已发生剧情”和章节正文为准，不把未来技术规划误记成主角已经知道或使用过的事实。

---

## 第一部分：总设定介绍

### 一、架空世界的基本原则

1. **现实提供技术参照**：现实中的技术进步、行业竞争、融资、人才流动及开源闭源之争，可以成为小说素材，但不是需要逐年照抄的历史剧本。
2. **核心 AI 实体使用架空名称**：AI 厂商、模型、主要 AI 产品与承载剧情的关键社交平台采用架空名称；Transformer、预训练、SFT、RLHF、后训练、推理模型、Harness 等真实技术术语正常保留。无需把小说里出现的所有现实日常品牌全部替换。
3. **能力参照，不机械平移产品史**：2021 年 8 月的 AI 总体技术水平约对标现实 2024 年 8 月下旬，具有较强的多模态、长上下文、基础编程和初期多文件编辑能力；具体产品、代号及后来技术路线均可独立发展。
4. **社会普及存在明显层次差异**：海外 AI 开发者圈已有较深的使用经验；国内大众助手也有一定用户基础，但普通学生对复杂 AI 编程工具仍较陌生。技术能力的出现，不意味着高校教学和传统工作流程已同步改变。
5. **允许架空历史分叉**：从故事开篇起，孙博的选择与实践可以逐渐影响工具生态及应用方式；不预设每次现实中的新模型都要在架空世界按固定日期出现。
6. **技术重要性不等于剧情篇幅**：某条研究路线可以显著影响行业，却不必被孙博认识、理解或亲自测试。强剧情张力主要留给对标现实 GPT-5.4 的高智能模型与成熟 Harness 时代；此前以校园生活、兴趣探索和小型项目为主。

### 二、2021 年 8 月的社会与产品环境

**海外技术圈**：OpenMind、Epistemic、Aleph 等实验室有较高知名度。Caret 等 AI-First 开发工具已经积累先锋开发者用户，但复杂自主 Agent 尚未成熟。

**国内大众圈层**：跃流科技旗下的小满等消费级 AI 助手已较知名，日常问答、中文表达、英语学习和闲聊属于常见用途，但高强度模型协作与专业 AI 开发仍然小众。学校的课程、考试和许多组织流程仍保留传统方式。

**孙博的认知起点**：高中时有通过搜索引擎、贴吧、Gulu 和技术论坛解决软件问题的经验；用过手机端小满做简单问答，却未使用过专业 IDE。对海外 AI 主要只听说过 OpenMind，不了解各家模型谱系。2021 年 8 月在 Natter 偶然看到 Caret 的十万月活公告，才首次接触 AI 编程编辑器。

### 四、主要厂商的长期定位

#### 1. OpenMind / ACT

前沿通用模型实验室。早期倡导非营利 AGI 探索，后引入资本建立商业体系，迭代速度快，拥有繁荣的 API 开发者生态。ACT 是其通用模型家族，ActChat 是面向普通人的对话产品。多模态、响应速度与广泛任务适应性是长期优势，但复杂推理仍可能出现自信错误。

#### 2. Epistemic / Norbert

Epistemic 由一批具有共同研究理想的研究人员独立创立，并非因 OpenMind 内部决裂而成立，也不照搬现实 Anthropic 的创始人、离职事件和组织历史。创立时间、人物及具体治理架构暂不锁定。

**长期文化气质**：兼具严肃研究机构与优秀独立刊物的风格，重视审美、清晰的研究表达、思想讨论，以及哲学、认知科学、语言学与数学、机器学习、系统工程之间的交流。这种克制、富有人文气息的文化不会随着规模增长和商业竞争自动消失，但也不意味着公司成员都偏文科，或研究工作脱离工程实际。

**技术与竞争定位**：Epistemic 同样投入前沿模型训练、可靠性与安全研究，具有世界一流的技术实力。Norbert 系列的强项仍是编程、复杂推理、长文本理解与严谨的指令执行，**不因公司的文艺气质而被限定为写作模型**。面对复杂任务仍可能犯错，安全约束也可能引发过度拒绝。Epistemic 与 OpenMind 可以彼此欣赏、批评和竞争，但双方具体的首次交锋、历史恩怨及关键人物留待行业线剧情逐步确定，不预设正邪对立。

#### 3. Aleph / Atlas

全球搜索、知识索引与云基础设施巨头。Atlas 是其模型家族，擅长长材料和多源信息处理。**模型的上下文能力**与**Aleph 产品通过搜索系统获取实时信息的能力**应区分：在 Caret 等第三方环境调用 Atlas，并不意味着模型无需外部工具就能直接联网搜索。数据来源也可能过时或错误。

#### 4. Cortex / Janus

Cortex 于 2020 年 9 月由原 Aleph / Atlas 项目部分成员创立。创始团队认为 Aleph 对搜索整合与大众产品的投入高于对专业代码、工程问题求解的投入，因此选择独立研发。

Janus 是其编程模型家族，强调明确需求下的代码生成、查错和工程问题处理。交互风格冷淡、简短、缺少人情味；这主要是产品风格和偏好，并非模型完全不能理解情绪或处理非技术内容。它可以与 Norbert 在编程方面竞争，但不预设任何一方永远领先。Cortex 不被默认塑造成危险公司或道德意义上的反派。

#### 5. Caret / Maestro

Caret 是基于开源 VS Code 深度定制的 AI-First 编辑器，在同阶段的产品设计、模型接入与体验上可以比现实 Cursor 发展得更好。它支持选择自研 Maestro 及在役的第三方模型。

Maestro 是 Caret **真正自主研发的专业编程模型**，不是外部模型套壳，也不是整套 Harness 的别名。它开篇表现一般，能完成基础补全、简单函数及局部修改，但综合编程能力尚不能稳定挑战一线旗舰；其宏大的名字可能招致开发者吐槽。Caret 可以凭借良好的编辑器体验吸引大量用户，即使不少人更愿意用 Norbert 等第三方模型。

Caret 与 Maestro 的研发进度不需要同步；孙博使用模型时也不必保持品牌忠诚，应该按实际能力、成本与任务需要选择。

### 五、主要平台的静态设定

**Natter**：名字取自英文“闲聊、唠嗑”。拥有关注、时间线、转帖、评论和热门话题等功能，是全球开发者展示作品、科技公司发布公告及社区讨论的主要公共平台。孙博在 2021 年 8 月首次通过代理访问海外社区时注册。

**Gulu**：国内综合视频及创作者社区，品牌名称统一使用 Gulu。覆盖游戏、音乐、生活、数码和技术教程。孙博高中时期就习惯在此搜索装机、游戏 MOD、软件排错教程；它不是专门的 AI 教学网站。

**跃流科技 / 小满**：跃流是具备推荐算法和大众产品运营能力的互联网公司；小满是其面向普通用户的中文 AI 助手，提供移动端、网页端及小程序，适用于问答、表达润色、英语学习和闲聊。孙博此前用过手机版小满，但对专业 AI 编程工具仍然陌生。小满的具体底座型号、发布日期和用户数暂未锁定。

### 六、未央大学（孙博就读高校）

**基本定位**：位于西安的老牌 985、双一流综合性研究型大学，文理工医协调发展，校园文化多元。

**校区**：学校拥有两个主要校区——**未央校区**位于西安市区，是历史老校区，校园环境成熟、文化积淀深厚；**曲江校区**建设时间较晚，教学与科研设施较现代化。校区面积、建筑名称、具体地址、学院分布、宿舍条件与校区间交通安排暂不设定。

**优势学科**：人工智能、计算机科学、数学处于国内顶尖水平；历史学、考古学等传统学科同样具有深厚积累。

**海洋工程方向**：学校设有海洋相关学院，具有水声工程、船舶与海洋工程等培养方向，拥有传统工科背景，并能与学校的 AI 优势开展交叉研究。

**校园技术环境**：前沿 AI 研究与传统本科教学并存。科研实力强不等于普通新生能直接参与前沿项目；本科低年级学生接触到的仍是基础课程与常规教学安排。

## 第二部分：各家模型代际时间线

本部分以**故事内日期**记录技术演进。现实型号只用于作者侧能力对照，不作为架空世界中的公开称谓。

- **已确定**：可以据此校验正文，防止版本提前登场。
- **待定**：保留方向或空位，后续讨论后再确定，不视作已经发生。
- **发布、Preview、受邀测试、公开 API 接入** 是不同状态，不能混用。

### 一、已确定的跨厂商时间轴

| 故事时间 | 厂商 / 产品 | 状态与事件 |
| --- | --- | --- |
| **2020 年 6 月** | Aleph / Atlas-1 | 第一代 Atlas 正式发布，重点是语言理解、知识检索与信息服务 |
| **2020 年夏季** | Aleph / Atlas 团队 | 对搜索与大众化产品、专业编程能力的研发优先级产生分歧 |
| **2020 年 9 月** | Cortex | 部分原 Atlas 项目核心成员离职创办 Cortex |
| **2021 年春夏** | Aleph / Atlas-2 | 第二代进入市场，形成 Horizon、Swift 产品线 |
| **2021 年 8 月下旬** | OpenMind / Epistemic / Aleph | ACT、Norbert、Atlas 在役；Caret 可接入这些第三方模型 |
| **2021 年 8 月下旬** | Caret / Maestro | Caret 十万月活活动；Maestro 已提供试用，但能力尚不强 |
| **2021 年 9 月** | OpenMind | 首次公布实验性独立推理模型；架空代号暂未确定 |
| **2021 年 9 月** | Cortex / Janus Preview | 首次公开技术预览，开放少量受邀开发者测试；尚未默认接入 Caret |
| **2021 年 12 月上旬** | OpenMind / ACT-5 | 新一代通用旗舰发布，ActChat 与 API 同步开放；通用能力和推理能力开始融合 |
| **2021 年 12 月** | Aleph / Atlas-2.5 Swift Preview | 模型平台与 API 公开预览，对标现实 Gemini 2.0 Flash Experimental；Caret 等正式版后接入，Atlas-2 Horizon 继续在役 |
| **2021 年 12 月中旬左右** | Caret / ACT-5 | 在 ACT-5 发布约一周后完成第三方 API 适配并开放模型选项 |

| **2022 年 1 月上旬** | Epistemic / Norbert-4.5 | 混合推理增强版发布；网页端与 API 同步开放，Caret 在发布后 24 小时内接入 |
| **2022 年 1 月中旬** | Cortex / Janus Public Preview | 专业编程能力升至一线；在官方测试平台公开可用，尚无公共 API；Caret 通过合作伙伴专用接口提前接入 |

### 二、OpenMind：ACT 模型家族

| 时间 | 型号 / 路线 | 状态 | 能力与定位 |
| --- | --- | --- | --- |
| **2021 年 8 月** | **ACT-4S** | 在役旗舰 | 对标现实 GPT-4o：通用多模态、响应快、结构化输出能力较强 |
| **2021 年 8 月** | **ACT-4S Lite** | 在役轻量模型 | 对标现实 GPT-4o mini：低延迟、低成本，适合高频轻任务 |
| **2021 年 9 月** | **独立推理模型（代号待定）** | 实验性公开发布 | 对标现实 o1-preview：复杂数学、科学与推理任务进步；速度、额度及功能有限 |
| **2021 年 12 月上旬** | **ACT-5** | 新一代旗舰；ActChat、API 同步开放 | 对标现实 GPT-5 初代：通用能力与推理能力融合，明显提升复杂推理、编程、多步骤任务与指令遵循；并非成熟自主 Agent |
| **2021 年 12 月—2022 年 3 月前后** | **ACT-4S** | 与 ACT-5 短期并存，约三个月后逐步退役 | 迁移期仍可经旧渠道使用；ACT-4S Lite 的后续安排未变 |
| **后续待定** | ACT 后续型号 | 尚未确定 | ACT-5 后的代际、轻量型号及其他路线仍待讨论 |

**现阶段能力边界**：ACT-4S 已足以处理大量基础 C 语言、Python、MATLAB 编程任务和普通大学课程问题，但多步复杂推导、数学常数及程序边界仍可能出错。严格 JSON Schema 等 API 能力可在受支持接口下使用，不代表任意输出都可靠。

**ACT-5 产品与推理控制（已确定）**：ActChat 面向用户提供统一智能模型体验，由产品系统根据任务复杂度自动调度快速回答和更充分的推理。ACT-5 API 支持 Low、Medium、High 三档推理强度；这不等于 API 完整复刻 ActChat 的自动调度系统。Caret 的模型菜单只显示 ACT-5，推理强度由任务配置控制，发布约一周后接入。ActChat 免费用户获得有限额度，付费用户额度更高；API 按实际用量计费，推理计算增加通常意味着更高成本。具体价格、额度和限速值待定。高推理强度不保证更优结果。

**叙事原则**：2021 年 9 月独立推理模型对行业研发影响很大，但孙博可以完全不理解其技术意义，也不必亲自测试。后续影响通过 ACT-5 等模型迭代间接体现。

### 三、Epistemic：Norbert 模型家族

| 时间 | 型号 | 状态 | 能力与定位 |
| --- | --- | --- | --- |
| **2021 年 8 月** | **Norbert-3 Apex** | 上一代高成本旗舰，仍在役 | 复杂分析、文史哲学思辨有优势，成本与延迟较高 |
| **2021 年 8 月** | **Norbert-4** | 新一代高效主力 | 对标现实 Claude 3.5 Sonnet：强代码、长文本、一致性与复杂指令能力 |
| **2022 年 1 月上旬** | **Norbert-4.5** | 增强版；网页端与 API 同步开放 | 对标现实 Claude 3.7 Sonnet：混合推理，普通响应与扩展思考共存，支持可调思考预算；强化复杂编程、长任务与推理 |
| **后续待定** | Norbert 下一代 | 尚未确定 | Norbert-5 等后续型号与发布时间未锁定，不预设永久代码第一 |

**现阶段能力边界**：Norbert-4 生成的代码通常结构清楚、注释及模块化较规范，仍会产生隐性漏洞；面对部分安全相关测试或需求不明确的场景，可能过度拒绝或给出冗长方案。网页端已有代码侧边预览交互。

**Norbert-4.5 使用与成本（已确定）**：普通响应与扩展思考同属一个模型，不是两个独立型号。API 可配置扩展思考预算。Caret 在发布后 24 小时内完成适配，模型菜单只显示 Norbert-4.5，提供默认关闭的 Thinking 开关与可调思考预算。两种模式共享第三方 Credits，按实际用量计费；启用扩展思考可能显著提高成本与延迟，但不能保证答案正确，也不意味着模型可以自行执行完整工程。

### 四、Aleph：Atlas 模型家族

| 时间 | 型号 | 状态 | 能力与定位 |
| --- | --- | --- | --- |

**公开预览和渠道（已确定）**：2021 年 12 月，Atlas-2.5 Swift Preview 在 Aleph 自有模型平台与 API 面向外部开发者公开预览，具有 Preview 的可用性及服务限制；Caret 不接入这次 Preview，等待正式版后再适配。正式版日期尚未确定。技术重点为高速多模态（文本、图像、音频等输入）、函数/工具调用及效率改善；工具执行依赖外部系统，模型基础架构的 Dense/MoE 细节未锁定。

**代际并存与能力边界**：2021 年 12 月推出 Atlas-2.5 Swift Preview 后，**Atlas-2 Horizon 不立即退役**，继续作为超长上下文与复杂文档分析的主力；2.5 Swift 则突出速度、成本与综合多模态、工具使用表现。超长上下文并非完美记忆或检索，复杂工程代码仍可能出现错误。Aleph 官方产品可以将 Atlas 与搜索工具深度结合，但基础模型本身不等于搜索引擎。

### 五、Cortex：Janus 模型家族

| 时间 | 型号 / 事件 | 状态 | 能力与定位 |

| **2022 年 1 月中旬** | **Janus Public Preview** | 官方模型测试平台公开预览；未提供公共 API | 在代码生成、调试及明确需求的工程问题上提升至同期一线，可与 ACT-5、Norbert-4.5 竞争，但不保证全任务领先 |
| **2022 年 1 月中旬** | Janus × Caret | 合作伙伴受限接入 | Cortex 为 Caret 提供合作伙伴专用接口，允许在无公共 API 的情况下提前集成 Janus Public Preview |

**能力演进与边界**：2021 年 9 月受邀测试版在部分编程任务上可以挑战 Norbert-4；2022 年 1 月的 Public Preview 则在明确需求的代码生成、跨文件调试与工程分析中达到一线竞争水平，仍不保证领先 ACT-5 或 Norbert-4.5。面对模糊需求与复杂沟通仍可能较弱，也会犯代码错误。自主执行、系统入侵与原生多模态均不预设为其早期核心优势。合作伙伴接口不等于面向所有开发者开放 API。

### 六、Caret：Maestro 自研编程模型

| 时间 / 阶段 | 型号 / 事件 | 状态 | 能力与定位 |
| --- | --- | --- | --- |
| **2021 年 8 月** | **Maestro（初期版本）** | 已提供使用 | 高速补全、简单函数与局部修改，实力暂逊同期最强编程模型 |
| **2021 年 8 月** | Caret 十万月活庆祝活动 | 已发生 | 新用户获 100 第三方共享 Credits + 200 Maestro 专属 Credits；老用户有一次 Maestro 额度重置 |
| **2021 年 12 月下旬** | **Maestro 1.5** | 升级版，直接替换原版 | 改善代码编辑、指令遵循和简单跨文件一致性；Caret 上下文检索、组装及差异应用系统同步改进；综合编程仍逊于同期一线 |
| **后续待定** | Maestro 后续迭代 | 尚未确定 | 后续版本可能进步、停滞或退化，Caret 编辑器仍可凭第三方模型与产品体验增长 |
| **未来待定** | Maestro 后训练突破 | **潜在重大节点，未发生** | 有望利用高质量代码数据、真实软件工程任务、编译与测试反馈、强化学习等方式明显增强编程能力 |

**口碑与产品关系**：Maestro 初期可能因为“大师”式名称与普通能力的反差遭到嘲讽。Caret 仍可是一款优秀的编辑器，支持用户改用 Norbert、ACT、Atlas 等第三方模型；模型选择依据任务、成本和实际测试，不需要品牌忠诚。

**版本与产品策略（已确定）**：2021 年 12 月下旬发布 Maestro 1.5 时，Caret 模型菜单继续只显示“Maestro”，版本号在更新日志等处标明；新版直接替换旧版，用户不必切换模型。初代在历史正文中仍称 Maestro，是否追认公开版本号“1.0”尚未确定。增强版的能力提升来自模型训练与 Caret 上下文系统共同作用，不能全部算作模型原生能力。

**模型与工具分层**：Maestro 提供代码推断与生成能力；Caret 负责上下文检索、文件修改和操作界面。开篇已经能进行实用的局部及多文件编辑，但仍需用户检查、运行和验证；长期自动任务执行尚不成熟。

### 七、共同技术路线与尚未确定的代际

**推理路线**：2021 年 9 月 OpenMind 的实验性模型说明推理时计算和后训练开始受到重视。这条路线可以逐步影响之后各家的模型研发，但不代表孙博当时已掌握相关知识，也不要求为每次版本升级安排独立剧情。

**高智能模型与成熟 Harness 的合流**：未来对标现实 GPT-5.4 的高智能模型成为重要分水岭，届时更强的代码推理、多步工具使用能力与上下文管理、权限控制、执行环境、测试和回归验证结合，使孙博有机会以个人为核心组织过去需要多人协作的项目。它主要是后期的技术与叙事方向，而非 2021 年 8—9 月已具备的产品能力。

**2021 年底至 2022 年初的行业窗口（已确定）**：OpenMind 首先以 ACT-5 实现一轮明显的代际突破；Epistemic 的 Norbert-4.5 侧重可控扩展思考与复杂编程；Aleph 以 Atlas-2.5 Swift Preview 突出高速多模态与工具调用；Cortex 的 Janus Public Preview 聚焦专业编程；Caret 的 Maestro 1.5 与上下文系统同步改善日常编辑。各模型没有固定全局排名。Interlude 以一段时间内实际向外部用户开放、且具有重要进展的型号为重点，纯内部未上线模型不必单独记录于间奏；厂商研发进展与孙博的使用时间不强制绑定。

**尚待讨论，不提前写死**：ACT-5 的确切日号与精确定价、Norbert-4.5 的具体思考预算范围、Atlas-2.5 Swift 正式版的日期与后续 Horizon、Janus 正式版及公共 API 时间、Maestro 后训练重大突破节点、国产开放权重推理模型的重要事件及其厂商/型号，均留待后续逐步决定。
