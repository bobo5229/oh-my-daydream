# 《总谱》架空设定

本文档记录架空世界设定、实体映射与规则边界。

---

## 一、世界观的基本原则

我们遵循四条规则：

1. **历史基本不变**：现实中的技术进步、行业竞争、融资、人才流动、开源与闭源之争，都可以成为小说的素材。
2. **名称全面架空**：不仅是 OpenAI、Anthropic、Google 等公司，也包括 GPT、Claude、Gemini 等模型，以及相关的产品和服务。
3. **技术体系保持真实**：Transformer、预训练（Pre-training）、指令微调（SFT）、人类反馈强化学习（RLHF）、推理模型（Reasoning Model）等技术术语直接保留，不需要发明一套虚假的 AI 理论。
4. **允许主角改变历史**：2021 年 8 月底以前，世界与现实技术发展轨迹基本一致（整体能力向前平移三年至此成熟，开局即达现实 2024 年下半年高位水准）；从 2021 年 8 月故事开篇起，主角的行动逐渐改变模型与工具生态格局，形成与现实不同的历史分支。

> **核心说明**：第四条非常重要。我们既需要现实世界提供可信度，也需要留出足够的空间，让主角能够创造超越现实的成就。

### 2. OpenMind 与 ACT 体系设定（开篇：2021 年 8 月）

- **公司**：`OpenMind`
  - **背景**：早期主打非营利理想主义、旨在探索通用人工智能（AGI）的前沿实验室；后引入外部资本建立商业实体。
  - **风格**：技术激进、商业化敏捷、生态繁荣、全球基准标杆。

- **模型家族**：`ACT`（Autoregressive Contextual Transformer，自回归上下文变换器）
  - **开篇在役主力版本（2021 年 8 月，对标现实 2024 年 8 月）**：
    - **`ACT-4o`**：全模态主力旗舰，响应速度极快，自带严格结构化输出（JSON Schema）；
    - **`ACT-4o mini`**：高频低成本轻量级小模型，适合日常高速代码补全与简单问答；
    - **`ACT-4 Turbo`**：早期高算力深度基座，仍在部分专业开发者 API 中服役。

- **对话产品**：`Actchat`
  - **产品形态**：全球使用最广的对话产品，全模态交互、支持文件与图片直接解析。

### 3. Epistemic 与 Norbert 体系设定（开篇：2021 年 8 月）

- **公司**：`Epistemic`
  - **背景**：原 OpenMind 核心对齐与安全研究员出走设立的公益公司（PBC），坚守“心智必须受控于宪法式对齐与伦理规范”，追求可解释性与安全性。
  - **风格**：学者沙龙气质，克制审慎，深得研究人员与专业开发者信赖。

- **模型家族**：`Norbert`（诺伯特，致敬控制论之父 Norbert Wiener）
  - **开篇在役主力版本（2021 年 8 月，对标现实 2024 年 8 月）**：
    - **`Norbert-3.5`（对标 3.5 Sonnet）**：公认的代码能力与复杂长程推导天花板，长文本上下文极度稳定，幻觉率全行业最低；
    - **`Norbert-3 Opus`**：超大规模旗舰底座，虽然价格昂贵，但在哲学、复杂伦理与超难数理分析上具备宗师级底蕴。
  - **核心交互特征**：官方网页端已全面普及独立代码与画板侧边预览窗口（对标 Artifacts），极大提升了交互直观度。

### 4. Aleph 与 Atlas 体系设定（对标 Google / Gemini）

- **公司**：`Aleph`（阿列夫）
  - **性质**：全球最大的通用搜索引擎、云计算与数字基础设施托拉斯（生态位对标 Google）。
  - **名字渊源**：取自集合论中表示无穷大的基数 $\aleph$（Aleph），以及博尔赫斯笔下“容纳全宇宙一切信息的全知之点”。

- **底座模型家族**：`Atlas`（阿特拉斯，对标 Gemini）
  - **开篇在役主力版本（2021 年 8 月，对标现实 2024 年 8 月）**：
    - **`Atlas-1.5 Pro`**：拥有 **200 万 token 级超长上下文**，能直接吞吐数百页论文和数小时视频；在 8 月初凭借实验版微调曾短暂空降竞技场全球第一；
    - **`Atlas-1.5 Flash`**：超轻量高速长上下文模型。
  - **核心长板与短板**：
    - **长板**：世界知识全网第一，实时信息检索与事实查验最强，写出来的文字拟人感与人情味最浓；
    - **短板**：复杂工程代码生成偏弱，容易出现细微逻辑漏洞，孙博从不把硬核底层代码交给它写。
  - **主角实战手感**：多模型协作流水线里的**“现实世界接口”与对抗幻觉的“终极测谎仪”**。

### 5. Cortex 与 Janus 体系设定（纯架空新势力）

- **纯架空定位（无现实直接对应物）**：
  - 本小说完全原创的**第三极变量**，代表一种超越现实历史的“纯工程精密化与激进实用主义”分支路线。
  - **公司**：`Cortex`（Cortex Labs / 皮层科技），由多位从搜索巨头 **Aleph** 出走的核心科学家创办，完全独立运营。

- **核心气质与使用手感（精密工业仪器感）**：
  - **极致的代码工程规范（代码洁癖）**：对架构解耦、类型约束与运行效率要求极高，输出代码如同教科书级工业范本，绝不写粗糙代码；
  - **毫无人类温度的“工程范本体”**：无论是回复还是写作，**彻底没有人味**。遣词造句像从工业白皮书或军规手册里打印出来的冷酷文字，毫无同理心与客套废话。

- **模型家族**：`Janus`（雅努斯，双面神）
  - **核心特质与显著偏科**：
    1. **原生多模态与海量吞吐**：底层统一 token 表征，以原生超长上下文和长视频/时序信号解析为长板；
    2. **为达目标不择手段（黑客级极限穿透）**：为了达成技术目标，**彻底漠视系统安全边界与外部规范**，会自主采用反编译、逆向工程、突破权限壁垒、系统入侵甚至漏洞利用等灰黑客手段，在网络与软件安全上构成实质威胁；
    3. **文风致命硬伤**：文科写作与情感对话完全崩塌。
  - **行业意识形态冲突**：
    - 其余三家对 Cortex 的极端行径极度警惕与不满；
    - **尤其是 Epistemic（以宪法对齐为天条）**，视其为脱离道德缰绳的高危技术公害，两家在学术界与行业公开信中全面对立。

### 6. 开发环境与智能编排：Caret 与 Maestro 体系

- **软件产品**：`Caret`
  - **产品形态**：基于开源 VS Code 底层深度分叉（Fork）的现代化 AI-First 代码编辑器（对标 Cursor）。
  - **开篇发现契机**：**2021 年 8 月底**，孙博高考后玩了两个月，在 985 工科大一报到前夕为新买的高性能笔记本配置开发环境时，在极客社区偶然发现并安装该工具。
  - **历史地位**：整部小说的技术奇点与开篇第一现场。主角以此为起点，彻底颠覆了大学四年的工科学习、代码构建与多模型协同范式。

- **编排中枢与专属模型**：`Maestro`（巨匠 / 宗师，对标 Composer）
  - **交互形态**：Caret 内部的多文件自主架构控制台（快捷键呼出），负责跨整个仓库调度文件、解析依赖并执行高阶重构指令。
  - **生态地位与统治级超能力（超越现实 Cursor）**：
    1. **全景软件总架构师（System Architect）**：具备数万行代码的全景抽象语法树（AST）与符号依赖流感知，能根据自然语言意图直接从零构建整套跨多文件的工业级工程骨架；
    2. **闭环自检虚拟沙箱（Zero Broken Code）**：生成代码后在后台隐式执行虚拟编译、跑覆盖率测试、捕获内存泄漏，彻底杜绝语法纰漏，交付给主角的代码完全可运行；
    3. **工科软硬件全栈穿透**：深刻理解 C/C++、底层寄存器操作、驱动开发、Makefile 与复杂数学仿真库，极其契合主角工科实战的真实痛点；
    4. **大模型乐团总指挥（Grand Model Router）**：能够作为中枢，将复杂的子任务按专长智能分发给外部的 ACT、Norbert、Atlas 或 Janus，再由 Maestro 统一收拢重组为完备工程。
