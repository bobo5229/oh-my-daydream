## 阶段目标

建立能真正阅读现有《总谱》正文、切换章节并恢复位置的最小网页。

**实施范围**：正文页面、章节导航、首页入口与本地阅读位置恢复。

**阶段外**：Interlude 业务抽屉、完整编年切换、Lore、图库、高级视觉增强。

**全局约束**：只使用原有 Markdown 作为文本权威；不修改小说正文、Interlude、Lore、worldview 或 Canon。没有得到作者额外批准，不实现本 Task 之外的功能；必要时先提出具体变更供确认。

## S01-T01｜章节渲染与阅读路由

- **依赖**：S00-T05。
- **输入／前提**：只读章节内容接口和现有真实 Markdown。
- **修改边界**：阅读器正文模板、必要路由与章节渲染，不修改数据源。
- **只做这些**：完成独立章节页面与自然纵向滚动，正文安全展示；现阶段以派生的正文片段呈现，避免混入 Interlude。
- **交付物**：可启动的章节页面及加载异常处理。
- **验收标准**：至少能逐一进入所有现有章节，中文内容顺序正确；章节不存在时有明确反馈。
- **明确不做**：不做整书无限滚动、翻页阅读和完整编年顺序。

<a id="s01-t02"></a>

## S01-T02｜章节目录与上下篇导航

- **依赖**：S01-T01。
- **输入／前提**：章节 ID、排序、标题和读取页面。
- **修改边界**：仅顶部基本导航、左侧目录抽屉、独立完整目录页和上下章链接。
- **只做这些**：读取章节索引生成目录，突出当前章节，支持上下章手动切换。
- **交付物**：两个目录入口和章节导航交互。
- **验收标准**：章节顺序与真实内容一致；末章无无效下一章；不写死每章链接。
- **明确不做**：不展示 Interlude 时间线，不植入未确认的卷次或未写章节。

<a id="s01-t03"></a>

## S01-T03｜首次首页与继续阅读入口

- **依赖**：S01-T01、S01-T02。
- **输入／前提**：小说名称、章节入口和本地是否存在阅读记录。
- **修改边界**：仅作品首页、首页路由及首次访问分流。
- **只做这些**：无进度时显示简洁作品首页，有进度时默认进入最近章节；导航可手动返回首页。
- **交付物**：首次／再次访问两种路径演示。
- **验收标准**：无记录正常从首页开始；有记录不会反复强制展示首页；访问首页不清进度。
- **明确不做**：不提前制作最终封面或引入外部图片依赖。

<a id="s01-t04"></a>

## S01-T04｜章节位置保存与恢复

- **依赖**：S01-T01、S01-T03。
- **输入／前提**：章节锚点和浏览器本地存储。
- **修改边界**：仅阅读进度状态、恢复模块及回归测试。
- **只做这些**：自动保存最后阅读章节与段落附近位置；支持布局变化、内容编辑后的安全回退；资料面板状态与正文进度区分。
- **交付物**：可复现的保存恢复演示与边界测试。
- **验收标准**：关闭重开恢复到原段落附近；清空／损坏本地存储仍可阅读；不会被首页访问误覆盖。
- **明确不做**：不建服务器账号、跨设备同步或手动书签。

## Stage 完成条件

- [ ] 现有小说正文可按独立章节纵向阅读
- [ ] 章节抽屉与完整目录正确跳转、上一章／下一章可靠
- [ ] 首次访问进入首页，第二次能恢复上次章节和原段落附近
- [ ] 关闭网页再打开仍能恢复；原稿保持未修改

本 Stage 所有必需 Task 必须分别通过验收，并由作者检查整阶段结果。完成 Stage 不等于自动授权下一个 Stage。

- 精确阅读定位应选择何种锚点与回退机制

如未决策事项影响当前 Task 的正确性，**先讨论形成明确选择，再下发该 Task 的 Codex 指令**，不得用候选方案冒充既定共识。
