## 阶段目标

在可用正文之上形成现代、柔和中性色、高品质中文阅读体验。

**实施范围**：统一视觉令牌、正文排版、深浅主题、字号／行距偏好和基础响应式表现。

**阶段外**：不制作 Lore、时间线内容、图库与大图查看器。

**全局约束**：只使用原有 Markdown 作为文本权威；不修改小说正文、Interlude、Lore、worldview 或 Canon。没有得到作者额外批准，不实现本 Task 之外的功能；必要时先提出具体变更供确认。

<a id="s02-t01"></a>

## S02-T01｜视觉令牌与正文排版

- **依赖**：S01-T04。
- **输入／前提**：已实现的章节模板与总纲排版参数。
- **修改边界**：仅 UI 样式、排版变量和相关组件微调。
- **只做这些**：建立浅／深中性色基准、字体栈、字号行距与标题留白；正文目标宽约 780px，参考范围 720–840px。
- **交付物**：实际章节长文排版与可比对截图。
- **验收标准**：默认正文 18px、行距 1.85，阅读区居中且不会在宽屏无限拉长。
- **明确不做**：不换成宋体，不大幅重设计导航信息架构。

<a id="s02-t02"></a>

## S02-T02｜系统跟随与手动主题覆盖

- **依赖**：S02-T01。
- **输入／前提**：视觉令牌与系统主题偏好。
- **修改边界**：仅主题状态、持久化与主题切换入口。
- **只做这些**：实现系统跟随、手动浅色和手动深色三态；保存偏好，允许恢复系统跟随。
- **交付物**：主题切换与记忆演示、自动化测试或手工步骤。
- **验收标准**：无设置时跟随系统；覆盖后重启依然生效；恢复系统跟随后响应系统切换。
- **明确不做**：不新增无关主题色方案，也不修改小说内容。

<a id="s02-t03"></a>

## S02-T03｜字号行距与恢复默认

- **依赖**：S02-T01。
- **输入／前提**：18px / 1.85 基线和可读取的浏览器存储。
- **修改边界**：仅阅读设置小面板、两个调节项及其保存逻辑。
- **只做这些**：支持调节字号／行距、记住偏好、恢复默认并即时更新正文。
- **交付物**：交互设置页与持久化测试。
- **验收标准**：页面刷新后偏好保留，恢复默认得到 18px／1.85；当前章节位置尽量保持。
- **明确不做**：不擅自扩展成字重、字体、段距、宽度自由编辑器。

<a id="s02-t04"></a>

## S02-T04｜基本自适应与阅读回归

- **依赖**：S02-T02、S02-T03。
- **输入／前提**：完整基础阅读器、主题和排版状态。
- **修改边界**：仅响应式样式、无障碍基础修正与回归测试。
- **只做这些**：检查大屏、普通桌面、窄窗口下阅读宽度、目录可访问性、横向滚动与位置稳定性。
- **交付物**：响应式截图／核验记录及修复。
- **验收标准**：窄窗口正文可读、无异常横滚；调节主题或字体不清空位置；目录可打开关闭。
- **明确不做**：不提前确定未来右侧抽屉拖动行为或移动端完整交互规范。

## Stage 完成条件

- [ ] 默认正文约 780px、18px、1.85 行距，使用现代无衬线中文字体
- [ ] 浅色柔和灰白／深色石墨灰均可阅读
- [ ] 系统主题跟随、手动覆盖、恢复跟随和偏好保存均正确
- [ ] 窗口大小、字号及主题变化不丢失当前正文进度

本 Stage 所有必需 Task 必须分别通过验收，并由作者检查整阶段结果。完成 Stage 不等于自动授权下一个 Stage。
