## 阶段目标

统一管理插图、Logo、SVG 和技术图表，使其既能融入正文与资料，也能独立浏览。

**实施范围**：可复用资产索引、正文自然嵌图、可选 YAML 内容增强、统一大图查看器、视觉资料库。

**阶段外**：不创作新的官方视觉资产、不为每篇 Interlude 强制添加图表、不因排版改写小说内容。

**全局约束**：只使用原有 Markdown 作为文本权威；不修改小说正文、Interlude、Lore、worldview 或 Canon。没有得到作者额外批准，不实现本 Task 之外的功能；必要时先提出具体变更供确认。

## S06-T01｜统一视觉资产清单

- **依赖**：S05-T01。
- **输入／前提**：仓库已有的图片、SVG、企业 Logo 与档案实体索引。
- **修改边界**：仅阅读器资源清单／元数据、引用解析和验证。
- **只做这些**：为每项资产建立稳定标识、类型、源文件路径和关联内容；资源缺失时提供诊断或占位。
- **交付物**：资产索引、复用接口和文件存在性测试。
- **验收标准**：同一文件可由不同页面引用，路径失败不导致整章打不开。
- **明确不做**：不自动下载网络示例图或把临时设计当成 Canon 资产。

<a id="s06-t02"></a>

## S06-T02｜正文场景插图的自然嵌入

- **依赖**：S06-T01、S00-T05。
- **输入／前提**：已确认插图、对应章节与稳定位置锚点。
- **修改边界**：仅阅读器派生插图映射、图文样式及锚点配置。
- **只做这些**：优先读取 Markdown 原有图片；必要时通过外部元数据插入章节场景附近，控制尺寸与留白。
- **交付物**：至少一个有授权素材的图文示例和位置回退验证。
- **验收标准**：插图不打断正文顺序；宽度通常不超过正文；无对应素材时页面仍正常。
- **明确不做**：不修改原稿写入临时图片链接，不自行生成角色立绘。

<a id="s06-t03"></a>

## S06-T03｜Interlude 视觉增强组件

- **依赖**：S03-T04、S06-T01。
- **输入／前提**：普通 Interlude 内容、可选 YAML 和 SVG／图表资产。
- **修改边界**：仅可选视觉增强解析与时间轴、事件卡片、技术图表组件。
- **只做这些**：用 YAML 描述额外视觉模块与稳定锚点，按需渲染；没有配置时继续显示普通 Markdown。
- **交付物**：可选组件示例、结构错误回退测试。
- **验收标准**：布局增强不能改变原文顺序或导致文字丢失；不存在的图表配置被清楚报告。
- **明确不做**：不为所有 Interlude 人工制造图表和事件卡片。

<a id="s06-t04"></a>

## S06-T04｜统一大图查看器

- **依赖**：S06-T01。
- **输入／前提**：正文、Lore、Interlude 的普通图片与宽幅 SVG。
- **修改边界**：仅媒体预览／大图交互组件。
- **只做这些**：抽屉内自动完整预览，点击进入可缩放／平移查看器，支持返回和位置恢复。
- **交付物**：图片与 SVG 的查看器和键盘／触控基础核验。
- **验收标准**：关闭后回到原段落或抽屉滚动处，宽图不被强制裁切且可读。
- **明确不做**：不让复杂图表自动强制跳去独立 Interlude 页面。

<a id="s06-t05"></a>

## S06-T05｜独立视觉资料库与复用回归

- **依赖**：S06-T01、S06-T04。
- **输入／前提**：统一资产索引与可用图片。
- **修改边界**：仅图库页面／分类索引及多视图复用测试。
- **只做这些**：集中浏览人物立绘、场景插图、企业 Logo、技术图表；条目可跳转到来源或关联资料（有则显示）。
- **交付物**：图库入口、分类浏览、大图预览与复用回归结果。
- **验收标准**：资源只存一份、多个视图正确引用；资产为空或部分缺失时有合理空状态。
- **明确不做**：不实现社交分享、下载商店、投稿或用户评论。

## Stage 完成条件

- [ ] 同一资产在正文、Lore、Interlude、图库中复用，不复制文件
- [ ] 正文插图自然邻近对应情节，基本排版简洁
- [ ] 大图支持缩放、拖动平移，关闭后保持原阅读位置
- [ ] 特殊 Interlude 组件可选，无 YAML 时仍正常显示纯文字
- [ ] 图库可按类型浏览、查看大图；资源缺失有可理解的降级
