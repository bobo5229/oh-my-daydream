## 阶段目标

在正文旁边快速查阅相关人物、企业、基础模型和 Harness，同时支持完整分类与搜索。

**实施范围**：规范实体索引、名称识别、YAML 覆盖修正、资料浏览、搜索和分层档案。

**阶段外**：不新写 Canon、不改原有 Lore、暂不完善图库和复杂关系可视化。

**全局约束**：只使用原有 Markdown 作为文本权威；不修改小说正文、Interlude、Lore、worldview 或 Canon。没有得到作者额外批准，不实现本 Task 之外的功能；必要时先提出具体变更供确认。

## S05-T01｜实体规范索引

- **依赖**：S00-T05。
- **输入／前提**：lore.md、worldview.md 及其他确定的设定来源。
- **修改边界**：仅派生实体清单、分类／别名配置和校验工具。
- **只做这些**：定义实体稳定 ID、类型、正式名、别名、来源链接；特别区分公司、基础模型、Harness 和产品。
- **交付物**：可核验的实体索引及来源追溯说明。
- **验收标准**：所有条目有来源；歧义名称可提示；不凭阅读器创造新技术设定。
- **明确不做**：不增写 Lore、不开辟新的事实权威文件。

<a id="s05-t02"></a>

## S05-T02｜正文识别与 YAML 修正

- **依赖**：S05-T01、S00-T03。
- **输入／前提**：实体索引与派生章节正文。
- **修改边界**：仅识别算法、章节关联索引、覆盖 YAML 及测试。
- **只做这些**：按名称／别称识别章节相关实体；支持手动添加、排除和冲突消解；对代码块和容易误匹配的普通词采取保守策略。
- **交付物**：每章关联实体列表及命中来源／修正测试。
- **验收标准**：典型别称匹配正确；覆盖配置可稳定修正误识别；不需要向正文添加链接标记。
- **明确不做**：不向 Canon 回写识别结果，也不以未经确认的 AI 推断补充事实。

<a id="s05-t03"></a>

## S05-T03｜分类目录与统一搜索

- **依赖**：S05-T01。
- **输入／前提**：规范实体索引与分类。
- **修改边界**：仅 Lore 分类入口、统一搜索和空结果反馈。
- **只做这些**：建立人物／企业／基础模型／Harness／技术等分类目录，提供名称与别称的检索。
- **交付物**：可使用的分类视图、搜索框、无结果和重复名处理。
- **验收标准**：能找到真实实体；别称可检索；不同实体类型不混淆。
- **明确不做**：不建设联网搜索服务或复杂数据库。

<a id="s05-t04"></a>

## S05-T04｜章节上下文与分层详情

- **依赖**：S05-T02、S05-T03。
- **输入／前提**：章节关联实体、原资料与抽屉布局。
- **修改边界**：仅当前章节相关列表、精简详情和相关实体链接。
- **只做这些**：抽屉默认展示当前章节相关条目；详情包含经来源确认的摘要、属性、Logo／人物图（有则展示）和实体关系入口。
- **交付物**：章节上下文列表和实体详情抽屉。
- **验收标准**：换章后关联条目对应更新；缺图缺摘要能优雅回退；正文阅读位置保留。
- **明确不做**：不自动生成没有来源的公司简介或人物生平。

<a id="s05-t05"></a>

## S05-T05｜完整档案展开与状态回归

- **依赖**：S05-T04。
- **输入／前提**：分层实体详情与原始 Lore 文档。
- **修改边界**：仅详细阅读／独立视图及导航回退测试。
- **只做这些**：在简洁摘要之外提供完整资料阅读入口，一键展开独立视图，支持回到原章节和原抽屉定位。
- **交付物**：档案深读功能和端到端回归结果。
- **验收标准**：展开与返回状态可靠，搜索－详情－正文之间导航可预测，原始设定文本不损失。
- **明确不做**：不引入未确定的多人编辑、评论与权限体系。
