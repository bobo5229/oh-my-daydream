## 阶段目标

在纯小说和完整编年两套正式阅读顺序间切换，仍共享正文进度。

**实施范围**：序列元数据、章中 Interlude 分段规则、模式切换入口、上一／下一篇导航、共享进度。

**阶段外**：不改变源 Markdown，不强制补读旧 Interlude，不构建 Lore 搜索。

**全局约束**：只使用原有 Markdown 作为文本权威；不修改小说正文、Interlude、Lore、worldview 或 Canon。没有得到作者额外批准，不实现本 Task 之外的功能；必要时先提出具体变更供确认。

## S04-T01｜双序列数据与章内切片规则

- **依赖**：S03-T01、S00-T04。
- **输入／前提**：已验证的嵌入式 Interlude、章节位置、YAML 关联信息。
- **修改边界**：仅阅读编排数据契约、派生阅读节点和测试。
- **只做这些**：根据 YAML 派生纯小说与完整编年两套顺序；为章中 Interlude 定义不修改 Markdown 的前后片段／锚点切换规则。
- **交付物**：两种可复核的节点序列及位置映射测试。
- **验收标准**：ch03 章中 Interlude 在完整编年顺序位置准确；任一模式拼接内容不丢不重。
- **明确不做**：不将时间线展示日期当成阅读排序，不自动补写未来 Interlude。

<a id="s04-t02"></a>

## S04-T02｜模式状态与双入口

- **依赖**：S04-T01。
- **输入／前提**：已确认模式序列与顶部工具栏／左侧目录。
- **修改边界**：仅模式状态、选择控件及本地偏好保存。
- **只做这些**：顶部轻量切换标签和左侧目录明确模式选择互相同步；作者先确认首次默认值。
- **交付物**：模式切换 UI、状态记忆及一致性测试。
- **验收标准**：两个入口显示相同模式，刷新后保留选择，切换不重新装载正文。
- **明确不做**：不得将此前「纯小说默认」的建议误当成确认。

<a id="s04-t03"></a>

## S04-T03｜按模式导航与位置映射

- **依赖**：S04-T01、S04-T02。
- **输入／前提**：两套序列、章节位置与 Interlude 视图。
- **修改边界**：仅上一篇／下一篇、目录节点链接和路由恢复。
- **只做这些**：根据选定序列决定下一节点；完整编年可进入 Interlude；纯小说继续正文；对章中片段保持准确返回位置。
- **交付物**：导航演示、边界状态和章中回跳测试。
- **验收标准**：各序列走到末尾正确停下，无无效页、无限循环或遗漏文本。
- **明确不做**：不自动跳转回头补读未读档案。

<a id="s04-t04"></a>

## S04-T04｜共享进度和切换回归

- **依赖**：S04-T02、S04-T03。
- **输入／前提**：原阅读进度模块、双模式路由和抽屉浏览状态。
- **修改边界**：仅切换行为、进度存储修正及端到端回归测试。
- **只做这些**：确保两模式只有一个正文进度；在正文切换原地保持位置；从 Interlude 切到纯小说恢复之前正文位置。
- **交付物**：刷新／切换／跨节点测试与对比记录。
- **验收标准**：任何切换都不清空进度、不强行补读、不会将 Interlude 进度覆盖正文进度。
- **明确不做**：不实现账号、跨设备同步或书签系统。

## Stage 完成条件

- [ ] 纯小说模式正式阅读序列不包含 Interlude
- [ ] 完整编年模式从 YAML 派生并正确包含章首和章中 Interlude
- [ ] 模式切换不会跳离正文位置、不会产生两份正文进度
- [ ] Interlude 中切换纯小说能够回到之前的小说位置
- [ ] 顶部模式入口与左侧目录状态一致且保留偏好

本 Stage 所有必需 Task 必须分别通过验收，并由作者检查整阶段结果。完成 Stage 不等于自动授权下一个 Stage。
