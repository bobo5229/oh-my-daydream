## 当前章节与定位

- **当前章节**：ch01

- **核心叙事命题**：**把新玩具带到寝室现场分享，从热闹整活到兴趣散场，初次察觉“我和大家在意的点不一样”。**
  - 心态定位：这是大一男生“发现新玩具想炫一下/分享一下”的心态，绝非技术布道或学术宣讲。
  - 核心错位：室友在乎的是“好不好玩、像不像某人、能不能做题、瞎不瞎编”；孙博在乎的是“没给规则、只给例子，它怎么就知道该怎么接”。
  - 认知锁死：孙博还不会 AI，也没有立志学 AI；但他发现即使大家热闹完散了，自己脑子里那个关于“它怎么懂的”的问号并没有随之消失。

### 时代与认知硬锁（本节硬禁出现）
1. **禁止技术权威感**：孙博在室友面前嘴笨、解释不清，绝不能说出成熟的深度学习术语。
2. **禁止宣扬未来/AGI**：不准出现“这是未来的趋势”“大模型将颠覆一切”等宏大叙事。
3. **禁止室友恶意冲突**：室友不嘲讽孙博，只是普通大一男生的正常反应——好玩就笑两声，翻车或没用就散开各干各的（洗澡、开黑、刷视频）。

## 剧情节拍（Beats）清单

- [x] **Beat 1：忍不住主动分享（轻写，约 10–12%）**  
  SEC 2 过去几天后，孙博没有继续研究 Genesis-3，但那个书签一直留着。某天晚上寝室比较闲，几个人正在聊天、等游戏开局或者刷手机。孙博突然想起这个东西，主动把电脑转过去：「哎，给你们看个东西。」不提“AI”，不搞科普，只用大白话：「国外刚出来一个挺怪的网站」「这个叫 Genesis-3，好像是什么语言模型」「你往里面写东西，它会自己接」。

- [x] **Beat 2：发现自己其实根本不会解释（中等，约 12–15%）**  
  室友问：「这东西干嘛的？」孙博试图解释，但说得很笨拙：「就是……你写一段东西，它能往后接。」「有时候你给它几个例子，它自己能猜出来后面该干嘛。」室友继续追问：「它咋知道的？」孙博只能老实回答：「不知道。我前两天查过，后面全是公式，看不懂。」延续 SEC 2 的粗糙认知，完全不具备科普能力。

- [x] **Beat 3：拿寝室聊天做现场演示（核心，约 22–25%）**  
  为了证明“它不是普通自动补全”，孙博临时想到拿寝室群聊天做例子。不写「请模仿」之类的指令，只给几轮非常生活化的群聊记录（老周催开黑，小陈推脱说洗澡，老周吐槽你每次都说洗澡，小陈说五分钟五分钟……）。打下冒号后，Genesis-3 顺着接出一句极具神韵的话：「你上次那个五分钟我等了半小时」。孙博关注的是：没给规则它自己看懂了语气与上下文；室友的反应则是第一重错位：「卧槽，还挺像老周！」「再整一个！」「让它学小陈说话！」

- [x] **Beat 4：Genesis-3迅速变成寝室玩具（核心重头戏，约 28–32%）**  
  大家围过来，兴趣迅速从“原理”滑向“这玩意还能整什么活”。连续尝试寝室典型恶搞：模仿某人习惯口吻、编离谱的迟到/请假理由、游戏输了后的经典甩锅语录、预测今晚开黑谁最坑等。Genesis-3 有的接得神准引人发笑，有的接得一般，有的直接胡说八道。大家笑闹几次后，它在寝室里的角色被彻底定性为：一个能自动写段子的搞笑网页。

- [x] **Beat 5：翻车与兴趣迅速退潮（中等，约 15–18%）**  
  玩了十来分钟后，模型开始翻车：高数题算得一塌糊涂、常识搞反、吐出一大堆没有重点的车轱辘废话。室友很自然地失去新鲜感：「这不还是瞎编嘛」「挺好玩，但没啥用」「还不如搜百度」「能帮我把作业写了再说」。气氛自然冷却，有人去水房洗澡，有人掏出手机开游戏，有人躺回床上刷视频。没有嘲讽，只是单纯不再在意。

- [x] **Beat 6：第一次意识到“我在意的点和他们不一样”（收束，约 12–15%）**  
  人散开后，寝室重新恢复走廊水声与打游戏的叫喊声。孙博坐在桌前，心里有一点说不出的微妙落差。他原本以为室友看到“不给规则、只看例子就能接住”的现象也会愣一下，结果大家在意的只是好不好玩、像不像老周、能不能做题。孙博没有宏大顿悟，只觉得奇怪：最邪门的明明不是它写了什么俏皮话，而是我什么都没告诉它，它怎么就知道该怎么接。室友喊着进房间开黑，孙博应了一声，但在手机点进房间前，视线又忍不住在最左侧那个书签上停留了一眼。兴趣没有随人群退潮而消失。
