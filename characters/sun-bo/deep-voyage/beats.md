## 剧情节拍（Beats）清单

- [ ] **Beat 1：再次点开书签与过滤门槛（轻写，约 10–12%）**  
  SEC 1 过去一两天后，趁着课间或晚上回寝，重新点开前天留下的标签页。面对密密麻麻的论文预印本页面，扫了一眼 Abstract、长串作者名、公式和架构图，果断关掉标签页，心里只有最真实的大一新生反应：“这什么东西，完全看不懂”。然后专门挑标题写着类似“Genesis-3 explained”或“What is a language model?”这类通俗科普的网页看。

- [ ] **Beat 2：初识“语言模型”这一标签（中等，约 15–18%）**  
  从浅显博客里看到对 language model 最基础的定义：处理语言、根据已有文字预测或生成后续文字的模型。完全不懂背后的数学对象或神经网络，但至少第一次能把那天见到的怪东西归类：原来它叫“语言模型”。甚至产生过一个朴素猜测：“高级一点的输入法？”但转念一想又推翻——输入法绝对做不到看三个例子自己把第四句翻译出来。

- [ ] **Beat 3：核心术语的一句话粗糙解构（中等，约 15–18%）**  
  通过搜词和查词典，把前天满屏生僻词压缩为极其粗糙的常识级理解，绝不深入：
  - `parameter`：Genesis-3 有 1600 亿个“参数”，但参数具体是什么，不知道。
  - `pre-training`：模型在开放使用之前，已经塞了海量文字提前“训练”过。
  - `prompt`：大概就是自己往输入框里敲的那行字。
  - `few-shot`：给少量例子，模型就能照葫芦画瓢完成任务。  
  到此为止，完全不触及权重、token 切分、损失函数与梯度。

- [ ] **Beat 4：第四次测试对上号（核心重头戏，重点，约 28–32%）**  
  在某个开发者博客或面向普通用户的介绍中，第一次亲眼看到 few-shot 的示范用例（例如英法翻译对照：`English: cat -> French: chat ...`）。孙博盯着屏幕愣了几秒，脑海里瞬间闪回自己前天敲下的“苹果/Apple、终南山起雾”的那四行输入。反应绝非高深的学术顿悟，而是一声极具生活实感的恍然大悟：“原来他们早知道这事。”“原来这玩法叫这个名字。”这是本节最大的认知推进。

- [ ] **Beat 5：再探原理，光速撞墙（中等偏重，约 12–15%）**  
  被好奇心推着点开一个解释 Genesis-3 底层原理的网页。开头说它基于 `Transformer` 架构；顺手去查 Transformer，解释写着“一种神经网络架构”；再顺着搜神经网络，紧接着扑面而来的就是 `matrix`（矩阵）、`vector`（向量）、`attention`、`embedding`、`probability`……往下滚了两屏全是公式和结构图。孙博看了不到五分钟，耐心彻底耗尽，毫无心理负担地直接按 `Ctrl+W` 关掉网页。真实普通人的自然退却。

- [ ] **Beat 6：粗糙认知封存，大学生活重新占上风（轻写，约 12–15%）**  
  合上浏览器前，脑子里关于 Genesis-3 只沉淀下几条极简的印象标签：叫语言模型、提前用很多文字练过、输入叫 prompt、给例子叫 few-shot、有 1600 亿个参数，至于底层怎么跑的——彻底不知道。随即现实生活压了过来：明天的工科课业、还没写的 C 语言作业、室友在背后戴着耳机扯着嗓子喊“五缺一快上号”。孙博关掉大半标签页，只在书签栏留着那个预览网址。兴趣没有消失，但也绝没有立志学 AI。起身、接水、融入寝室吵闹的日常。
