# 《深潜航道》（deep-voyage）节拍记录

本文档为当前章节与各小节（Section）的推进节拍。遵循 SOP 1 流程。

---

## 当前章节与定位

- **当前章节**：ch01
- **当前小节**：SEC 1
- **核心叙事命题**：**孙博第一次遇到一种自己无法用已有“人工智能”印象解释的软件。**
  - 不是“发现人工智能革命”，不是“立志成为 AI 工程师”，甚至不是“意识到大模型的未来”。
  - 核心状态变化只有一句朴素的叩问：“**这东西到底怎么回事？**”

### 时代与交互硬锁
1. **产品形态**：Asterion Research 仅开放了一个功能受限的公共 **Playground Preview**。不是完整 API（正式 API 需审核申请），更不是成熟的聊天产品。注册 Asterion 账号即附带固定少量的免费试用额度（quota）。
2. **界面气质（纯正 2020 年极客/开发者质感）**：
   - 绝非 User: / Assistant: 的对话气泡窗口；
   - 包含模型选择下拉框（Model: Genesis-3）、大文本输入框（Prompt:）、右侧参数滑块（Temperature 0.7、Max Length 128、Top P 1.0）及单一的 [ Generate ] 按钮；
   - 孙博此时根本不知道 Temperature 等参数的技术含义，全用默认设置。
3. **试探体验（拒绝逢问必神）**：
   - 真实体验必须是“时灵时不灵，但灵的那几次不知道它为什么能做到”；
   - 第 1 次：普通，甚至有点傻；
   - 第 2 次：跑偏、车轱辘话或胡言乱语；
   - 第 3 次：突然非常精准，孙博开始察觉不对劲；
   - 第 4 次：换了一种非延续性任务，它居然仍然接住了，让孙博陷入深度困惑。

## 剧情节拍（Beats）清单

- [x] **Beat 1：开学后的信息探索（轻写，约 5–7%）**  
  2020 年秋，孙博刚入西工大长安校区。个人电脑彻底脱离高中娱乐属性，成为随心折腾的个人设备。因游戏、数码或日常兴趣，经常碰到打不开的海外网站、视频和社交平台链接。单纯出于好奇与折腾欲琢磨如何访问海外互联网。无任何宏大动机。

- [x] **Beat 2：初次动手解决网络工具（轻写，约 6–8%）**  
  照着网上教程下载客户端、寻找配置、碰到连接超时与报错。自己一步步排查测试后终于跑通。技术过程展现真实的新手折腾感，不写成教程说明书。核心在于获得一次微小但实在的正反馈：原来原先看起来神秘的电脑与网络问题，是可以靠搜索、试错和排查解决的。

- [x] **Beat 3：初入海外互联网生态（中等，约 8–10%）**  
  第一次进入两套架空海外平台：先看类似 Instagram 的图片流平台 `Luma`，再进入类似 Twitter 的短图文信息流平台 `Relay`。初体验并无震撼感，甚至觉得“也就这样”。顺手刷刷球员、游戏资讯、数码新品与国外大学生的日常碎碎念，随手关注几个账号。确立 2020 年大一新生的生活底色与新信息入口的开启。

- [x] **Beat 4：偶然刷到 Genesis-3（中等偏重，约 12–15%）**  
  在 `Relay` 上无意刷到某位平时关注的开发者/数码博主随手转发了一条推文，附带一句调侃：“Genesis-3 playground preview is open now. This thing is ridiculous.”。没有铺天盖地的“AI 革命”营销，只是小众圈子的离谱感叹。孙博第一次撞见 Asterion Research 和 Genesis-3 这两个名字，纯出于好奇顺手点进链接。

- [x] **Beat 5：首次上手 Genesis-3（核心重头戏，重点，约 28–32%）**  
  进入 2020 年简陋的开发者 Playground Preview。孙博注册了账号，获得初始试用 quota。面对大文本框、滑块参数和 Generate 按钮，他带着随意的玩票心态敲下输入：
  - 第 1 次：普通甚至有点傻，回答中规中矩；
  - 第 2 次：直接跑偏，吐出车轱辘话；
  - 第 3 次：给了一段残缺前提让它接，结果接续内容逻辑异常严密且极其精准，孙博开始觉得哪里不太对劲；
  - 第 4 次：临时换了一种完全不同维度的格式/翻译/逻辑任务，它居然依旧严丝合缝接住了。  
  没有所谓“涌现”或“上下文学习”的概念，孙博脑子里只有最本能的震动：“它怎么知道我要干什么？”

- [x] **Beat 6：回到国内互联网寻找解释（中等偏重，约 14–17%）**  
  新鲜劲过去后，下意识切回百度、知乎、B站等国内平台搜索 Genesis-3 和 Asterion Research。搜索结果寥落得反常：几篇冷门的技术博客机翻摘要、零星几条几乎零互动的动态，大量结果甚至风马牛不相及。孙博没有“国内错失革命”的上帝视角，只是产生了一个非常朴素、真实的工科新生困惑：“这么有意思、这么邪门的东西，怎么几乎没人聊？”

- [x] **Beat 7：重返 Relay 与兴趣锚定（中等，约 10–12%）**  
  因中文资料极度匮乏，只能切回 Relay 顺着那条推文的转发链与讨论顺藤摸瓜。顺手关注了 Asterion Research 官方和几位主创研究员，屏幕上第一次扑面而来一堆生僻技术名词（language model、parameter、pre-training、prompt、few-shot）。绝大部分完全看不懂，只能不断 Ctrl+点击新标签页、查在线词典、存书签。本节在满屏未关闭的标签页中收束。状态彻底锚定为：“我想搞明白 Genesis-3 到底是什么”。
