第二，后续不再逐个记录 0.1 小版本。小版本可以作为背景存在，只有发生明显“使用范式变化”的大版本才进入主时间线。

- OpenMind / Genesis：通用能力、代码、推理、产品化速度领先，是行业能力上限的主要丈量尺。
- Sapient / Sage：长上下文、复杂文本理解、逻辑严谨、稳定性和安全性更突出。

第四，孙博仍然首先是大学生和 AI 的顶级使用者，而不是基础模型研究者或 Agent 框架开发者。新技术出现后，他会了解、测试、使用和判断价值，但不会自己去造 Genesis、Sage、Hermes 或底层 Agent 框架。

第五，幻觉始终存在。模型能力增强可以降低部分错误，但不能写成某一代模型彻底解决幻觉。后续错误可以从早期明显的“编论文、编数据”，逐渐变成更隐蔽的错误推理、错误引用、错误工具调用以及“引用真实材料却得出错误结论”。

## 一、2023 年暑假：对话模型开始突破纯聊天框

时间：2023 年 7—8 月。

这一阶段不安排新的代际旗舰模型正式发布。

三家仍大致处于 Genesis-3.x、Sage-1.x、Hermes-1.x 的成熟期，小版本继续快速迭代，可以不逐一编号。

行业开始出现一个新的趋势：

模型不再只能在网页聊天框里输入文字、输出文字。

开发者社区开始大量讨论：

- API 调用；
- 函数调用；
- 插件；
- 代码执行；
- 搜索工具；
- 外部工具调用；
- 让模型先制定简单步骤，再调用工具完成局部任务。

但这一阶段的这些能力仍然非常原始，远未发展为成熟 Agent。

孙博会在全球 AI 社区里注意到这些变化，也会觉得很新鲜，但由于他此时仍然是大学生，并没有必要立刻深入开发 API 系统。

对孙博本人而言，2023 年暑假的重点应该仍然是：

**AI 已经进入学习与生活，而不是孙博开始转型成 AI 开发者。**

## 二、2023 年秋：第一轮真正的代际跃迁

### OpenMind：Genesis-4

Genesis-4 正式发布。

这是故事开篇以来第一次真正意义上的“大版本跃迁”。

核心变化：

- 推理能力显著强于 Genesis-3.x，但复杂数学与长链推理仍然会犯错；
- 代码能力明显提升；
- 指令遵循更加稳定；
- 上下文长度明显增加；
- 幻觉有所改善但仍然突出；
- **视觉输入第一次真正进入普通用户可用阶段。**

视觉能力非常重要。

在此前的 2023 年上半年，孙博面对教材公式、伯德图、根轨迹、实验图、课件截图等内容时，仍然需要自己手动转成文字描述。

Genesis-4 出现以后，他第一次可以：

- 上传课件截图；
- 上传公式图片；
- 上传图表；
- 上传实验结果截图；
- 让模型直接解释图像内容。

这应该成为 Genesis-4 对孙博产生最明显冲击的能力之一。

但视觉理解仍然不能绝对可靠，复杂工程图、细小标注、数学图像仍可能看错。

### Sapient：Sage-2

Sage-2 与 Genesis-4 前后进入市场。

它不需要在视觉、代码、通用能力上全面击败 Genesis-4，而是继续强化 Sapient 自己的路线：

- 更长上下文；
- 更稳定的长文理解；
- 更好的复杂指令保持；
- 更强的文档总结和结构梳理；
- 更少出现明显胡说，但仍可能出现“逻辑自洽但前提错误”。

Sage-2 开始出现一个非常鲜明的应用场景：

**把大量课程材料、论文、长文档一次性交给模型处理。**

Genesis-4 更像能力全面的大跃迁；

Sage-2 更像“终于可以认真读长东西了”。

### Helix：Hermes-1.x 后期版本

此时暂不急于发布 Hermes-2。

Helix 继续快速完善 Hermes-1 系列：

- 搜索结果引用更加透明；
- 实时网页信息整合增强；
- 图片搜索与基础视觉能力开始结合；
- 回答中更容易定位信息来源；
- 对新闻、人物、现实事件和实时数据的处理明显优于纯离线模型。

这一阶段，Hermes 开始从“搜索引擎长了嘴”向“能够理解现实世界信息的 AI 入口”过渡。

## 三、2023 年冬：三家正式进入多模态竞争

### Genesis-4.x

Genesis-4 进入快速产品化阶段。

重点不再是继续堆一个大版本号，而是：

- 图像理解更加稳定；
- 文件处理能力增强；
- 代码与普通办公任务结合；
- 工具调用开始逐渐进入普通产品；
- GenChat 从单纯聊天网页逐渐变成综合 AI 工作台。

### Sage-2.x

继续扩大长上下文和文档处理优势。

Sage 开始特别受到：

- 学生；
- 研究人员；
- 写作者；
- 法律、咨询等长文本职业用户

欢迎。

### Helix：Hermes-2

Hermes-2 正式发布。

这是 Helix 第一次真正意义上的代际升级。

Hermes-2 的核心定位不是“最聪明的模型”，而是：

**最能连接现实世界的模型。**

重点能力：

- 图片理解；
- 搜索；
- 网页；
- 地图；
- 新闻；
-实时信息；
- 多来源引用；
- 图片和文字混合查询。

Hermes-2 逐渐形成独立竞争逻辑：

Genesis 争“最强通用智能”；

Sage 争“最强理解与长上下文”；

Hermes 争“最强现实世界接口”。

## 四、2024 年上半年：长上下文与多模态真正普及

这一阶段不再把“能够上传图片”当作大新闻。

视觉、多文件、PDF 等能力逐渐成为旗舰模型的标准配置。

真正的新变化是：

**上下文规模开始爆炸。**

### Genesis-4.5

可以作为 Genesis-4 与下一代之间的重要中代升级。

特点：

- 推理、代码、多模态全面增强；
- 能处理越来越长的文件；
- 工具调用逐渐成熟；
- 复杂任务连续保持能力增强；
- 但仍不是后来的成熟 Agent。

### Sage-2.5

Sage 在这一阶段进一步突出自己的传统优势。

长上下文规模大幅提升。

过去孙博只能：

复制一段教材；

后来可以塞一章；

现在开始能够直接处理：

- 一本教材的大量章节；
- 整门课程讲义；
- 多篇论文；
- 大量笔记；
- 一个长期项目的资料集合。

这里应该体现一次明显的使用范式变化：

**模型开始从“回答当前问题”，转向“理解一个较完整的个人知识环境”。**

### Hermes-2.5

Hermes 将长上下文与搜索、多模态结合。

优势继续放在：

- 最新信息；
- 跨网页资料整合；
- 图片、地图、文本联合查询；
- 带来源回答；
- 现实世界知识更新。

## 五、2024 年下半年：推理能力成为下一轮竞争核心

这是继 2023 年秋多模态之后的第二次重大技术范式变化。

模型不再只是追求“马上给答案”，开始出现：

**愿意花更多计算时间处理复杂问题的推理型模型。**

OpenMind 可以率先推出 Genesis 系列的新一代能力，例如：

### Genesis-5 / Genesis 推理型旗舰

具体最终型号可以后续剧情中再定，但能力方向必须明确：

- 数学能力发生明显跃迁；
- 代码推理更加可靠；
- 科学问题处理增强；
- 多步骤问题开始真正具备较稳定的连续推理能力；
- 对复杂开放任务的处理显著强于 2023 年模型。

这里应该和孙博 2023 年数学建模失败形成强烈呼应。

当年：

模型连复杂模型假设、公式推导和数据验证都经常胡说。

现在：

新一代模型第一次开始真正能够解决一部分当年把孙博坑惨的问题。

但不要写成：

“如果当年有 Genesis-5，孙博一定拿一等奖。”

新的模型仍会犯错，只是复杂推理能力的上限发生了真正跃迁。

### Sage-3

Sapient 不跟随 OpenMind 单纯拼 benchmark，而是将：

- 长上下文；
- 深度推理；
- 更强的自我检查；
- 更稳定的复杂文本理解

结合起来。

Sage-3 的特色可以是：

**慢，但是谨慎；不一定最惊艳，但复杂任务中更让人放心。**

### Hermes-3

Helix 把自身巨大搜索与现实信息优势进一步和推理模型结合。

Hermes 不只是“找到信息”，而开始能够：

- 主动搜索多个来源；
- 对来源进行比较；
- 整合现实世界信息；
- 再进行推理和回答。

这为后续真正的 Deep Research、Agent 等能力埋下伏笔。

## 六、到 2024 年底，全球 AI 格局应该达到的状态

截至 2024 年底：

大模型已经从：

**网页聊天机器人**

发展成：

**能够理解图像、大量文件、搜索互联网、调用部分工具并进行较复杂推理的通用 AI 助手。**

但仍没有全面进入成熟 Agent 时代。

尤其不要在 2024 年过早写出：

- 成熟 Claude Code 类 CLI；
- 自己接管代码仓库；
- 自动完成完整软件项目；
- 长时间无人监督执行复杂现实任务；
- 稳定自主浏览网页并完成多阶段工作。

这些能力应留给后续 2025 年的 Agent / Coding Agent 阶段。

## 七、模型明线对应孙博成长线

后续写剧情时，模型升级必须服务于孙博人生，而不能变成单独的版本更新日志。

对应关系暂定为：

### 2023 年上半年
孙博学会：

**和 AI 对话。**

### 2023 年下半年
随着视觉和多模态出现，孙博开始学会：

**把现实中的资料直接交给 AI。**

课件、图表、截图、实验结果第一次可以直接进入模型。

### 2024 年上半年
随着长上下文爆发：

**孙博开始把完整知识环境交给 AI。**

不是问一个知识点，而是让 AI 理解整门课程、多个文档和长期任务背景。

### 2024 年下半年
随着推理型模型出现：

**AI 第一次真正开始参与复杂思考。**

过去 AI 更多是解释、整理和辅助；

现在它开始在部分复杂数学、代码、科学和规划任务中成为真正的“思考伙伴”。

这一步必须让孙博感受到时代变化，但仍不能让 AI 直接把他变成各领域专家。

## 八、后续写作约束

从 2023 年暑假以后：

不要每出现一个 0.1 版本就在正文中专门写一次发布。

小更新只作为背景。

真正值得成为剧情事件的节点只有：

1. Genesis-4 / Sage-2：视觉和长上下文第一次真正改变普通用户体验；
2. Hermes-2：多模态 + 搜索 + 现实世界信息入口形成；
3. 2024 上半年：长上下文规模爆炸；
4. 2024 下半年：推理型模型真正出现；
5. 后续 2025 年：Agent / Coding Agent 才正式进入主舞台。

同时保留一条贯穿全书的技术事实：

**模型越来越强，但幻觉不会因此从故事中消失。**

模型能力越强，幻觉可能越不明显、越难察觉，因此孙博的判断能力、人类终审和真实世界验证始终有价值。
