## 1

十一月最后一个礼拜，长安校区的风一下子变硬了。

从宿舍楼出来往教学区走，正对着南边连绵的终南山。天晴的时候山体像是一堵青灰色的屏障直接砸在眼前，但只要刮风，空气里就全是干燥微凉的土腥味。路两旁的悬铃木叶子早掉光了，光秃秃的枝丫在风里晃，落叶打着旋往绿化带里滚。

我缩着脖子把羽绒服拉链往上拽了拽，手里拎着装了笔记本电脑的黑色双肩包。

高考结束那个夏天，家里给我配了这台联想拯救者。到今年大二，这台机器已经陪我在宿舍、机房和自习室之间转了一年多，键盘边缘被磨得发亮。

大二上学期的课表比大一时松了一点，但期末周的影子已经隐隐压过来。数据结构的实验报告还没写完，概率统计的卷子印了厚厚一沓。除了上课和去食堂，我大部分时间还是耗在寝室这张一米宽的书桌前。

我最初倒不是为了折腾什么高深的技术。起因琐碎得很：我喜欢看球，也关注几款还没国服的端游，平时在贴吧和虎扑刷帖子，经常能看到别人随手贴出的 Twitter 截图或者海外视频网站链接。点进去，要么是浏览器标签页顶端那个灰色的圆圈无休止地转，要么就是干脆利落的连接超时。

那种白茫茫的「无法访问此网站」，看多了总让人觉得窝火。

大二开学后我总算把代理的事理顺了。大一摸索了一年，从最开始换端口、改配置，到后来踩了无数节点失效的坑，现在终于有了自己固定在用的几条线路。周五下午没课，寝室里只有饮水机偶尔加热的咕噜声。我盘腿坐在椅子上，就着一罐冰红茶，习惯性地摸进了 Twitter。

Twitter 的信息流节奏快得很。我顺手关注了几个平时常看的 NBA 球星、两家数码媒体的官方号，还有几个在主页发代码段和数码开箱的海外博主。屏幕上的英文碎碎念夹杂着缩写和俚语不断往下滚。

直到晚饭前，我在 Twitter 的时间线上刷到了一条转发。

发帖的是一个常年测 Linux 内核和显卡驱动的开发者，平时动态互动量也就几十上百。但他在一小时前随手转发了一条动态，自己只配了一句简短的评语：

「GenChat is live. Everyone should try this.」
（GenChat 上线了。都去试试这个。）

转发的原帖来自一个叫 OpenMind 的机构账号。头像是一个线条极简的迷宫图案，帖子内容同样干练，只附带了一个链接，说是新发布的对话产品 GenChat 开放注册，注册即送基础额度。

GenChat？

我从来没听说过这个名字。至于人工智能，我脑海里的印象还停留在几年前下围棋的 AlphaGo，或者手机里那个经常听不懂人话的语音助手。大一学 C 语言的时候课上提过一嘴神经网络，但也就是提了一嘴，满屏幕都是 `printf`、`scanf` 和指针。

我纯粹是被那个博主口中的语气勾起了好奇，顺手点开了那个链接。

网页跳转得很快。

跳出来的界面完全没有科技宣传片里的那种质感——就是一个干净的网页，中间偏下位置挂着一个对话框，底下是输入框，光标正在一闪一闪地等着我打字。右上角标着一行小字：Logged in。

我愣了一下。

这玩意儿……是个聊天窗口？

我把光标点进输入框，想了想，顺手敲了一句最标准的英文问候：

Hello, what is your name and what can you do?

按下回车。

对话框里我的那句话旁边，立刻弹出了一个新的回复气泡，字体和我的那句话不太一样，是它自己的样式：

Hi there! I'm GenChat, an AI assistant made by OpenMind. I can help you with all kinds of things—answer questions, brainstorm ideas, write code, translate text, explain concepts, and more. What would you like to do today?

我盯着那个回复气泡看了三秒。

语法自然，语气流畅，甚至还带了点主动问我想干什么的意思。我从来没见过任何软件能这样跟人说话。

我又敲了一句：

Can you write a short poem about the终南山 in winter?

它几乎立刻就回了：

Sure! Here's a short poem:

The Zhongnan ridges wear a thin white veil,
Wind whispers through the pines and chills the vale.
A student hunches o'er a steaming bowl,
While winter writes its slow and quiet scroll.

我靠在椅背上，把这段英文反复读了两遍。

不是什么了不得的诗，但它居然听懂了「终南山」这三个字——我是中英混着打的，它没有当成乱码，而是直接把这个地名嵌进了诗里，还押上了韵。

我又来了兴致，往输入框里敲：

Explain recursion to me like I'm a college freshman who only knows C.

它这次回复得稍微长了一点：

Sure! Think of recursion like Russian nesting dolls. You open one doll, and inside is a smaller doll that looks just like it. You keep opening smaller dolls until you reach the tiny solid doll at the center—that's the base case, where it stops. Then you put them all back together.

In C terms: a function that calls itself is like that. As long as it hasn't hit the base case, it keeps calling a smaller version of itself. Once it does, it unwinds and returns.

Example:
```c
int factorial(int n) {
    if (n <= 1) return 1;   // base case
    return n * factorial(n - 1);  // recursive call
}
```

我盯着那段代码看了几秒。

不是什么高深的东西——大一上学期就学过递归——但它居然真的用 C 语言举了个例子，而且那个 Russian nesting dolls 的比喻我一下就懂了。

寝室里很静，窗外的天色不知不觉已经暗了下来，灰蒙蒙的暮色压在终南山的轮廓上。

我往输入框里敲了一句：

You are just predicting the next word, right? How do you actually know what recursion is?

它停了大概两秒——回复气泡里跳出了一个「正在输入…」的指示——然后回了：

You're right that I predict the next word based on patterns I've learned from a huge amount of text. But what that means in practice is that I've seen recursion explained, used, and discussed billions of times across books, websites, and code repositories. So when you ask, I don't "know" in the human sense, but I can put together a response that makes sense based on all those patterns.

That said, I don't actually understand what recursion feels like. I'm just very good at sounding like I do.

我读完那段回复，手指在键盘上停住了。

它居然……自己承认了。

没有吹自己多厉害，没有装神弄鬼，而是老老实实告诉我：我只是在预测下一个词，我不懂递归是什么，我只是很擅长装懂。

这种坦诚反而让我后背微微泛起一阵凉意。

我切出浏览器，打开了 Helix、知乎和 B 站。

我在搜索框里输入 GenChat。

按理说，能做到这种效果的程序，国内的技术社区应该有人讨论才对。

然而搜索结果跳出来的一瞬间，我有些意外。

Helix 的第一页，和这个 AI 相关的结果只有寥寥几条。一条是某个科技自媒体在今天下午机翻的一篇海外快讯，标题叫《海外实验室 OpenMind 发布对话产品 GenChat，号称能听懂人话》，正文干瘪得像机器说明书，阅读量刚过千，底下评论只有个位数。

另一条是一个程序员的个人博客，博主提了一嘴自己下午注册了 GenChat，说「这东西比想象中能干，但也没那么神」，后面就是关于它偶尔胡说八道的牢骚。

我又切到知乎。

搜索 GenChat，相关的提问刚冒出来两三个。关注人数最多的一道题叫「如何评价 OpenMind 新发布的 GenChat？」，底下总共只有三四个回答，而且都是今天下午才发的。排名第一的回答是一个在读博士写的，通篇充斥着公式推导，结论却相当冷淡：

「……本质上依然是一个基于自回归（Autoregressive）的概率补全模型，不具备真正的因果逻辑推理能力。GenChat 只是在 GPT-3 级别模型的基础上做了指令微调（instruction tuning），让它学会了听人话，但底层依然不理解世界……」

我盯着那个回答看了半晌。

指令微调？不理解世界？

我想起刚才对话框里它写的那首诗、那段递归解释、还有它自己承认「我不懂递归」的那番话。

答主说得头头是道，那些专业词汇我也看不太懂。可如果它真的只是个概率补全模型，刚才为什么能听懂我中英混打的那句诗？为什么能用俄罗斯套娃解释递归？为什么它自己知道它不懂？

一个很朴素的念头在我脑子里冒了出来：

这东西今天下午才刚上线……怎么网上讨论的人这么少？

寝室门「吱呀」一声被推开了，室友拎着两盒热气腾腾的黄焖鸡米饭从外面挤进来，带进一阵走廊里的饭菜香和冷风。

「博哥，还没去吃饭呢？楼下二食堂爆满，排队排得要死，我等了二十分钟才买到。」

「啊……一会儿去。」我应了一声，随手按了快捷键，把知乎页面最小化。

室友把饭盒往桌上一撂，撕开一次性筷子，掏出手机点开了《王者荣耀》。

手机屏幕横了过来，外放里很快传出熟悉的游戏开场播报音。日光灯管在头顶发出轻微的嗡鸣。

六点二十。室友的黄焖鸡吃了一半，手机上的对局刚刚进入加载界面。

我看着自己屏幕上那个对话框，手指在触控板上划了划。

我没有去关电脑，而是重新切回了 Twitter。

既然中文网页里找不到什么有价值的讨论，那就只能回源头看。

我顺着那条动态的转发链，找到了 OpenMind 的官方账号，又点进了简介里列出的几位研究员主页。

全英文。

满屏幕都是我不认识的技术短语。

language model……语言模型？
instruction tuning……指令微调？
prompt……提示词？就是输入框里打的那行字？
context window……上下文窗口？

我根本看不懂这些词背后的机制。

我右手按住键盘上的 Ctrl 键，食指连续点击鼠标左键。

新标签页一个接一个地在 Chrome 顶端弹出来：词典释义、某个海外开发者的讨论串、还有几个独立技术博客。中间有一条链接连到了一个论文预印本平台，页面白底黑字，密密麻麻全是双栏排版的英文小字和数学符号。我扫了一眼那篇几十页长文的标题和摘要，满屏都是生僻术语，看了两行就觉得头皮发麻，甚至连下载 PDF 的念头都没有，直接顺手把那个标签页关了。

原本宽敞的标签栏被挤得只剩下一排小小的图标。

我把那个 GenChat 的对话页面拖到最左侧的第一个标签位，按下 `Ctrl+D`，把它收进了书签栏。

窗外的天彻底黑了下来。

我重新点开那个写得相对通俗的个人博客，就着寝室日光灯的白光，开着划词翻译，硬着头皮一行一行地看了下去。

我现在根本不知道这东西算不算所谓的未来，更没想过自己一个航海学院的大二学生跟这玩意能有什么联系。

我只是想弄明白——

刚才它为什么能听懂我打的那句中英混打的诗？它凭什么知道该怎么解释递归？

## 2

周末被作业和各种琐事占得满满当当，周一又从早到晚连着在几个教室之间赶场。

等到了周二晚上，寝室里总算清净了一点。

室友端着脸盆去水房洗衣服，走廊里飘着洗衣粉的柠檬香。我坐在书桌前，合上数据结构课本，按了下鼠标唤醒休眠的拯救者。

屏幕亮起来，Chrome 依然停在周五那天留下的状态。

书签栏最显眼的位置挂着那个 GenChat 的图标，旁边还有好几个没关掉的英文网页。中间有一条我几天前随手留在历史记录里的论文预印本链接，我顺着点开看了一眼，页面跳出来的还是那篇白底黑字的 PDF 预览。

标题长得像绕口令，作者栏密密麻麻排了三十多号人。我试着读了两句摘要，又是「inductive bias」，又是「unsupervised pre-training objective」，往下稍微滚了一轮鼠标滑轮，满屏都是下标极其复杂的数学公式和多层方块图。

我看了不到一分钟，只觉得眼眶发胀，心里只有一个最直接的念头：

这什么东西，根本看不懂。

我抬手直接按了 Ctrl+W，把它从屏幕上彻底掐灭。去啃这种几十页的学术大部头纯属给自己找不痛快，大二的课已经够忙了，那些天书一样的公式推导看两行就让人犯困。

我切回其他的标签页，专挑那些标题看起来容易看懂的博客点：类似《GenChat explained for developers》或者《What is an instruction-tuned language model?》。

就着浏览器插件的划词翻译，我硬着头皮读完了两篇篇幅较短的开发者笔记。

文章里的很多概念依然模糊，但至少有一点我第一次对上了号——周五随手试的那个 GenChat，在他们专业的语境里属于一类叫「大语言模型」（Large Language Model）的东西。

按照博主的解释，这类模型是一套专门用来处理自然语言的计算程序。它先在海量的网页、书籍和代码上做预训练，学会了语言的规律；然后再经过一道叫「指令微调」的工序，学会听懂人类用自然语言下的指令。

我坐在椅子上琢磨了一会儿。

「预训练……就是把整个互联网的文字都喂给它看一遍？」

博主大概也没想到我会这么理解，但这个粗暴的类比居然差不离。

至于「指令微调」，博主解释得更通俗：就是拿大量人类写的指令和对应的理想回答去教它，让它学会「人类说人话，它也说人话」，而不是像以前的模型那样只会顺着你打的开头往下编。

我这才明白周五为什么会让我那么惊讶——你不用想办法「诱导」它，不用给个开头让它续，直接跟它说人话，它就照着做。

在一篇讨论规模的博客里，作者提到了 GenChat 的底座模型叫 Genesis-3，参数规模是 160B。我查了一下，B 是 billion，160B 就是 1600 亿。帖子里有人惊叹这是人类目前为止参数规模最大的模型之一。但这个所谓的「参数」到底是什么东西，博主没细讲，我也没概念，只记住了 1600 亿这个数字。

我切回那个 GenChat 的对话界面，重新打了一行字：

Can you write a simple C function that reverses a linked list?

它几乎立刻就回了：

Sure! Here's a simple C function to reverse a singly linked list:

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode *prev = NULL, *curr = head, *next = NULL;
    while (curr != NULL) {
        next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

This uses an iterative approach with three pointers. It traverses the list once, reversing the direction of each link. Time complexity is O(n), space is O(1).

我盯着那段代码看了几秒。

链表反转——这正是数据结构课上周刚讲过的内容。我自己写的时候绕了半天指针，还漏了个边界条件。它不仅一次写对了，还标了时间复杂度和空间复杂度。

我靠在椅背上，愣了半天。

这东西……是真能干活。

我又敲了一句：

Explain why the base case is needed in recursion. What happens if you don't have one?

它回了：

Without a base case, recursion is like a loop that never stops. The function will keep calling itself with smaller inputs until the program runs out of memory (stack overflow) and crashes. The base case is the "stop here" signal.

Think of it like Russian nesting dolls again: if there's no smallest solid doll to stop at, you'd keep opening dolls forever, getting smaller and smaller, until your hands give out.

我读完那段回复，心里那点困惑不但没解开，反而更深了。

它说得都对。它写的代码能跑。它解释的递归我一下就懂了。

可它到底是怎么做到的？

我顺着博客底下的链接，又点开了一篇标题叫《A Deep Dive into Transformer Architecture》的文章。

开头写着：

「The transformer architecture is based on self-attention...」

我查了下 Transformer，解释写着"一种基于自注意力机制的深度神经网络架构"。

行，神经网络。

我接着往下翻。

然而刚往下滚了一屏，网页里的画风就彻底变了。

正文里不再有通俗的解释，密密麻麻全是英文术语：

`high-dimensional matrix`（高维矩阵）
`vector representation`（向量表示）
`self-attention mechanism`（自注意力机制）
`token embedding space`（嵌入空间）
`softmax probability distribution`（概率分布）

生僻词汇中间夹杂着好几张复杂的结构图，再往下滚两屏，是一长串带有角标的偏微分符号与推导公式。

日光灯在头顶照着，风扇在机箱里微弱地转。

我盯着那一堆大写字母和希腊符号看了五分钟。

大二这一年多，高数和线代学了一些，但眼前这些高维矩阵和概率分布连起来，整整三屏数学符号，我脑子里除了一片空白，什么都没看懂。

刚才那点好奇心，在这些公式面前被彻底磨光了。

我看了五分钟。

又往下滚了两屏。

然后按下了 Ctrl+W。

那个满是矩阵和架构图的网页瞬间消失，退回了空白的浏览器主页。

我揉了揉眼睛。

折腾了一圈，我对这东西的理解其实依然极其粗糙：

它叫大语言模型。
它的底座叫 Genesis-3，有 1600 亿个不知道是什么玩意的参数。
它经过指令微调，所以能听懂人话。
我往里面打的字叫 prompt。

至于底层到底是怎么算出来的——完全不知道。

寝室门在这时候被推开了，室友端着洗干净的衣服走进来，搭在阳台的晾衣杆上。

另一个室友也合上了作业本，转头看向我：

「博哥，数据结构那道链表反转你写完了没？发我一下呗，指针怎么绕都绕不对。」

「写完了，等下微信发你。」我往旁边让了让椅子。

「谢了！」室友掏出手机点开《王者荣耀》，「对了，老周他们那帮人刚刚在群里吼，说今晚组内战差一个人，你来不来？赶紧上号，缺个打野。」

桌上的手机也震了一下，辅导员在群里发了明天上午一门专业课临时换教室的通知。

生活重新按部就班地铺了回来。

我看着屏幕上方仅剩的几个标签页。

我没有把它们全都关掉。我留下了那个 GenChat 的对话页面，把它静静地挂在书签栏的最左侧。

我不知道自己以后还会不会再用到它，更没觉得自己一个航海学院的大二学生能跟这种复杂的计算机技术扯上什么长远的交集。

但至少，那行书签留在那儿。

我关掉了网页，起身去饮水机接了半杯温水，走回桌前，拿起手机横了过来，点开《王者荣耀》：

「来了，拉我进房间。」

## 3

又过了两天。

周四晚上，数据结构作业总算赶在晚自习前交了上去，整个寝室难得空闲下来。

老周穿着塑料凉拖窝在椅子里刷短视频，手机喇叭里外放着笑声；对面的小陈刚洗完头，搭着毛巾等游戏更新；斜对角的室友戴着耳机看论坛。

我坐在自己的拯救者前，屏幕右上角开着 Chrome。书签栏最左侧，GenChat 的小图标一直挂在那儿。

从周二晚上被那几屏高维矩阵劝退之后，这两天我一次也没点进去过。大二的连轴转作业很容易把好奇心冲淡，但那个对话框，还有它写出来的链表反转代码，一直像个没解开的疙瘩悬在脑子里。

我握着鼠标，顺手点开了那个书签。

GenChat 的对话页面弹了出来，干净的对话框，光标一闪一闪。

我盯着输入框看了几秒，忽然有点按捺不住。在网上发现了个怪软件，憋了好几天，身边坐着天天开黑的室友，想显摆新玩具的心态一旦冒头，很难压回去。

我把椅子往后退了退，转头拍了拍小陈的桌角：“哎，给你们看个东西。”

老周刷视频的手指顿了顿：“哪儿又有加速器免费兑换码了？”

“国外刚出的一个网站，挺怪的。”我把屏幕偏过去。

小陈探头瞅了两眼：“一个对话框？这不就是在线客服吗？”

“叫 GenChat，好像是个大语言模型。”话一出口，我自己都觉得干瘪，“你在里面说人话，它能听懂，还能接你的话。”

老周按灭手机嗤笑了一声：“一堆代码连脑子都没有，凭什么能听懂？”

“不信是吧？”我被他这一笑激得有点来劲。

现场拿什么演示？寝室微信群刚才的提示音在脑子里闪了一下，八点多老周和小陈在群里因为谁先上号扯皮了好几句。那种每天在宿舍上演的废话，格式再简单不过。

我在输入框里敲下提示词，把宿舍群聊喂了进去：

老周：今晚开不开？
小陈：等我洗完澡
老周：你每次都说洗澡
小陈：五分钟五分钟
老周：

按下回车。

不到一秒钟，对话框里它的回复气泡就冒了出来：

你上次那个五分钟我等了半小时

老周整个人猛地往前一凑，眼睛瞪大：“卧槽？！”

老周拍着大腿大喊：“神了！这玩意儿怎么知道我上周等了小陈半小时？！博哥，你提前把聊天记录粘进去了？！”

小陈也愣了：“你就打了上面那几行？它怎么知道老周要怼我半小时？”

看着他们一脸意外，我心里憋了几天的沉闷总算舒展了一点。

可在那一瞬间，我的思绪和他们完全不在一个频道上。他们惊奇的是这句话有多像老周平时的口吻，而我盯着那行字，后背微微发凉。我没有解释“五分钟”在宿舍里通常是托词，它自己抓住了那种推拉与嘲弄的语气。

“有点东西啊！”小陈彻底来了兴致，整个人趴到桌沿上，“再整一个！”

老周一把挤开小陈抢过键盘：“写老周打排位诸葛亮 2-8-1 甩锅，看它怎么编！”

敲完按回车，不到一秒，屏幕吐出一行字：

打野一次中路都没来过，对面打野几乎住在了中路，而且对面中单跟开了透视一样，下路送得太快根本带不动，建议查一下队友的账号。

寝室里瞬间爆发出一阵大笑。小陈笑得直拍桌子：“绝了！老周这就是你上周输了的原话吧，连标点符号都一样！”

短短两分钟，这个我想不透的技术迷局，极其自然地成了大二男生宿舍今晚最大的消遣玩具。

玩了几轮段子，老周忽然抓了抓头：“博哥，这玩意儿能做题不？把今天数据结构留的证明题输进去试试呗？”

“对啊！要是能把题目写对，以后还抄什么作业！”小陈也来了精神。

我顺手翻开桌角的数据结构课本，把递归正确性数学归纳法证明的题干敲进了输入框，按下回车。

大家齐刷刷盯着屏幕。

两秒后回复冒了出来，第一段写得有模有样。然而第二段画风急转直下，第三行莫名引入了三维坐标系与偏导数符号，最后两行更是彻底放弃了数学符号，煞有介事地总结道：

由此可见，递归的正确性在逻辑上体现了事物量变引起质变的辩证统一规律，在工程实践中具有极其深远的哲学意义，故命题得证。

空气安静了一瞬。

小陈伸长脖子，期待全垮了：“这特么都哪儿跟哪儿啊？证明题最后还能扯出辩证法来？”

老周也撇嘴挥手：“扯淡，步骤全是错的，抄上去明天非被老师挂黑板不可。行了别看了，赶紧上号开黑，今晚看我诸葛亮杀穿对面。”

“来了，等我两分钟去水房冲把脸。”小陈端起脸盆趿拉着拖鞋出去，戴耳机的室友也转回了身。

挤得水泄不通的书桌周围，转眼间散得干干净净。发现它不能应付现实的课业，短暂的好奇心在几分钟内蒸发殆尽，大家立刻回到了原本的轨道——洗澡、打游戏。

日光灯在桌面上照出一片亮斑。

我一个人坐在拯救者前，屏幕上还挂着那段滑稽的“辩证统一规律”。

老周他们觉得它只是个写段子的玩具，编瞎话翻了车就毫无用处。可我盯着那个输入框，自始至终在意的那个结根本没有解开。

最让我心惊的，自始至终都是它在面对无规则日常语言时的接续能力。我明明什么都没教给它，它却知道顺着语境走。

“博哥！发什么愣呢？”老周的大嗓门隔着桌子砸过来，“四缺一就差你了，选个打野带飞！”

“来了。”

我应了一声，握着鼠标的手指在触控板上停顿了一秒。我没有关掉网页，而是顺手按下了最小化，把对话框压进了任务栏底端。

我拿起手机横了过来，点开《王者荣耀》。在跳入组队界面的一瞬，我的目光还是不由自主往电脑屏幕左上角扫了一眼。

室友们的兴致已经散了，但那个 GenChat 的图标还在那儿，悬在心里的问号也依旧没有消失。

## 4

周日晚上，宿舍楼走廊里的脚步声密了起来。

周一第一节是《数据结构》，要求今晚十点前在学院 OJ 上交完实验作业。

拯救者的风扇低沉嗡鸣，屏幕左边是灰蓝色的 OJ 页面，右边开着 VS Code。五道题的前三道我没费多少工夫就写完了，在本地编译跑通提交，整齐挂着三行绿色的「Accepted」。

但到了第四题，进度卡死了。

题目叫「消除相邻重复并计算交替差值」。要求读入一个整数序列，把连续出现的相同数字缩减为一个，再依次做奇偶项的交替加减，输出累加和。

知识点全在循环和数组的基础范围里，但它偏偏需要多绕一层：既要记录相邻重复，又要防止索引越界，还要在交替求和时对奇偶项做符号翻转。我在草稿纸上画满了方格，在 VS Code 里写了一个带标记变量的双重 `for` 循环。本地跑样例明明是对的，一交上去，页面刷出来的就是一片深红：

「Wrong Answer」
「测试点 1：通过」
「测试点 2：通过」
「测试点 3：答案错误」
「测试点 4：答案错误」

我改了终止条件，换了符号初值，反复提交了三次，依然是刺眼的「Wrong Answer」。

后背有些发僵，我往后靠在椅背上喝水。老周正横着手机喊“拉扯一下看暴君”，小陈在门后晾鞋。在 OJ 上被各种边界坑折磨得焦头烂额是工科生的日常。

我切回浏览器打算在 CSDN 搜遍历思路，按下 `Ctrl+T` 时，目光扫到了书签栏最左侧——那个 GenChat 的图标安静地挂在第一位。

周四晚上的吵闹仿佛还在耳边。大家拿它接梗、编段子、最后因为算法证明胡扯一哄而散。

我看着图标，脑子里忽然冒出一个念头：既然它能接人话、能写链表反转，那代码呢？这道题卡了一个多小时，它能不能帮上忙？

这不是什么深思熟虑，纯粹是一个卡在作业里的工科生在连续吃红字后的试探。

我点开书签，把 OJ 上的中文题目描述整段贴进输入框，接着把自己写到一半、悬在空花括号里的代码也贴了上去。我没写任何多余解释，按下了回车。

屏幕光标闪动，回复气泡开始一行行往下吐代码。

它顺着我空落落的花括号缩进四个空格，声明了去重计数器，敲出一个极干净的循环和判定条件。处理完去重，它另起一行定义累加变量，用一个简洁的 `sign = -sign`，直接代替了我在草稿纸上算不清的奇偶项索引判断。末尾补齐 `printf` 和花括号，跳动停住了。

一套严整、规范、连缩进都挑不出毛病的代码横陈在眼前。

我愣了几秒。这代码语法我全学过，但思路和我完全不同：我满脑子想着怎么在原数组里反复标记删除，它却用了一个临时数组做顺序接收，并在遍历中顺手处理符号翻转，干脆利落。

能写出来是一回事，能不能跑是另一回事。我全选复制，贴回 VS Code，按下 F5。

编译通过，控制台弹出。我把样例输入粘进去按回车，下一行干脆地吐出了 `-1`，与题目样例分毫不差。

我搓了搓鼠标。大二刷 OJ 谁都遇到过“样例全过、一交全崩”，后台测试用例专门塞满了各种刁钻边界。

我切回浏览器，把代码贴进 OJ 提交框，按下绿色的「提交代码」。

页面跳转，状态栏跳出灰色沙漏：「Pending...」。手心居然微微冒汗。

三秒后页面刷新。深红色的警告没有出现，取而代之的是一行纯正扎眼的绿色英文字符：

「Accepted」
「测试点通过：5 / 5」

满分。

我僵在转椅上，双手甚至忘了离开键盘。

走廊里有人哼着歌走过，身后的老周还在戴着耳机大声报点，小陈靠在床头刷短视频。没有任何人注意到这一幕。

但我只觉得太阳穴在突突直跳。

这和周四晚上完全是两码事。在宿舍群聊里接梗，像与不像全凭主观感受；可眼前的「Accepted」，来自学校服务器里那套冷冰冰、不讲情面的自动判题机。

评测系统把代码扔进隔离沙盒，用五个隐蔽的测试用例轮番喂进去，逐字节比对输出。

代码把题做对了。实打实把一道大二工科题目的全部分数拿了下来。

一股混杂着难以置信的兴奋感猛地冲了上来。我几乎没有停顿，顺手在题库里点开了压轴的第五题。

## 5

第五题是这次作业的压轴，叫「寻找单峰序列极值并计算偏离度」。要求在乱序输入的数组里找出是否存在唯一的局域极大值点，如果存在，还要同时输出该极大值与所有非峰值元素均值的绝对偏差，如果不存在则输出特定错误码。

这道题我在上周课上就听课代表抱怨过，说坑极多，很多人都卡在全降序或者多峰并列的边界情况上。

放在五分钟前，我肯定会老老实实掏出草稿纸从头推演。但此时此刻，刚才那记「Accepted」带来的冲击完全把我的耐心冲散了。

我切回 GenChat 的对话框，把第五题的整段题目复制下来，直接贴了上去。

随后，我在下面敲了三行最基本的框架：

`#include <stdio.h>`
`#include <math.h>`
`int main() {`

我甚至连输入循环都没写，直接把半截框架和整段题目扔在那里，再次按下了回车。

它的回复气泡立刻开始一行行往外吐代码。

和刚才一模一样，代码以惊人的平稳节奏一行行往下吐。定义变量、处理多重分支、寻找峰值下标、累加非峰值和、计算浮点绝对值。

不到二十秒，一段长达四十多行的 C 代码再次工整地出现在对话框里。

我立刻全选复制，贴回 VS Code。

按下 F5。

编译顺利通过。我把第五题的样例数据复制进去按回车，控制台输出的数字也和样例一字不差。

我几乎没有仔细看它到底写了什么逻辑，刚才的成功让我产生了一种近乎荒谬的信任。我直接切回 OJ 页面，把代码贴进提交框，再次按下了提交。

页面跳回列表。

沙漏图标转动，「Pending...」。

我盯着屏幕，心跳快得厉害。

两秒后，页面刷新。

然而，屏幕上并没有跳出想象中的那一抹绿色。

状态栏刷出来的，是一行鲜红且刺目的字样：

「Wrong Answer」
「测试点 1：通过」
「测试点 2：答案错误」
「测试点 3：答案错误」
「测试点 4：答案错误」
「测试点 5：运行超时」

我愣住了。

像是一盆凉水当头浇了下来，刚才那一股子燥热的兴奋劲瞬间退下去大半。

「怎么会错？」

我皱了皱眉头，切回 GenChat 的对话框，在输入框里敲：

That didn't work. Can you try again? Check for edge cases.

对话框里它的回复气泡又吐了一段新代码。

但我只看了两行就察觉到了不对劲。

这一次，它不知道为什么突然在循环外部多声明了三个根本没用到的浮点变量，而在寻找峰值的判断里，原本用来比较相邻元素大小的条件，竟然被它莫名其妙写成了两个一模一样的逻辑与。

我把第一份生成的代码切回 VS Code，耐着性子从头到尾一行行手动往下捋。

在翻到核心循环的那一段时，我手里的鼠标突然停住了。

我盯着第十八行看了一眼，随即抬手按住了额头。

它在找峰值的时候，初始极大值直接随手赋了一个 `max_val = 0;`。

可题目第一行的输入范围明明写得清清楚楚：输入的整数取值范围是 `-10000` 到 `10000`。如果输入的测试数据全是负数，它那个判定极大值的条件从头到尾根本就一次都进不去。

不仅如此，在计算均值除法的时候，它连分母是不是零都没做任何校验，直接拿元素总数硬除。

这根本不是什么高深的逻辑漏洞。

这是任何一个学生在写前两周作业时，稍微动动脑子就能避开的最低级失误。

刚才还看似无所不能的「代码高手」，在一道稍微需要兼顾负数范围和边界除零的题目面前，立刻漏洞百出得像个刚学会敲键盘的马虎鬼。

我靠在椅子上，长长舒了一口气。

宿舍走廊外的说话声清晰地落进耳朵里。寝室里老周赢了一局排位，正乐呵呵地跟小陈商量等会儿要不要去楼下自动贩卖机买瓶红茶。

现实的生活没有半点偏移。

我看着对话框里那两份漏洞百出的代码，又看了看旁边空白的 VS Code 编辑区。

我没有去翻任何网上的技术资料，更没有产生半点「我要去弄懂代码生成模型底层原理」的冲动。

我只是默默关掉了 GenChat 的标签页，重新抽出一张干净的草稿纸，拿起圆珠笔，把第五题的边界情况一项一项老老实实列在了纸上。

等我终于靠自己的逻辑把第五题改完并在 OJ 上拿到「Accepted」的时候，时间已经快到晚上十点半了。

宿舍楼的熄灯铃响了起来。

我合上拯救者的屏幕，拔掉电源线，端着脸盆去水房洗漱。

水龙头里流出的凉水浇在脸上，让人清醒了不少。

我擦着脸走回寝室，重新躺到床上。

天花板上一片昏暗，下铺的老周还在就着微弱的手机屏幕光刷帖子。

我闭上眼睛，脑子里却反反复复还是刚才屏幕上的那一幕。

在今晚之前，那个 GenChat 的对话框在我眼里只是个新奇的谈资，一个很会顺着人话逗闷子、偶尔能逗大家笑一笑的怪异网站。

但今晚之后，某些东西切切实实变了。

它第一次以一种不可辩驳的客观事实证明了：在某些时刻，它真的可以跨过那些玩笑，把一件真实的、具体的工科作业做出来。

可随之而来的，是那个扎得更深的结。

第一道题它明明能写出那么漂亮干净的循环，拿到满分 Accepted；为什么到了第二道题，它又会犯那种连负数都没考虑到的弱智错误？

它在敲下那些代码的时候，到底知不知道那些符号代表着什么？

它到底……会不会写代码？

窗外终南山方向刮来的夜风吹得窗框轻轻晃了一下。

我在被窝里翻了个身，带着这个解不开的疑问，慢慢沉入了梦乡。

## 6

做完那次实验作业后，GenChat 稳稳落在了我浏览器的书签栏最左侧。

我没有天天泡在里面，大二的课业被早八、实验和写不完的作业塞得满满当当。它变成了我抽屉里一把偶尔拽出来的瑞士军刀：写英语练习时用它润色生硬的长句，写 Matlab 实验时用它补齐画图脚本的边角料。

在一次次随手使用里，我摸索出了一点朴素的手感。这东西的脾气很怪：如果只是含糊地让它“写个滤波脚本”，它给出的东西往往错漏百出；但只要把上下文铺得极细，把参数边界写死、在前面附上两个规范的输入输出示例，它顺着逻辑接出来的代码质量就会高得惊人。

那时候我不知道学术界管这叫提示词工程，我脑子里只有工科生最直白的体会：它像个聪明但不靠谱的学长，给足规矩和例子他就能干活，话没说明白他就自己瞎编。

十一月底一过，终南山落下了第一场雪。

秦岭的冷风倒灌进长安校区，东大镇的柏油路上寒风刺骨。大学生活真正吃劲的一面在入冬后砸了下来：概率统计的假设检验、数据结构的图论遍历、航海大类的专业硬件实验连轴转。

寝室里开黑的声音少了大半。老周期中测验没及格，每天裹着黑羽绒服抓着我死磕习题集。晚上九点半自习归来，四个人围着电热水壶泡老坛酸菜面，就着热气腾腾的酸辣汤吸溜吸溜地吃。在那段被作业、实验与寒风填满的日子里，GenChat 安静地悬在书签栏，有时候连着几天我都不会点开一次。眼前的期末绩点才是现实，没人会把未知的网页当饭吃。

直到十二月中旬的一个深夜。

我刚写完实验报告，寝室早已熄灯，台灯下我习惯性地唤醒电脑摸进 Twitter。

屏幕上的英文动态快速滚动，一条独立研究员的推文让我指尖猛地停住：

“上周在 GenChat 和另一个模型上跑了相同的提示词。GenChat 依然占优，但差距缩小的速度远超预期。那个新模型你们很快就会听到。”

另一个模型？

我把手悬在触控板上，脑子里泛起一股奇特的陌生感。在此之前，我一直默认这个能对话写代码的黑盒是 OpenMind 的独门绝技。而这条推文却白纸黑字地暗示：地平线另一端，已经有第二架飞机准备起飞。

我顺着转评看下去，开发者们已经在隐隐讨论竞争格局。

我坐在微凉的桌前，心底掠过一个清晰的念头：大语言模型绝不是某家公司偶然捣鼓出的玩具，这扇被撞开的缝隙背后，全球的顶尖团队都在往里涌。它正在变成一条破晓的战线。

换作旁人，或许只是把这当成遥远的科技新闻扫一眼。但我做不到。只要它公开上线，我必须亲手把它敲进自己的电脑里试一次。

我手里没有学术界的标准跑分库，但我有三道最熟悉的题：那道曾经卡住我的去重数组累加题、十一月底试探它的中英写诗翻译、以及逗乐室友的宿舍群聊接梗。

这三道题在 GenChat 上已经跑透了。接话像不像人、写代码能不能过样例、复杂上下文会不会错乱，我心里早有一本账。

任何新模型跳出来，我都得拿它比一比。

不知不觉中，GenChat 已经成了我衡量后来者的那把尺子。

## 7

十二月中旬的一个周六深夜。

西安飘了一整天的小雪，宿舍楼下冬青树叶上积了薄薄一层白霜。

我刚在书桌前把概率统计习题集翻到最后一页，准备关机上床。

在关掉 Chrome 之前，我习惯性地切回 Twitter 主页做最后一次刷新。

信息流顶部刷出来的第一条动态，赫然挂着一个我从未见过的名字。

发帖的不是 OpenMind。

那条动态发布于半小时前。

发帖的是一个叫 Sapient 的账号。头像是一个极简的盾形图案，底下的正文只有极短的三行英文：

「We're Sapient.」
「Our first model is Sage.」
「It's as capable as the best, but it won't make things up.」
（我们是 Sapient。我们的第一个模型叫 Sage。它和最好的模型一样能干，但它不会胡说八道。）

短短半小时，动态底下的转评数量已经破了千。

那些平时极具权威感、在各个学术圈和硅谷大厂发声的资深工程师、知名实验室首席架构师，此刻全毫无架子地挤在评论区的前排，留着自己的开发者账号，急切地索要测试邀请码。

那种热度与声浪，比几周前 GenChat 刚上线时，喧嚣了何止十倍。

我坐在微凉的桌前，盯着屏幕上那条短短三行的动态。

窗外终南山方向的夜风呜呜地掠过屋檐。

在这一瞬间，几个月前那个刚刚在宿舍里配通网络工具、面对一个对话框抓耳挠腮不知所措的大二学生，仿佛在不知不觉中被时间推到了一个极其微妙的节点上。

我没有像最初那样茫然地问「这是个什么怪网站」。

也没有像室友那样觉得这只是个无足轻重的逗乐玩具。

我握着鼠标，看着那行「It won't make things up」，心底缓缓升起、并且清晰定格在脑海里的，只剩下了极其纯粹的一句话：

「它这次……又做到什么了？」

## 8

我点开了 Sapient 主页上的注册链接。

本以为又要排队等内测邮件，页面跳转出来却直接是一个干净的输入框，注册即送额度，和两周前 GenChat 的路径一模一样。

我敲了一句最标准的英文问候。

屏幕上的回复气泡弹得极快：“Hi, I'm Sage, made by Sapient. I can help answer questions, write code, explain concepts, and more. If I'm not sure about something, I'll tell you.”

没有 GenChat 那种热情的反问，结尾直接补了一句“不确定就说不知道”。

像是换了一个严肃的说话对象。

我把同一道链表反转的题目喂给它。代码很快吐了出来，变量名和 GenChat 几乎一致，但它每一行都加了克制的单行注释，末尾附上了精确的时间与空间复杂度，全篇没有一个感叹号。

两个标签页并排挂在屏幕上。左边是 OpenMind 的 GenChat，右边是 Sapient 的 Sage。

一个像跟你混熟了的学长，说话随便、反应极快，但偶尔会吹过头；另一个像实验室里做事一丝不苟的助教，每句话都严丝合缝，但一板一眼得有些死板。

第二天清晨，长安校区的雪下得更大了。

教学楼自习室的暖气烧得很足，玻璃窗上蒙着一层水雾。期末考试周正式砸了下来，概率统计、数据结构、Matlab 实验排得极满。

老周缩在角落里背假设检验，咬着笔头一脸痛苦：“博哥，第七题的 p 值我怎么算老差个根号二？”

“你显著性水平取错了，应该是 0.05 不是 0.5。”我抽过他的草稿纸点了点。

老周懊恼地抓头：“操，我这脑子真记不住。”

吃完饭回自习室，我把 Matlab 的实验大作业翻开，屏幕上开着两个对话框。我把一道 FFT 频谱分析题目贴给两个模型。

GenChat 三秒钟吐出一套最精炼的代码，运行直接出图，严丝合缝；Sage 则慢了两秒，附带了完整的坐标轴标签、采样定理注解和单边谱换算说明。

两边都能跑通。

没有哪个绝对更强，只是路数完全不同。写代码图快找 GenChat，推导严谨找 Sage；翻译要自然找 GenChat，要教科书般的正式找 Sage。

几周前我还在为“这东西到底是什么”抓耳挠腮，现在我已经在琢磨“哪个该干什么活”了。

数据结构考完那天晚上，寝室里难得安静。老周对完答案一头栽倒在床上，嘟囔了一句“不想说话”便沉沉睡去。

我坐在书桌前合上复习提纲。双肩包已经塞满了换洗衣物，明天考完最后一门，就可以直接去高铁站。

窗外终南山黑得发沉，大雪悄无声息地覆在窗框上。

屏幕上只剩两个对话框亮着。左边是 GenChat，右边是 Sage。

书签栏里，两个图标并排挂在最左侧。

几周前我还以为这只是一个偶然闯入生活的新奇玩具。现在全世界顶尖的团队都在往这条赛道里冲，而我手里刚刚握住了两把方向各异的尺子。

我合上电脑。明天考完试，寒假就要开始了。

## 9

Matlab 考试比预想中顺利。最后一门考完那天下午，我直接拖着行李去了高铁站。西安的冬天干冷，候车室里暖气烘得人发困，旁边几个学生模样的人在聊回家的票。我靠在椅背上刷了会儿 Twitter，看到 GenChat 又上了一次趋势。

#GenChatDown 的标签飘在首页。点进去，全是在吐槽服务器崩了的：

「Is it just me or is it taking forever to load today?」
「Same here. Been waiting three minutes.」
「OpenMind, please buy more servers.」

我试了一下，确实慢。对话框加载了五秒才出来，打字的时候还有点卡顿。上学期用的时候从来没这样过，看来用户量涨得确实太快了。

高铁开了五个多小时，到家门口的时候已经是晚上七点。我妈开门的时候手里还拿着锅铲，看了我一眼说「又瘦了」，然后把我拽进厨房吃了一碗热汤面。我爸在客厅看电视，新闻联播的声音从门缝里钻进来。

寒假就这么开始了。

我自己的房间还是走之前的样子，书桌上摊着上学期的课本，窗台上落了一层薄灰。我把笔记本放在桌上，连了 Wi-Fi，打开 GenChat。加载了快十秒——家里的网络确实比学校慢得多——然后对话框弹出来，光标一闪一闪。

我随便敲了一句：

Hello, write me a haiku about winter in China.

它几乎立刻就回了：

Cold wind through bare branches,
Snow falls on silent rooftops,
Steam rises from bowls.

我看着那三行英文，笑了一下。还是老样子，会写，但没什么深度。

寒假的日子过得很快。

我没有认真研究怎么用 GenChat 或者 Sage，就是每天偶尔打开，想到什么问什么。有时候是让它帮我翻译一段英语课本里的长句，有时候是让它写个 Matlab 的小脚本做作业，有时候纯粹是闲着没事跟它闲聊——问它天气怎么样、推荐一部电影、或者让它写一段吐槽老板的段子。

我妈推门进来送水果的时候，看了一眼我的屏幕，问我「你在跟谁聊天」。我说是一个 AI，她哦了一声，把水果放下就出去了。她显然没听懂这是什么，但也没追问。

Twitter 上倒是热闹。

GenChat 的用户量像是坐了火箭。每天刷首页，至少能看到三条关于它的动态：

「Used GenChat to write my entire lab report. Don't tell the prof.」
「GenChat suggested I change my major. I think it's right.」
「OpenMind just announced they're hiring 200 more engineers.」

中文科技媒体也开始大规模报道了。知乎上突然涌出一堆科普文章，标题一个比一个夸张：

「这个 AI 会聊天，人类要完蛋？」
「GenChat 深度评测：它真的理解我们说的话吗？」
「大学生用 GenChat 写论文，导师看哭了」

我刷到这些的时候，只是笑了笑。几周前我还是第一个发现这东西的人，现在全世界都知道了。那种"我比所有人都先知道"的感觉，淡了不少。

Sage 也在更新。Sapient 偶尔发个动态，说模型又微调了一版，更少胡说了。我试了一下，确实——以前问它不知道的东西，它还会硬编一个答案；现在它会老老实实说「I'm not sure about that」。但有时候也变得更死板了，让它写个段子，它会先分析「这个话题可能不合适」，然后才小心翼翼地写出来。

我没太在意。寒假嘛，就是玩。

春节前后家里忙得很。

走亲戚、拜年、被问期末考试考了多少分、有没有找女朋友、毕业后打算干什么。我妈在旁边打圆场，说「孩子刚上大二，不急」。我爸倒是不问这些，只是看了一眼我的成绩单，说「还行」。

大年初三那天，我躲在自己房间里刷 Twitter，刷到一条 Sapient 的动态：

「Sage just got a small update. Longer context window. Try it out.」

我试了一下，确实——以前对话超过十几轮就开始忘前面说了什么，现在能聊更久了。但也就那样。

正月十五过后，离开学还有一周。我开始收拾行李，把换洗衣服叠进背包，把上学期的课本塞进书包。

那天晚上刷 Twitter，首页突然被一条新动态刷屏。不是 OpenMind，不是 Sapient，是 Helix。那个我用了好几年的搜索引擎。

它发了一条动态，配文只有一行：

「We've been working on something. Meet Hermes-1.」

底下附了一个链接。我点开，跳出来的页面是 Helix 的搜索主站——但搜索框下面多了一行小字：

「Ask Hermes anything.」

我愣了一下。Helix 做了大模型？

往下翻，页面上写着 Hermes-1 的介绍。三个档位：

**Hermes-1 Epigram** — 最小最快。
**Hermes-1 Ode** — 中等，均衡。
**Hermes-1 Epic** — 旗舰，最强最大。

我盯着那三个名字看了几秒。Epigram、Ode、Epic，三种诗歌体裁，和我之前用的 GenChat、Sage 完全不是一个路数。

我试了一下，默认用的是 Ode。往对话框里敲：

Hello, who are you?

它的回复比 GenChat 短，比 Sage 更正式：

I'm Hermes, made by Helix. I can help you find information, answer questions, and more.

没有感叹号，没有多余的寒暄，像是搜索引擎突然长出了一张嘴。

我又试了一句：

What's the weather like in Xi'an today?

它回了：

Xi'an weather on February 5: partly cloudy, high 6°C, low -2°C. Light breeze from northwest.

直接甩了个数字，没有解释，没有寒暄。

我靠在椅背上，看着屏幕。三周前我还觉得 GenChat 和 Sage 是全部，现在第三家来了。而且是 Helix——那个每天都在用的搜索引擎。它不是小实验室，不是创业公司，它是 Helix。

我盯着那个对话框，脑子里冒出来的不是「它行不行」，而是：

如果 Helix 都来了，那还有谁在后面？

## 10

回学校那天，高铁上坐了五个多小时。西安的冬天还没完全过去，出了高铁站，风一吹还是缩脖子。拖着行李箱进宿舍的时候，老周和小陈已经到了，桌上堆着寒假没吃完的零食袋。

「你怎么才到？」老周从上铺探出头，「食堂都开了，赶紧去吃饭。」

新学期课表贴在门后。有门新课叫《信号与系统》，老师第一节课就说期末要交一个大作业——选一个信号处理的小课题，从调研到实现，两个人一组，期末演示。

我和老周一组。

第一周没什么事，就是上课、记笔记、买饭。但我发现自己打开 GenChat 的次数比上学期多了。不是为了玩，是真的在用——写英语作业的时候让它帮我润色句子，写 Matlab 实验报告的时候让它帮我解释一段看不懂的代码。

小陈寒假回家的时候听高中同学说过 GenChat，说就是个能聊天的 AI，他试了一次，觉得没意思就没再用。老周更绝，说他刷到过别人发的截图，「就跟那种陪聊 App 似的，有啥好玩的」。

有天晚上小陈突然凑过来问我：「博哥，我寒假听同学说那个 GenChat 挺厉害的，怎么弄？我试了一下，网页根本打不开。」

「你得先科学上网。」我说。

「科学上网？」老周也凑过来，「就那种翻墙软件？我上次下了一个，用了两天就不能用了。」

我没理他，转头看着小陈：「你电脑呢？拿过来我给你弄。」

小陈把笔记本搬过来，我把自己的U盘插到他的电脑上，在他的电脑上安装了 Clash。

「这个软件装完之后，你得先填节点。」我一边操作一边给他讲，「我给你发个节点链接，你复制到这个框里，然后点连接。」

小陈捣鼓了半天，终于把软件连上了。我打开浏览器，输入 Helix 的网址，页面跳出来了。

「接下来注册个 Helix 账号。」我指着注册按钮，「别用国内手机号，用邮箱。QQ 邮箱就行。」

小陈按照我说的，填邮箱、设密码、收验证码。折腾了十分钟，终于把 Helix 账号注册好了。

「现在打开 GenChat 的网址。」我说，「点登录，选 Helix 登录，授权一下就行了。」

小陈点了一下，页面跳出来，授权确认，然后 GenChat 的对话框弹了出来。

「成了！」小陈拍了一下桌子，「我也能玩了！」

我笑了笑，没说什么。这些步骤我上学期刚发现 GenChat 那天晚上就摸熟了，现在讲起来倒是简单。

老周在旁边看得眼馋，也说要弄一个。我把压缩包发给他，让他自己照着小陈刚才的步骤弄。

Sage 也更新了。Sapient 发了个动态说升级到了 1.1，更长上下文、更少胡说。我试了一下，确实——以前问它不知道的东西，它还会硬编一个答案；现在它会老老实实说「I'm not sure about that」。但也变得更死板了，让它写个段子，它会先分析「这个话题可能不合适」，然后才小心翼翼地写出来。

Hermes-1 我也在用。默认用的是 Ode，有时候切到 Epic 试试。它和前两个完全不是一个路数——GenChat 像个聪明但爱吹牛的学长，Sage 像个一丝不苟的助教，Hermes 像个百科全书编辑。问它问题，它不会像 GenChat 那样跟你聊半天，而是直接甩事实、甩出处、甩链接。

真正让我开始认真比较这三个模型的，是信号与系统的第一次小作业。

老师让我们调研一种常见的滤波算法，写一份两页的报告。

我把题目分别丢给三个模型。

GenChat 的回答最均衡。它先解释了滤波算法的基本原理，然后举了个 Matlab 的例子，代码写得规规矩矩，注释也清楚。但它的解释有点泛泛而谈，像教材里的标准段落。

Sage-1.1 的回答更谨慎。它把原理拆成了三步，每一步都标了「假设」「因为」「所以」，逻辑链条完整得像论文。但它的回答太长了，两页纸根本写不下，而且太正式，不像学生写的。

Hermes-1 Epic 的回答完全不一样。它一上来就甩了三个参考文献链接，然后列出了不同滤波算法的对比表格——哪种在什么场景下用、优缺点是什么、最新的研究进展到哪一步了。它不是在"教我"，而是在"给我查资料"。

我盯着三个对话框看了半天。

这不是谁好谁坏的问题。

它们根本就是三种东西。

那天晚上，我没有急着写报告，而是先把三个模型的回答各自复制到一个文档里，然后开始想：这份报告到底该怎么写？

Hermes 帮我找到了最新的研究进展和参考文献。Sage 帮我把原理拆成了清晰的逻辑链条。GenChat 帮我把 Matlab 代码写出来，跑通。

我自己负责判断哪些内容是对的、哪些是错的，然后把它们整合到一起，改成自己的话。

这是我第一次有意识地把一个任务拆开，分给不同的模型去做。

以前我总觉得，哪个模型最好就用哪个。但现在我发现，根本没有"最好"这回事——只有"最合适"。

Hermes 查资料最快，Sage 解释最清楚，GenChat 写代码最顺手。

那为什么非要拿一个模型干所有事呢？

报告交上去那天，老师在课上念了几篇写得好的作业，其中就有我的。他说这份报告"调研扎实、逻辑清晰"，问我参考了哪些文献。

我报了几个名字——都是 Hermes 帮我找的。

下课后，老周凑过来问我：「你怎么找到那么多文献的？」

「用 Hermes 搜的。」我说，「它那个搜索功能比直接用 Helix 方便，直接给你甩文献。」

老周哦了一声，没再追问。

晚上回到宿舍，我把三个对话框并排开着。GenChat、Sage、Hermes，三个标签页整整齐齐地挂在屏幕上方。

我看着它们，脑子里突然冒出来一个念头：

别人还在 Twitter 上争论这三个模型谁更强。

但如果它们能自己互相配合呢？

Hermes 查资料，Sage 解释，GenChat 写代码，最后自己整合——这不是一个模型干所有事，而是三个模型组成一个团队。

我摇了摇头，觉得这个念头有点离谱。

但它确实冒出来了。

## 11

三月上旬，终南山脚下的风还刮得紧，天黑得明显比上学期晚了些。

《信号与系统》的大作业正式推进到第二阶段：任选一种滤波算法在 MATLAB 里完整实现，跑出幅频特性与相位曲线，并和经典窗函数做横向对比。期末占四成成绩，还要当堂抽人演示代码。

我和老周分在一组。老周对画图调参向来头疼，主动揽下了做演示 PPT 和排版的活。

周三下午没课，宿舍楼里很静。我盘腿坐在椅子上，拯救者的风扇压着低音运转，屏幕左边开着 MATLAB 编辑器，右边并排悬挂着三个标签页：GenChat、Sage 和 Hermes。

我先把选题定在 FIR 滤波器的窗函数设计。实验要求设计一个线性相位低通滤波器，通带截止频率设在 0.2$\pi$，阻带最小衰减必须压到 40 dB 以下。

我切到 GenChat 窗口，描述了设计指标。

几秒钟后，GenChat 吐出一套规范的流程，建议使用 Kaiser 窗调节旁瓣衰减，并在底下给了一段示例代码，直接把形状参数写成了 `beta = 5.0`。

我把代码复制进 MATLAB 按下 F5。绘图窗口弹了出来，蓝色的幅频特性曲线在坐标系里拉出一条下坠的折线，但在阻带区域的衰减仅仅停在 35 dB 左右，离要求的 40 dB 差了一截。

我把阻带衰减不达标的现象贴回 GenChat，它很快回了一大段客套的解释，在采样率和阶数公式上绕圈子，甚至建议我干脆把 $\beta$ 直接加到 8.0。

看着那段模棱两可的回复，我心里泛起了嘀咕。工科公式背后必然有确切的数值拟合关系，GenChat 写代码框架极快，但一碰到具体参数，就容易露出信口开河的毛病。

我切到 Hermes 标签页，直接询问 40 dB 阻带衰减下 Kaiser 窗 $\beta$ 的精确经验公式与经典教材出处。

Hermes 几乎瞬间给出了答案，排版利落：引述了奥本海姆经典教材《离散时间信号处理》第十章的分段公式。根据公式计算，阻带衰减在 21 到 50 dB 之间时，输入 40 dB 对应的 $\beta$ 理论值约为 3.4。

我把公式和 GenChat 建议的 5.0 顺手贴进 Sage 窗口做逻辑核验。

Sage 很快给出了条理分明的报告：证实奥本海姆的公式标准准确，40 dB 对应精确值 $\beta \approx 3.395$；如果误套用 50 dB 对应的 5.0 参数，会导致主瓣不合理展宽，过渡带超标且阻带波纹失衡。

整个链路在几分钟内彻底闭合了。

我切回 MATLAB，把参数改为 `beta = 3.4`，顺带修正阶数，再次按下 F5。

Figure 窗口陡然一闪，折线利落地跌穿水平虚线，阻带衰减稳稳停在 42.6 dB，通带波纹平整收拢在 0.5 dB 以内，完全达标。

我松开鼠标，往椅背上一靠。耗时不过十分钟，没有在论坛里盲目翻帖，也没有胡乱试数。

GenChat 负责搭起可运行的脚本框架，Hermes 负责下钻检索经典教材定位原始公式，Sage 负责代入推导、审查漏洞并解释机理，而我坐在屏幕前派发任务、裁定信息，把参数放回本地环境验证。

三个对话框并排挂着，俨然是一支在我手底下高效运转的微型技术小组。

老周抱着快递推门进来，凑过来看了一眼屏幕：“卧槽，博哥你这曲线调出来了？刚才看阻带还悬在半空呢，怎么弄的？”

我顺手最小化 MATLAB：“翻了翻奥本海姆那本教材，重新套公式改了个参数。”

老周一脸敬佩地抓头：“那本全英文砖头书你也啃得动……行，图发我微信，我插进 PPT 里。”

晚上十一点，宿舍按时熄灯。

我看着屏幕上并排的三个标签页。一个清晰的事实摆在眼前：今晚流畅的排错，本质上依然由我充当了数据中继站。我在手动复制公式、贴给推理模型验算、再搬回代码框架。

如果这些模型未来能互相感知、自动协同呢？

写代码的工具遇到参数疑义，自动触发检索模型翻阅文献，由推理模型完成逻辑审计，最后把修正后的代码直接交付给本地编译器。

在 2023 年初这个春寒料峭的夜晚，这个念头显得遥远而科幻。但我看着闪烁的光标，心里很清楚：有些关卡一旦被推开一条缝，就再也合不上了。

## 12

三月中旬，西安的风还带着点凉意，但校园里的玉兰已经开了。

我的日子过得很规律：早上八点去教室，中间插着课间操和食堂，下午泡图书馆，晚上回宿舍。三个浏览器标签页从早到晚挂着，GenChat、Sage、Hermes，切来切去已经成了肌肉记忆。

老周说我最近眼睛里只有屏幕，连开黑都心不在焉。小陈倒是经常凑过来问东问西，说我跟变了个人似的。

周三下午没课，我在宿舍赶信号与系统的大作业 PPT。小陈从隔壁窜过来，手里攥着笔记本，一脸愁容。

「博哥，帮我看看。」他把电脑往我桌上一放，「我这 Matlab 代码又报错了。」

我扫了一眼屏幕，红色的错误信息滚了好几屏。

「你自己试过 GenChat 没？」我问。

「试了啊。」小陈挠头，「我把报错贴进去，它给了我一大段解释，我照着改了，结果报了更多错。」

我笑了笑，把他的电脑拉过来。

「你把报错原文再贴一遍。」

小陈重新贴了一遍。我看了两秒，没直接复制给 GenChat，而是先问他：

「你这段代码想干什么？」

「就……就画个频谱图。」

「画什么信号的频谱图？采样率多少？你用的哪个函数？」

小陈愣了一下：「就……老师让画的那个，采样率 1000，用的 fft。」

我点点头，把他的报错原文、他想实现的功能、采样率、用的函数，全部整理成一段话，贴进 GenChat：

I'm trying to plot the FFT spectrum of a signal in MATLAB. My sampling rate is 1000 Hz. I'm using the fft function. But I'm getting this error: [粘贴报错]. What am I doing wrong?

GenChat 三秒就回了：

The error is because you're not using fftshift. After computing the FFT, you need to use fftshift to center the spectrum around zero frequency. Also, make sure your frequency axis is correctly scaled.

我把这段解释给小陈看：「你看，它说你没加 fftshift。」

小陈凑过来，一脸恍然大悟：「哦——原来还要加这个？我之前直接问它为什么报错，它给我扯了一堆采样定理的废话。」

「你直接贴报错，它不知道你想干什么，当然瞎猜。」我说，「你得把目标、参数、用的函数都告诉它，它才能给你准话。」

小陈哦了一声，把这段话抄在笔记本上。

「对了，」他忽然抬头，「你平时用 GenChat、Sage、Hermes，这三个到底有啥区别？」

我来了点兴致，把三个标签页切出来给他看。

「GenChat 最均衡，写代码、改句子都顺手，但有时候会胡说。Sage 更谨慎，解释原理特别清楚，但太死板。Hermes 是 Helix 做的，查资料、找文献最快，直接甩链接给你。」

「那你平时怎么组合着用？」小陈追问。

我顿了一下。

「就……哪个好用用哪个呗。」我说，「查资料用 Hermes，解释用 Sage，写代码用 GenChat。」

「那你能不能给我看看你平时怎么问的？」小陈眼睛亮了，「你刚才那段话写得特别清楚，我照着学。」

我笑了笑，把刚才那段提示词复制给他：「就这个，你照着写就行。」

「就这？」小陈有点失望，「我还以为有什么秘籍呢。」

「真没有，就是把问题说清楚。」我耸耸肩，「多试几次就熟了。」

小陈半信半疑地回去了。

过了两天，他又窜过来，一脸哭笑不得。

「博哥，你是不是还有东西没教我？」

「怎么了？」

「我照着你那段话写了，结果 GenChat 给我的代码还是跑不通。」小陈把电脑递过来，「它说什么参数不对，我照着改了，结果又报了新错。」

我看了一眼他的代码，确实——他把提示词改了改，但没把上下文补全，GenChat 给的参数是错的。

「你这个参数不对。」我指着屏幕，「采样率和你之前说的不一样。」

「啊？」小陈愣住，「我改了采样率，忘了改提示词里的了？」

「对。」我笑了笑，「你得把所有上下文都告诉它，不能只改一半。」

小陈哦了一声，似懂非懂地点点头。

晚上十一点，宿舍熄了灯。

我坐在桌前，看着小陈刚才坐过的椅子。

其实我刚才说的都是实话——把问题说清楚、把上下文补全——这些确实是对的。但我没告诉他的是：我还会把 Hermes 查到的文献贴给 Sage 验证，把 Sage 验证过的结论再贴给 GenChat 写代码，跑出来的结果不对，再把报错贴回去。

这套流程是我花了好几个月，踩了无数坑才摸出来的。告诉小陈"把问题说清楚"，他能入门。但要让他达到我这个水平，光靠这几句话不够。

我不是故意不教他。只是这些细节，我自己也是慢慢才摸出来的，一时半会儿也讲不清楚。或者说——我下意识地觉得，这是我自己花了好几个月才攒下来的东西，没必要全倒出来。

手机震了一下。

我看了一眼，没回。

窗外的夜色很深，三个标签页在屏幕上静静挂着。

我已经习惯了。

## 13

四月初，长安校区的杨树开始抽芽。

班级群里转发了教务处的通知：校内数学建模选拔赛周三晚开赛，自由组队，每队上限三人，赛期三天三夜。往年这个比赛在西工大很有分量，拿个省奖在保研测评里都能加上扎实的分数。

通知刚发出来，老周就趴在床架栏杆上嚼着辣条往我这边看：“博哥，建模你报不？咱俩再拉上小陈，正好凑三个人。代码你来扛，我和小陈搜文献排版，省得一个人猝死在机房。”

小陈在下铺赶紧摆手：“别拉我，大二作业堆成山了，去年我组过一次，光是选 A 题还是 B 题就吵了一整夜，最后写论文的学长中途撂挑子，吐了两天苦水。”

我转着笔，看着屏幕。如果放在大一，我肯定会组队。传统组队往往伴随着无休止的催进度、口径对不齐和论文前后割裂，大部分精力都耗在沟通内耗上。

但现在的书桌上，我日常挂着三个大模型窗口。前几天《信号与系统》大作业，别人三个人折腾了一周，我靠着 Hermes 检索、Sage 梳理推导、GenChat 写代码，一个人几个小时就跑通了滤波算法仿真。

那种把所有上下文和进度完全攥在自己手里的感觉，顺手得让人上瘾。

那天晚自习，我用去年的校赛旧题——一道冷链物流调度优化做了测试。Hermes 抓文献，Sage 列目标函数逻辑，GenChat 搭建求解框架。不到四个小时，终端输出了收敛解集，散点分布图干净利落。

专业壁垒在模型面前仿佛缩成了一条细缝，我觉得三个人做的事，一个人完全能扛下来。

第二天中午，我在报名系统的队长栏填上自己的学号和姓名，点击了单人提交。

下午在东大镇食堂吃油泼面，老周端着盘子坐过来，眼睛瞪大：“博哥，你怎么就一个人填了表？那可是整整三天三夜啊，几万行数据、两万字论文，三个人轮流睡都得蜕层皮！”

“我有顺手的工具，想试试自己一个人能推进到哪一步。”我笑了笑，把话题带了过去。

周三下午六点，竞赛官网准时放题。

A 题是水下航行器轨迹控制，属于偏微分方程机理推导；B 题是物流集散中心的货运负荷预测与调度优化，附带数十万行时序数据。

我把题目分别喂给 Hermes 和 Sage 探路。半小时后结果明朗：Hermes 在 B 题的运力预测上抓出了扎实的经典模型，Sage 给出了清晰的四步求解路线。四十分钟内，选题拍板：主攻 B 题。

我泡上一桶老坛酸菜面，十指在键盘上敲得飞起。

Hermes 圈定异常值清洗阈值，Sage 构建多变量凸优化目标函数，GenChat 顺畅吐出基于 Pandas 的清洗代码和热力图脚本。

按下运行，终端字符瀑布般刷下。几十万行杂乱数据清洗完毕，第一批彩色的负荷热力图在屏幕上舒展开来。

夜里两点，寝室走廊的声控灯已经熄灭，老周的床上传来鼾声。

我喝了一口发凉的速溶咖啡。开赛八小时，我不但拿到了第一问的数据清洗集与拟合图，甚至在论文模板里把背景、预处理和数学模型骨架填补了四千多字。

三个模型窗口安安静静地悬挂着，随叫随到，省去了所有组员间的争吵与等待。

我揉了揉发干的眼角，靠在椅背上。

那种强烈的掌控感在心头蔓延。三个人做的事，一个人真的够。

## 14

周四清晨，老周和小陈去上早八，房间里只剩下散热底座微弱的风噪。

Word 里的论文已经堆到了十几页，昨晚的顺利让我对今天的推进充满信心。

第二问的核心是动态调度模型：在全区数十个分布式充电桩与数十辆卡车之间，根据分时电价与路况给出未来二十四小时的动态充电路径与电网负荷平抑方案。数据量骤增，伴随着早晚高峰的集中脉冲与随机波动。

我把文献任务交给 Hermes。不到五分钟，它抓回了一条重点标星的路线——“自适应改进灰色预测模型”，声称能将短期负荷均方根误差压到百分之三以下，并附带了顶刊论文链接。

我把摘要贴给 Sage 搭建微分方程组，Sage 却在对话框里给出了长篇负面评估。它认为灰色预测适用于平稳趋势外推，面对阶跃突变数据天然存在发散缺陷，极力推荐经典的差分 ARIMA 模型。

面对两个顶尖工具在算法选型上的撞车，我只当这是常见的工科路线分歧。为了抢进度，我兵分两路：让 Sage 细化经典方程约束，同时让 GenChat 尝试写出改进灰色预测的 Python 仿真代码。

中午十二点，GenChat 吐出的两百行代码落到本地。我导入运力数据按下运行，控制台顺利跑通。

然而当 Matplotlib 把预测曲线和实际散点叠加在一起时，第七十五个时间步——恰好是电价下调、车辆集中进场的拐点处，原本平滑上升的曲线突然笔直拉起，随后死死贴在一条水平线上，宛如一堵被天花板截断的墙。

我把坐标和图表特征贴回 GenChat 质问。

GenChat 毫不犹豫地弹出了条理分明的解释。它用极其笃定的学术口吻告诉我，这完全符合物理机理，称为“基于电池组动态阻抗引起的饱和阈值效应”，是电网在大规模集中充电脉冲下自动触发的软保护机制。为了增加说服力，它甚至当场推导出一个结构严密的“动态阻尼折减公式”。

我盯着屏幕看了十分钟。大二尚未接触过工业微电网保护机制，它解释得头头是道，我甚至一度怀疑是自己缺乏专业常识。

但在反复调参后，那道生硬的水平线依然如鬼魅般横亘在图表中央。我不得不暂时搁置，先去补齐第二问的机理支撑材料。

我切回 Hermes 寻找那篇关键论文。在文献摘要末尾，醒目地标着一行数据：“据《电网技术前沿》报道，某示范园区实测动态负荷峰值系数为 2.84，可作为同类场景基准校核参数。”

2.84。只要把这个具体到两位小数的基准代入惩罚权重，前面无法解释的曲线突变立刻能被包装成“与工程实测高度吻合”。

我随手点开 Hermes 生成的那行蓝色超链接。

浏览器标签页转了两圈，弹出一行白底黑字：

「404 Not Found. The requested URL was not found on this server.」

我愣住了。把 DOI 复制到校内图书馆的镜像数据库，检索结果显示：该 DOI 不存在。去搜索引擎查那本《电网技术前沿》，发现该期刊当年根本没有出过第四期。

胃里泛起一丝轻微的下坠感。

我把这段包含“2.84 峰值系数”的文字复制下来，分别发给 Sage 和 GenChat，询问该参数是否合理、能否用于验证模型收敛。

Sage 率先回复，洋洋洒洒列出四条支撑理由，开篇便是“该参数设定具有高度工程合理性”，并根据货运吞吐规律逆向推导出了合理性证明；GenChat 紧随其后，不仅完全赞成，更贴心地将这段推导重写成标准的英文学术摘要，推荐填入正文。

两个模型在屏幕两端各自展开，互为背书，字里行间充斥着逻辑自洽的严密。

而在另一个标签页里，那个查无此页的 404 界面还孤零零地挂着。

搭在键盘上的双手慢慢僵住了。

它们全在认真回答，全在严谨推导。但所有这些漂亮的公式、严密的论述，全都建立在一串由算法随机拼凑的虚构数据之上。

模型间的意见吻合，并不意味着事实存在。

我看着那个塞满了各色图表、已经写了上万字的 Word 文档。那些被我工整嵌进章节里的参数，到底还有多少是真实可靠的？

夜风吹得窗扇轻轻颤动。我盯着闪烁的光标，第一次察觉到，在这场看似行云流水的单人突进背后，一张巨大的虚空之网已经悄无声息地缠住了每一个齿轮。

## 15

周五清晨六点，窗外泛起灰蒙蒙的冷光。

我盯着屏幕上查无此页的 404 界面，反复检索证实了一个确凿的事实：Hermes 提供的那篇所谓顶刊论文，从标题、作者到 DOI 编号，全是模型根据上下文编出来的假象。

更糟的是，这个根本不存在的 2.84 峰值系数，已经被我层层嵌进了前两问的数学假设、归一化代码与第三节的核心推导里。

整座搭了半截的精巧模型，地基里浇筑的是一坨虚空的沙子。

我咬牙把 Word 里第三节的六页纸整段删除，但距离周六中午十二点的截止时间只剩下不到三十个小时。

在巨大的时间压迫下，原本清晰的流水线开始崩解。我焦急地向三个模型求助，试图寻找一个真实的经典参数替换掉 2.84。

然而三个并排的对话框却陷入了各执一词的混乱：Sage 极其保守，要求推倒双目标规划，回归单目标重新推导拉格朗日乘子；GenChat 表现得异常激进，贴出一整套自适应遗传算法代码，声称无需外部参数即可逼近最优解；Hermes 依然源源不断抓取着真假难辨的新文献。

我夹在中间频繁摇摆。按 Sage 的要求重写目标函数，矩阵求逆在本地报错发散；换上 GenChat 的代码，跑出来的货车充电负荷在电价高峰期居然为零，完全违背物理常识。我质问 GenChat，它改动了两个权重声称“已修正”，再次运行控制台直接炸出一串红色的 `ZeroDivisionError`。

时针转过周五下午，滑入深夜。

桌角堆着捏扁的易拉罐，我的提问变得越来越仓促，提示词从结构化规范退化成了焦躁的催促：“直接给完整代码”“别解释原理，给一个能跑通的函数”。

在此前，我一直沉浸在单人掌控多模型的自负中。直到置身死线前的泥潭，我才真切体会到：当这些工具用毫无破绽的语气吐出谎言时，排查谎言付出的代价远超过从头推导。

周六清晨八点，宿舍阳光透进窗棂。文件夹里堆满了 `model_v1.py`、`model_fix.py`、`model_final_really.py`，连我自己都分不清哪个脚本对应哪张图表。论文前面用的是线性规划假设，后半截分析却套用了遗传算法曲线。

最后两小时，所有的严谨链条被抛弃。

我麻木地删掉前后矛盾的论据，用模糊的套话强行缝合断掉的逻辑；图表对不上，就笼统标注成“数值仿真结果”；公式推导接不上，直接跳过写上一句“综上可得”。

十一点五十分，我把这份连自己都不敢细看第二遍的 PDF 打包上传。

屏幕中央弹出绿色的提示：“您的作品已成功提交，提交时间：11:53:20。”

老周和小陈站在身后，长舒了一口气拍我的肩膀：“牛逼啊博哥，真让你一个人把三天的比赛硬扛下来了，赶紧睡会儿。”

我坐在转椅上一动不动。

没有通关后的释怀，胸口像塞了一团受潮的棉花，沉重发闷。

别人看到的是一个大二学生单枪匹马交出了三十多页的竞赛论文。唯独我自己清楚，那是一篇地基悬空、模型假设前后矛盾、经不起任何推敲的残次品。整整三天三夜，我以为自己是调度三个强大助手的指挥官，最终却沦为给算法谎言四处救火、连最后交上去的东西自己都不敢信的泥瓦匠。

我合上滚烫的电脑屏幕。

在这场失控的狂奔里，我到底是有多天真，才会觉得自己真的学会了使用 AI？

## 16

周六中午交完卷，我倒在床上整整昏睡了十几个小时。

醒来时浑身酸疼，按亮拯救者的屏幕，三个悬挂着对话记录的模型标签页依然挂在浏览器里。我没去看那些对话框，直接关机。

整整一周，我陷入了一种近乎刻意的逃避。老周喊我手机开黑，我立刻加入；小陈去东大镇买夜宵，我也跟着在人群里晃悠。只要不掀开电脑，那场三天三夜的混乱推演就像从未发生过。

但心底深处偶尔还是会泛起一丝侥幸：评委老师会不会没时间查文献？会不会最后硬改出来的曲面图足够唬人？万一混上一个成功参赛奖，也算有个交差的由头。每次冒出这种念头，我都狠狠抹一把脸，强行压下去。

公示结果是在第二周的周五下午。

下课铃刚响，班级群里就炸了锅，几支队伍发出了教务处官网的喜报截图。

我坐在宿舍桌前，点开教务处的《获奖名单公示.pdf》。三十多页的名单按奖项排布，我按下 Ctrl + F 输入学号，匹配结果是 0/0；换成名字，依旧是 0/0。

一二三等奖没有，底下的成功参赛名单同样没有。

我握着鼠标逐行翻到末尾，又从头翻了一遍。

确实没有。

没有取消资格的通报，也没有安慰性的成功参赛奖。就是普普通通地，没获奖。

房间里很安静，窗外操场上有打篮球砸网的闷响。我默默关掉 PDF。

老周从床上翻身下来，走过来拉开椅子反向坐下，语气很真诚：“博哥，没事。你一个人报的名，人家三个人组队都熬得叫苦连天，你能把三十多页论文硬磕下来已经牛逼了。想拿奖等秋天国赛，咱们三个正经组个队搞一次。”

小陈也递过来一包零食：“就是，一个人能交上去就是胜利。”

他们眼神里全是真切的宽慰。

可这些安慰落在耳朵里，却让我觉得无地自容。

身边的朋友以为这只是一次人数悬殊的遗憾，唯独我自己清楚崩盘的真相。在那个混乱的深夜，为了赶死线，我明知道 Hermes 捏造了一篇不存在的论文，明知道 2.84 是虚构的数字，却已经没有时间从头再找一套真实数据。我换了三个模型、四套方案，最后拼出来的那套东西逻辑不完整、结果不可靠，连我自己都不敢多看一眼。

强烈的警惕与反感在心头滋生。

此前几个月，这些对话框在我眼里像是前沿的科技奇迹。真正被拉进高强度的工程绞肉机时，掩藏在华丽修辞背后的缺陷才暴露无遗：它们不仅会编造文献与数据，更可怕的是，它们能用极其笃定的学术语气，把荒谬的错误一路合理化到底。

那种自信满满的胡说八道，比写不出代码更令人心惊。

接下来的几天，我的桌面恢复了最单调的模样。模型书签被我拖进了末尾的折叠夹，别人在走廊聊起 GenChat 写作文，我低头走过，不再参与。

某天深夜十一点半，宿舍熄灯，我坐在台灯下改《概率论》的课后题。

遇到一道复杂的二维随机变量联合概率积分，算得草稿纸密密麻麻。我下意识点开折叠夹，重新打开了 GenChat。

墨绿色图标亮起，光标在空白输入框里闪烁，像一只等待指令的眼睛。

我把积分方程敲进第一行。

但在准备按下回车的瞬间，那个荒谬的 2.84、404 的虚假网页、以及通报里那行冰冷的铅字，冷不防再次浮现出来。

悬在键盘上方的手指停住了。

如果它吐出的推导依旧是一套看似天衣无缝、实则在某个边界偷换概念的伪解，我又得花多少时间去辨别真伪？

我盯着那个光标看了几秒。

最终，我伸出食指按下退格键，把输入框里的公式一个字一个字删得干干净净，关掉了窗口。

## 17

放榜过去了大半个月，长安校区的杨絮在风里漫天飞卷。

数模选拔赛的余波早已散去，我把那几个模型的标签页从浏览器常驻栏撤了下来，整个人对大模型的热情明显降到了冰点。偶尔为了查个报错贴代码，只要它吐出超过两百字的长篇大论，我便下意识关掉，宁可去翻论坛里排版混乱的旧帖。

但在某些深夜，刷 Twitter 的旧习惯依然保留着。

四月下旬的一个周三深夜，寝室里只有老周均匀的呼噜声。我握着鼠标无目的地划着屏幕。

信息流里开始频繁跳出带有火药味的讨论。那股由各路科技博主吹捧起来的狂热赞歌，似乎在落地进入实际工程与科研后，撞上了一堵坚硬的墙。

前排的一条高赞动态里，一个生物信息学博士生愤怒发推：GenChat 给他编造了一整篇论文引用，包含两位领域权威大牛的名字、期刊卷号与页码，导师检索后发现两人从未合作过这篇论文。

底下的评论区充斥着共鸣，各路工程师与学生都在吐槽类似经历。在这些激烈的讨论里，我第一次频繁看到一个专业词汇：

`Hallucination`（幻觉）。

有人在长文里拆解其底层机制：大语言模型根据上下文预测下一个词的概率分布，目标是输出在统计学上最顺畅的下一个词，根本缺乏核实物理世界真伪的能力。只要上下文诱导稍有偏差，模型就会在极其逼真的学术语法下，面不改色地捏造事实。

我盯着那个词，眼眶有些发热。原来不止我一个人被那串 404 的虚假链接撞得头破血流，全世界都在同一条阴沟里狼狈翻车。

顺着算法标签，我刷到了一条发布于数小时前的长推文。

发帖人的头像是在一处堆满示波器和机械零件的实验台前拍的侧影。他详细复盘了自己参加全美大学生数学建模竞赛的惨痛经历。

他在帖子里写道，自己开着多个标签页，让不同模型各司其职，前十二个小时的高效率让他误以为找到了单挑团队的利器。然而中途模型捏造了一个虚假的雷诺数经验修正项，他没核查便喂给另一个模型，另一个模型顺水推舟推导出一整套严密的收敛证明。模型间互相背书，直到最后绘制网格曲面数值全盘发散。

我握着鼠标，一行行读着那些英文句子。屏幕上的自负、慌乱与死线前删改论文的狼狈，与我那三天的经历严丝合缝地重叠在了一起。

平时在这些海外动态底下我只是个过客，这次我把双手放上了键盘。

我用直接的英文在输入框里敲下一段长留言，告诉他我是大洋另一端的工科生，刚刚在校内选拔赛里遭遇了完全一模一样的溃败。同样的三个模型分工、同样被捏造的数据带偏、同样目睹了多模型间的盲目互信。

原以为这条留言会沉入信息流，不到三分钟，右上角亮起了通知红点。

发帖人直接回复了我的评论：

"I did the same thing — multiple tabs open, manually copying context between models, asking one model to verify another. I also mistook 'multiple models agree' for 'this is correct'."
（我也干了完全一样的事——开着多个标签页，在模型之间复制上下文，让一个模型去验证另一个。我也曾经误以为「多个模型意见一致」等于「结论符合客观事实」。）

我们在公开推文底下你来我往地回了四五条。两个素昧平生的工科生相隔上万公里，不仅踩进了同一个由算法编织的陷阱，连应对陷阱时的多窗口操作都展现出惊人的默契。

原本沉重的自我否定悄然松动。那场惨败并不代表多模型协同是异想天开的弯路，分工的价值实实在在，致命漏洞在于盲目交出了审核权。

屏幕上再次浮起一条通知，这次是一则私信气泡。

发帖人发来一行简短的问询：

"Your workflow looks interesting. Do you want to keep talking?"
（你的工作流看起来很有意思。你想接着聊聊吗？）

我靠在椅背上，看着那行跳动的光标。心中的戒备不知不觉消散了大半，取而代之的是久违的专注与好奇。

我活动了一下指关节，把光标点进了私信框。

## 18

屏幕右下角的私信图标亮着蓝色的微光。

对方的主页头像是在工科实验台前拍的侧影，背景里隐约看得到示波器和排线，简介只写了加利福尼亚某所大学的机械工程专业，名字叫 Aaron。

我搭上键盘，用工科报告里最直接的句式敲出第一行英文，告诉他我是西安的工科生，刚才那场数模比赛对我来说同样是一场灾难。

输入框顶端几乎立刻浮出三颗跳动的灰色圆点。

"Tell me about it. How many models did you chain together?"
（跟我说说，你当时串了多少个模型？）

我顺着记忆回过去：Hermes 抓文献，Sage 推导假设，GenChat 写代码和报告。

Aaron 回了个苦笑的字符，紧跟着一句长句：“我的组合也差不多。本地 Python 调接口，再开两个网页交叉核对。头十二个小时感觉跟变魔术一样，对吧？”

这句话一下子戳中了数模第一夜的狂妄。

我们迅速对起了崩盘的节点。转折点是 Hermes 凭空捏造了一篇带虚假 DOI 的论文，当我去向 Sage 求证时，Sage 居然顺理成章地把那组编造的数据给合理化了。

Aaron 在屏幕那头敲来一连串感叹号。他也撞上了同一堵墙：模型在偏微分方程里随口给出了一个经验修正系数，他省去了查工具书的步骤直接喂给另一个模型，另一个模型顺水推舟推导出一整套收敛证明，直到最后绘制曲面全盘发散。

两个素未谋面的工科学生隔着时差，把各自在比赛里不敢外传的粗心与狼狈，一笔笔摊平在私信里。

最初的郁结迅速散开，交流很快切入更深的使用细节。

我也立刻察觉出我们在方法上的截然不同。

Aaron 展现出的严谨让我有些发愣。任何模型给出的论文或常数，只要不能在校内数据库里搜出带页码的原版 PDF，他一律视作不存在；遇到关键公式，他绝不直接问模型“对不对”，而是专门写一段带有奇异点或极限值的测试提示词，逼着模型去处理退化情形。

"Never ask a model if it's right," Aaron 写道，"It's trained to be helpful and agreeable. It will hallucinate a proof just to make you happy."
（永远别问模型它对不对。它的目标是讨喜和顺从，为了让你满意，它宁可现编一套证明。）

我搓了搓手指。在比赛后半程，面对时间压力，我不仅放弃了反查，甚至主动给模型喂带偏向性的引导词，把模型生成的顺从废话当成了救命稻草。

但 Aaron 同样对我的操作习惯充满了好奇。

当我把平时如何拆解任务、如何在几个模型之间流转上下文的笔记贴过去时，对话框停顿了两分多钟。

我把任务切得很碎：Hermes 找资料和关键词，清洗掉修饰词后单向喂给 Sage；Sage 帮我把问题拆成步骤、检查思路，确定无误后再推给 GenChat 负责写具体代码。每个模型只在极窄的区间里运转，绝不让单一模型承担从找资料到写代码的全局职责。

"Wait," Aaron 问，"You managed this workflow entirely in your head and manual tabs?"
（等等，你完全靠脑子和手动切换标签页跑通这个流程的？）

我敲字承认：我不会写程序把几个模型自动串起来，全靠开着浏览器窗口，复制粘贴、手动清洗文本和在记事本里倒腾上下文。

Aaron 显得格外吃惊。他说自己的 Python 脚本把前一轮的完整输出一股脑塞进下一轮，错误信息像滚雪球一样在整个上下文里发酵蔓延。我这种原始的手动清洗，反而在任务边界的隔离上做得更加彻底。

窗外的夜风拍打着宿舍老旧的铝合金窗框。这场越洋对话没有沦为情绪安慰，反而逼着我们把模棱两可的感觉梳理成了明确的技术共识：

大模型本质上是概率驱动的文本续写系统，完全缺乏对物理现实与数学真理的感知力。

多模型交叉验证只能剔除低级的语法疏漏，根本无法确认事实真伪。当一个错误的假设被包装成合理的上下文输入时，两个甚至三个模型完全会在虚构的前提下达成一致。模型间的意见吻合，只能证明语言叙述顺畅自洽，与客观现实没有任何关联。

这几行字落在屏幕上，让我心里那团自我怀疑松动了一些。

多模型分工体系本身立得住，崩盘的根源在于盲目信任了概率工具的可靠性，又在压力下丢掉了工科生底层的验证原则。

探讨逐渐落到代码段与报错日志上，Twitter 的私信窗口限制太多，大段缩进被挤成一团。

Aaron 问：“你用 Relay 吗？这窗口快看瞎了，那边发代码和附件方便得多。”

Relay。我知道这个带有绿色波纹图标的通讯工具在海外极客和工程师群体中很流行，支持点对点加密和无损代码排版。

我切出浏览器，花了五分钟下载安装好客户端，用手机号收了个海外网关验证码注册完毕，把账号发回推特。

几秒钟后，Relay 弹出了好友申请。

换到更适合工程交流的工具后，对话明显顺畅起来。Aaron 随手甩过来几段他写的自动化验证脚本，代码高亮清晰规整；我也把几套提示词结构文档直接拖拽过去。

话题从那场失败蔓延到更深层的技术生态：OpenMind 的大算力暴力美学、从他们团队出走另立门户的 Sapient 主打的严苛对齐与安全性、以及 Helix 将搜索强行焊在大模型上引发的信源污染隐患。

夜色深沉，电脑右下角的时间跳过了凌晨两点。西安的气温降了下来，而在加利福尼亚，正值中午的 Aaron 敲下告别，说自己得赶去上材料力学实验课。

"Glad we had this talk, Sun. Keep your pipeline, just add the checkpoints."
（很高兴聊了这么多，孙。保留你的流水线，把校验哨卡加上就行。）

我敲下回复，看着他的头像变暗。

Relay 的聊天界面静静停在屏幕中央，几百条英文对话与规整的代码块向上延伸。

宿舍里回荡着室友均匀的呼吸声。

在此之前，在这间宿舍、整栋楼乃至航海学院大二的圈子里，我习惯了被当成那个“懂 AI 的人”。室友写不出代码会回头找我，隔壁配置不好网络会拎着饮料敲门，那种被簇拥的感觉给了我一层虚浮的安全感。

但在今晚，看着屏幕上这几百条跨洋消息，在小圈子里积攒的那点底气显得有些单薄。

隔着大洋，像 Aaron 这样的人早已把工具拆解得更加透彻，在严苛的工程纪律下摸索前行。在这场刚刚拉开大幕的技术变局里，我凭借一点好奇心摸出来的那点门道，放在真正的坐标系里大概算中等偏上。

身边的小小圈子，根本不该是衡量自己的尺子。

如果真的要把这套工具做成自己的核心底牌，目光就必须从身边的几张书桌移开，投向更广阔的地方。

我按下拯救者的电源键。屏幕熄灭，风扇声平息，房间重新归于终南山脚下的夜色之中。

## 19

五月初，长安校区的杨絮落尽，大二下学期的日子在教室与宿舍间平稳推进。

数模失利带来的郁结渐渐淡去，我重新把浏览器收藏夹里的模型书签拖回了常用栏。面对那几个熟悉的输入框，我的心态有了极大的变化。

我不再关注科技媒体上天花乱坠的官方宣传片，也对各个机构发布的跑分基准榜冷眼相待。数模交上去的那份残次品教给我一个最朴素的道理：在标准题库里跑出九十分以上的模型，一旦扔进混乱的真实工况，踩中一个凭空捏造的数据，整套方案照样会瞬间塌陷。

我把视线转向了那些真正拿这套工具在工程一线干活的人。

顺着 Aaron 随手分享的关注列表，我找到了十多位长期在海外一线测试大模型的重度用户：加州的大厂系统工程师、高校带实验的助教、开源社区全栈开发者。顺着他们的转评，我的书签页迅速向外蔓延，摸进了几个极客论坛和技术讨论区。

在这些圈子里，我像个无声的影子一样潜伏着。

信息流每天都在滚过海量内容：长上下文的组织方式、特定矩阵运算下的幻觉分布、提示词的逻辑边界，以及针对新版本性能退化的激烈声讨。

我新建了一个本地笔记，分类保存有价值的截图与踩坑记录。随着阅读量增加，一个此前未曾意识到的事实浮现出来：

全球范围内，根本不存在一份官方编撰的权威使用指南。

面对这种概率生成系统，大厂的顶尖架构师同样缺乏确定性。全世界的使用者都在各自的屏幕前摸索，野蛮生长出一套五花八门的民间方法论。

但讨论越多，泡沫也越厚。

每当在论坛里看到被数百人点赞的所谓“革命性提示词”，我从不盲信。我把那些花哨的句子复制下来，分别扔进刚刚热更新的三个模型里做对照实验：底座升至 Genesis-3.7 的 GenChat、上下文放宽的 Sage-1.3，以及搜索卡片更规整的 Hermes-1.2。

在这三个新版本面前，很多神乎其神的技巧立刻现了原形。

有的经验确实管用。在提问前强制要求模型“列出关键物理假设并在输出前自我检查边界”，能有效减少 Genesis-3.7 在代数运算上的低级错误；用清晰的标记层级定义输入输出，能降低 Sage-1.3 遗漏长文本约束的概率。

但更多的技巧纯粹是文字游戏。加上“请扮演图灵奖得主”的前缀，除了多出两句客套话，底下的算法题依然会在同一个指针边界上崩溃；甚至有人宣称在末尾承诺“给你两百美元小费”能提升逻辑严密性，我实测跑含有奇异点的偏微分方程，模型吐出一串热情的感谢，迭代代码照旧溢出。

我坐在微热的拯救者前，在本地笔记里敲下一行行冰冷的测试记录，剥除那些被吹捧出来的玄学。

数模翻车的痛感催生出最坚硬的防线。结合从 Aaron 那里学到的审慎，我在显示器旁贴上了一张便利贴，写下五条朴素的防失控底线：

信源穿透，引用的常数与文献必须能在知网或期刊官网查到原文，否则一律视作幻觉；
对抗质询，一个模型给出的解法，必须调换窗口交给另一个模型作为红队去挑逻辑破绽；
真机跑通，所有代码必须在本地终端输入极端数据实跑，绝不凭肉眼判断；
状态封存，长任务拆分成子模块，跑通一个固化一个，禁止版本混用；
人做终审，模型只负责提供候选方案，关于现实物理的最终决断，由坐在这张椅子上的人负责。

五条规则带着工科生笨拙的冗余，却终于在未知黑盒与我的屏幕之间立起了一道可靠的屏障。

然而，外部世界的节奏走得越来越快。

进入五月中旬，三个模型的迭代频率陡然加快。几乎每隔两三周，界面就会弹出版更通知。Genesis-3.7 对口语化指令的理解越来越顺，Sage-1.3 一次吞下几十页讲义或一章教材也不再卡壳，Hermes-1.2 的引用卡片也罕见出现失效链接。

工科生习惯了教材上数十年不变的经典定理，但在这里，使用规则以周为单位被重写。

几个星期前被奉为秘笈的复杂拆分技巧，随着模型长文本能力的提升变成了无用负担；某些精心构建的防御前缀，在新版本自我对齐后反而成了干扰。

看着那些迅速过期的旧笔记，我脑海中形成了一个清晰的念头：

在快速更迭的领域里，具体技巧是有保质期的。

死记几套精巧的模板构不成壁垒。真正靠得住的，是在工具剧烈演化的过程里，始终保持对底层特性的敏锐，以及随时推倒重构工作流的适应力。

论坛里关于 Genesis-4 的传闻开始甚嚣尘上。有人发出了真假莫辨的多模态交互截图，号称新模型将跨越纯文本边界，直接读懂工程图纸。

面对满屏幕的喧嚣与狂欢，我握着鼠标的手很稳。

经历过此前那场虚火，现在的我学会了顺着主页去查发帖人的背景，去排查图片中的渲染破绽，把工程推论与自媒体炒作分辨得清清楚楚。

终南山的夏夜微风穿过防盗窗，书桌上的五条规则便利贴微微晃动。

我关掉喧闹的讨论区，关机休息。大模型在演进，现实世界在重组，只要自己的双脚踩在实测与验证的土地上，无论下一个面世的模型叫什么名字，我大概也能比别人更快一点摸清楚它的脾气。

## 20

五月中旬，长安校区的白昼开始被初夏的暑气拉长。

专业基础课全面进入深水区，胡寿松那本经典的蓝色《自动控制原理》被我翻得卷了边，摊在宿舍书桌正中央。

推导卡在二阶系统的单位阶跃响应部分。闭环传递函数的标准形式、阻尼比与自然振荡角频率的微分方程推导，老师在黑板上画满了三个版面。课上我记了一整页笔记，晚上坐在宿舍重看，推到极点在复平面上的位移轨迹时，思维忽然在半空断了层。

数学推导能够一步步代入，但我始终抓不住那个无量纲阻尼比从零变到一之间，物理系统内部的能量耗散究竟对应着怎样的动态过程。

要是放在大一或者半年前，遇到这种卡壳，唯一的办法就是硬着头皮翻教材的前后章节，或者在搜索引擎里翻找各种排版错乱的工科博客。常常是翻了半小时，被几篇互相抄袭的劣质笔记绕得心浮气躁，索性把书一合，拖到期末复习周再去死记硬背。

现在，我右手握着笔，左手很自然地在浏览器里切到了模型窗口。

我把教材上的微分方程和阻尼比定义直接输入对话框，按下回车。

屏幕上光标闪动，几秒之内吐出了一大段标准的拉普拉斯变换推导。通篇都是符号、留数定理和复变函数展开，严谨得挑不出毛病，但也冰冷得让人提不起兴致。

我没有关掉窗口，而是敲下第二行字：“先别用拉普拉斯变换。用一个水下潜器的方向舵偏转受阻作为例子，给我解释阻尼比小于一的时候，舵面为什么会越过目标角度产生超调振荡。”

光标重新跃动。这次它剥离了所有的拉氏变换符号，直接把舵机的回复力矩、水流阻尼力矩拆解成了两股对抗的物理作用，生动地描述起水下舵面在惯性冲过平衡位置时如何被反向推回。

我盯着屏幕看了一遍，还是觉得有些模糊，手下敲得更快了：“如果阻尼比无限接近于零，系统的能量耗散在哪里？退回到高中的简谐振动动能势能转化给我讲。”

屏幕几乎没有停顿，顺从地将微积分与状态方程彻底抹去，重构成高中物理课本里光滑水平面上的弹簧振子模型，逐帧拆解势能转化为动能的能量循环。

我靠在椅背上，长长舒了一口气，手里中性笔的笔帽在桌面上轻轻磕了两下。

这是一种此前从未体会过的解惑体验。

在大学的教学楼里，哪怕再耐心的教授或研究生助教，也不可能坐在工位上，陪一个学生把同一个推导来回拆解四五遍，更不可能容忍你把大二的专业课难点一路追问回高中的基础概念。成年人哪怕出于礼貌，连问三遍之后，眼神里也难免带上审视或倦意。

屏幕对面的对话框没有情绪。只要你敲下回车，无论你的问题问得多笨拙、多细碎，它都会毫无怨言地把同一套知识碾碎、重组，换成能让你听懂的语言重新讲一遍。

推导讲到最后，模型顺带给出了一个关于闭环特征根分布的结论，声称“在该参数配置下系统必然全局渐近稳定”。

我的视线落在那行字符上，手指停顿了一下。

数模竞赛留下的教训已经刻成了肌肉记忆。我没有顺手把这句话抄进笔记，而是翻开手边的教材，对照着赫尔维茨稳定判据的代数表，在草稿纸上草草列出了三阶行列式。

果然，多项式的二次项系数在模型给出的参数配置下其实是负的。模型在推导中把符号判断错了，直接得出了"全局渐近稳定"的结论。按赫尔维茨判据，这个特征多项式在当前参数下根本不满足所有主子式为正的条件，系统实际是不稳定的。

我拿起红笔，在草稿纸上把那行推导划掉，顺手在旁边标注上适用边界。

我没有特意去想什么工作流或者验证规则，那次翻车的教训已经变成了下意识的警惕——只要涉及工程判断，最后盖章的只能是自己手底下的笔。

这种交互悄无声息地渗透进日常学习的每一处缝隙。

专业课前，把 Sage-1.3 喂进从课件里复制出来的一整章讲义文字，让它提炼出核心定理和公式的逻辑主线，上课时就不至于在老教授密集的板书中迷失方向；

实验课写仿真脚本，Matlab 的命令行里冷不丁弹出一行奇异矩阵报错，把几十行脚本贴给 Genesis-3.7，它往往能迅速指出循环内部某个变量在特定步长下除以了极小值；

阅读外文文献遇到生僻的专业术语，Hermes-1.2 溯源出处的表现最为扎实，不仅能给出发音和释义，还能列出该术语最初在流体力学经典教材中的出处；

复习遇到瓶颈时，甚至可以让它根据课件上的典型例题更换工况参数，重新生成两道变式选择题拿来自测。

宿舍的另一侧，室友横着手机开了一局游戏，中途切到微信和网页，抱怨下周的思政课要交八百字读书报告。他顺手打开 GenChat，敲了一句“帮我写一篇关于工业遗产保护的体会”，把模型生成的套话复制到 Word 里，调整了字体便直接关掉。

我从旁边扫了一眼，没有多说什么。

我的各科成绩并没有因此出现夸张的暴涨，我也并没有摇身变成掌控一切的天才。

真正发生质变的，是跨越卡壳的速度。

过去学工科，一个推导想不通、一段代码调不通，常常意味着一整个晚上的挫败感。困惑往往积压成期末的隐患。现在，只要自己愿意追问到底，那个卡在胸口的疙瘩大部分能在当天晚上被解开。

推特的信息流里，关于 Genesis-4 即将发布的各种所谓内部爆料依然时不时划过屏幕。有自媒体把多模态推理能力吹得神乎其神，也有论坛在热烈争论它会不会彻底改变软件工程的生态。

我握着鼠标，顺手关掉了那个讨论帖的标签页，目光重新落回眼前画了一半的伯德图。

那些浮躁的喧嚣似乎离我很远。

十一点半，宿舍准时熄灯。头顶的风扇规律地旋转着，送来终南山初夏温热的风。

我合上笔记本电脑，将桌上的草稿纸、自动铅笔、教材和冷掉的大半杯绿茶归拢到一旁。

我忽然意识到，自己已经很久没有在动笔之前，认真琢磨“今天到底要不要用 AI”了。

它就像抽屉里的卡西欧计算器、电脑里的 Matlab，或者这叠翻卷了边的草稿纸一样，无声地沉进了大学生活的背景里，变成自习时默认就会打开的基础设施。

## 21

六月上旬，期末周的气氛一下子压了下来。

自动控制原理、信号与系统、概率论，三门课集中在同一个礼拜考。教材上画满荧光笔的页码越来越密，图书馆四楼的插座从早到晚被抢光，食堂里聊的话题也从游戏变成了"你复习到哪章了"。

我把三门课的课件打包整理好，打开 Sage-1.3，先把《自动控制原理》的目录和前两章讲义文字复制进去，敲了一句：

「帮我整理这一章的知识框架，标出核心定理、公式和它们之间的推导关系。」

它几秒钟就吐出来一张结构化的大纲：时域分析、根轨迹、频率响应，每个标题下面挂着关键公式和适用条件。我对照着教材翻了一遍，框架本身没大问题，但有一两个节点明显是它自己脑补出来的过渡，教材里根本没有单独成节。

我没有删，也没有全信，只是在那个节点旁边打了个问号，翻到教材对应页码确认。

接下来的几天，这套流程变成了复习的默认节奏。

上午在图书馆，先让模型把当天要复习的章节目录拉成框架，对照教材过一遍；下午做题，遇到卡壳的概念就切到对话框追问。有时候一道题卡了半小时，自己翻书翻不到，问模型两句就通了——不是它给了答案，而是它把概念拆开讲了一遍，自己忽然想通了。

遇到课堂上没听明白的概念，比如二阶系统的阻尼比对超调量的影响，我不再直接往教材后半段翻找，而是先把概念描述喂给模型，让它用更基础的例子解释。问得不够清楚就追问，嫌它讲得抽象就让它换角度——从数学公式跳到物理直觉，再从物理直觉退回高中的简谐振动。

以前复习最费时间的"这个东西到底是什么意思"，现在省下来大半。

但边界也很清楚。

复杂的电路图、伯德图和根轨迹，我还是得自己手绘在草稿纸上，再用文字描述给模型听——2023 年了，随手拍一张题就自动上传识别的功能还远没成熟。真正综合的大题，三个模型都经常抓瞎，给出来的步骤跳步严重，或者直接套错公式。所以题目我还是自己做，做完了拿教材答案和老师讲义核对；模型只负责解释为什么错、涉及什么概念，绝不拿它当解题器。

第四天晚上，我在复习奈奎斯特稳定判据。

Sage 给了一段解释，顺便列了一条"奈奎斯特-香农采样定理的推论"，说得头头是道，还标了适用条件。我盯着那行字看了两秒，觉得哪里不对——采样定理明明是信号与系统里的东西，怎么跑到自动控制的奈奎斯特判据里来了？

我翻开课件，翻到对应章节。果然，课件里根本没有这条"推论"，是模型把两个名字都带"奈奎斯特"的相近概念拼到了一起。

「又来了。」

我在心里说了一句，顺手把那段从笔记里划掉。

没有失望，也没有惊讶。数模比赛那次之后，模型说得再完整、再自信，我都会习惯性翻课件核对一遍。关键定义以老师 PPT 为准，知识框架以教材目录为准，模型能提醒可能遗漏的考点，但不能替老师决定考试重点。

这个边界不是我专门总结出来的规则，而是在一次次复习里自然长出来的。

一周下来，三门课里有两个以前因为时间不够直接放弃的知识盲区——根轨迹的零度根轨迹分支、概率论里的极大似然估计推导——这次我都能当天晚上定位到问题在哪，追着模型问明白，再翻教材验证。

真正被压缩掉的，不是做题的时间，而是"卡住以后不知道去哪找解释"的那段空白。

考试前最后一晚，我把三门课的框架再过了一遍。模型又给出了一个听起来十分确定的结论，我习惯性翻开课件核对，果然发现一个小错误——它把两个相似的公式符号搞混了。我顺手改掉，继续往下复习。

窗外的夜风带着初夏的闷热，宿舍里老周的台灯还亮着，对面小陈在翻高数笔记。

AI 已经成了我复习时随手打开的工具，但教材、老师和自己的判断，仍然决定什么是真的。

## 22

七月初，期末考完，我拖着行李箱回了家。

西安的夏天比学校更闷，空调从下午两点开始嗡嗡转。我把拯救者搬到书桌上，接上家里那对旧音箱，打开本地音乐文件夹。

播放器是系统自带的，界面丑得像上个世纪的产品，歌曲列表按文件名排序，专辑封面要么不显示，要么显示成一团模糊的色块。

我靠在椅背上听了两首歌，脑子里忽然冒出来一个念头：

能不能自己做一个本地音乐播放器？

目标并不复杂。扫描电脑里的本地歌曲，显示歌曲列表，播放暂停上一首下一首，有进度条和音量控制，能搜索歌曲，最好还能显示专辑封面。界面简单干净，按照我自己喜欢的方式来。

如果完全靠自己，我根本不知道从哪里开始。但现在不一样了。

我打开 GenChat，敲下第一行字：

「我想做一个可以播放电脑本地音乐的软件。」

模型几乎立刻就开始一步一步告诉我：新建一个文件夹，用 Python 的 tkinter 做界面，安装 pygame 处理音频，复制这几段代码，然后运行。

我照着操作。装库的时候报了个版本冲突，把报错贴回去，它让我换成另一个版本。再跑，成了。

屏幕上弹出一个灰扑扑的小窗口，里面有一个按钮，一个进度条，还有一个文件选择框。我随便选了一首周杰伦，按下播放。

音箱里传出了前奏。

我盯着那个小窗口看了足足半分钟。

在我原来的认知里，"做一个软件"是属于真正会编程、会开发的人才能做的事情。我学过 C 语言和数据结构，能写 OJ 题，但从来没想过自己能做出一个"软件"。

现在只是和 AI 聊了几个小时，居然已经摸到了一个播放器的雏形。

界面很丑，控件大小参差不齐，但声音真的响了。

那种兴奋感比第一次 OJ 拿到 Accepted 还要强烈。因为这一次不是做题，是真的在"做一个东西"。

接下来的几天，我开始不断往里加功能。

「能不能加搜索框？」
「能不能自动读专辑封面？」
「能不能记住上次的播放列表？」

每提一个需求，模型就生成一段新代码。我把代码复制到本地文件里，运行，报错，把报错贴回去，它再改，我再复制回来。

最初一切都很顺。直到我提出"能不能记住播放列表"的时候，模型说可以用 SQLite 保存歌曲信息，这样搜索、收藏、最近播放这些功能都好做。

「音乐播放器为什么还需要数据库？」我问。

它解释了半天，我大概理解成：原来软件也需要一个地方记住东西，不然每次打开都要重新找一遍歌。

我点了点头，虽然还是不太明白为什么不能直接存成一个文本文件。

但在和模型交流这件事上，我已经很熟练了。不理解概念时，我会让它用大白话解释；出错时，我先问"为什么"，而不是直接让它整段重写；我会提醒它不要破坏已经能工作的功能；我会把关键代码和报错一起贴过去；我还会让 Sage 判断 GenChat 给出的方案有没有明显问题。

比如 GenChat 说可以用一个列表存所有歌曲信息的时候，我问了一句："那为什么不用文本文件存？每次打开读一遍不就行了？"

Sage 解释说，其实几百首歌用文本文件完全没问题，但如果以后要加收藏、最近播放、按专辑分类这些功能，数据结构会越来越复杂，数据库会更方便维护。


我大概听懂了一点，虽然还是不太清楚 SQLite 具体怎么用，但至少知道了"数据多了以后存起来会越来越麻烦"这件事。

问题是，功能越加越多，项目开始失控。

最初只有一个 main.py 文件，几百行代码。后来变成了 main.py + player.py + library.py + ui.py，四个文件。模型每次只能看到我贴过去的那一段代码，根本不知道整个工程长什么样。

它修改一个地方时，经常不知道另一个文件还在依赖旧逻辑。

我把播放列表的保存逻辑从 JSON 改成 SQLite 的时候，模型改了 library.py，但 ui.py 里还在调用旧的 JSON 加载函数。程序直接崩了。

我把报错贴回去，它说"哦，这里也要改"，然后改了 ui.py。结果改完以后，播放按钮又失灵了——因为它不小心把事件绑定覆盖掉了。

这样来回折腾了好几次。

文件越来越多，代码越来越乱。同一个功能在不同文件里重复写了好几遍，有些函数我已经不知道还能不能删，有些逻辑我自己都理不清。

到了第六天，我打开项目目录，看到十几个 .py 文件散在那里。

按数模比赛养成的习惯，我每次改坏一个版本，都会把整个文件夹复制一份存成 backup_0708、backup_0709。确实能回退，但复制粘贴式的备份只能救急，阻止不了工程本身越来越乱。

里面有一半是我已经不敢碰的。
看到一个现在还能工作的函数，即使知道写得很乱，我也不敢轻易改——因为不知道改完以后会不会牵连其他地方。

最关键的是，修一个功能可能让另一个功能重新坏掉。

那天晚上，我终于把程序运行起来，放了一首歌。

声音确实出来了。专辑封面也显示了，虽然经常显示成另一首歌的封面。搜索也能用，但歌曲多的时候会卡个一两秒。

但我没有第一天想象中的那种成就感。

我重新翻出最开始写在便签上的需求，一项一项对照。

"简单、干净、符合自己使用习惯的本地音乐播放器"——这个东西其实并不存在。

界面丑得像 Windows 98，控件大小和间距乱得没法看。搜索偶尔失灵，切歌有概率出错，播放状态和界面状态经常对不上。

有的功能做了一半，有的功能因为一直报错后来干脆删掉了，有的功能实现出来以后，和我最初想象的完全不是一回事。

眼前这个东西甚至很难称作完整产品。最多只能算一个勉强能运行的原型。

我靠在椅背上，看着屏幕上那个灰扑扑的窗口。

这次和数模比赛不一样。毕竟如果没有 AI，以我现在的编程水平，可能连这个原型都做不出来。大模型确实帮我跨过了原本跨不过去的那道门槛。

但我第一次非常具体地意识到：

AI 可以帮我把一个想法变成雏形，却还不能替我把这个雏形变成真正想要的作品。

我打开 GenChat，最后问了一句：

「如果真正会做软件的人来做这个播放器，会怎么组织这些东西？」

模型开始解释：模块怎么划分，数据怎么存，界面和逻辑怎么分离，状态怎么管理，为什么要做版本控制。

其中一些词，我已经不像一周前那样完全陌生了。我大概能听懂一点。

然后我重新看了一眼自己那个混乱的项目目录。

第一次真正明白：

从"程序能跑"，到"软件真的做好"，中间还有很长一段路。

## 23

播放器的项目文件夹后来就一直搁在硬盘里。

偶尔点开一次，看到十几个乱哄哄的 .py 文件，以及那些 backup_0708、backup_0709 的压缩包，我直接关掉窗口，再也没碰过。没有大挫败，也没有上升到什么深刻总结。只是接受了一件事：现在还做不好。

之后就是普通的暑假。睡觉、开黑、跟家里出去吃饭、刷 Twitter、偶尔翻一翻下学期的课程大纲。

变化是从七月中旬开始明显的。

我用 AI 的频率已经高到了每天都要打开好几次。GenChat 免费账户的限流开始变得烦人——有时候问着问着就弹出一行小字：「您今日的使用次数已达上限，请稍后再试。」高峰期更是要等半天才出结果。

我其实早就知道 GenChat Pro 的存在，$20 一个月，按汇率算下来一百多块。大学生不是付不起，但也绝对不是完全无感。

我没买。撞限流的时候就等一会儿，或者切到 Sage 和 Hermes 继续问。一个月给一个 AI 聊天网站交二十美元，这种事放在半年前我自己都觉得荒唐。

Twitter 的信息流也在变。

去年年底大家还在围观 GenChat 会不会写诗、会不会写代码，现在讨论的重点明显不一样了。越来越多的人在晒自己用大模型做出来的东西——有人做了个 PDF 问答工具，把论文扔进去直接提问；有人做了个浏览器扩展，打开任何网页自动总结全文；还有人做了个写作助手，帮你润色邮件和翻译文档。

我随手试了其中两三个。

很快就发现，很多所谓"全新 AI"，底下接的还是 Genesis、Sage 或者别的现成模型。

Twitter 上有人看到新产品就嘲讽：「又一个 Genesis wrapper。」

我有时候也能一眼判断底层接的是什么。但经历过音乐播放器以后，我不会简单地嘲笑"套壳"。

因为我很快注意到另一件事：有些产品虽然没有更聪明的模型，却确实把麻烦的步骤省掉了。

以前读 PDF，要自己找段落、复制、粘贴给模型；现在产品直接让用户围绕文档提问。以前读英文论文，要一段一段复制翻译；现在工具直接整段拖进去，边读边问。

我第一次比较明确地意识到：模型有多强是一回事，把模型变成一个真正好用的产品，是另一回事。

以前看到一个 AI 产品，我首先问"它用的模型是谁"；现在会多问一句："它到底替用户省掉了哪一步？"

基础模型本身也在小步迭代。Genesis-3.7、Sage-1.x、Hermes-1.x 在整个暑假不断变得更稳定、更快，产品功能也越来越完整。但我不会再因为一次普通小版本更新兴奋半天了。

真正持续占据社区讨论中心的，是两个"下一代"传闻。

OpenMind 的 Genesis-4。有人爆料说新模型推理能力会有质变，代码和长上下文都会大幅提升。

Sapient 的 Sage-2 也开始有人讨论。开发者社区里有传闻说 Sapient 这次会把模型拆成多个不同算力的档位，轻量的快而便宜，旗舰的慢但强。具体叫什么名字还没人知道，只说是三个档位。

但真正让我在意的，是关于 Genesis-4 的另一个爆料：

Vision。

有人声称新模型能直接读取照片、图表、公式截图。

我盯着那条爆料看了很久。

这正好击中我过去半年的真实痛点——伯德图不能给、公式图片不能给、实验截图不能给，什么都得自己转成文字描述。经历过数模的幻觉事件以后，我不会把泄露截图当事实，只是默默把那条帖子收藏了。

整个暑假就在这种背景噪声里过去了。

播放器文件夹很久没有再打开；GenChat Pro 每个月自动扣款；Twitter 收藏夹里的 AI 产品越来越多；有些七月份还很火的工具，八月底已经没人讨论。

新产品、新模型、新功能不断顶掉旧热点。

八月底，我拖着行李箱重新回到长安校区。宿舍、东大镇、终南山，一切都跟走的时候一样。

但校园里的 AI 氛围已经完全不同了。

去年我给室友展示 GenChat，大家像看魔术。现在同学之间已经非常自然地说："让 GenChat 帮我改一下。""这个英文丢给 AI 看看。""报告先让它润一遍。"

知道 AI 已经不再构成任何领先。

我真正的优势开始从"我知道这个东西"变成"我比大部分人更知道怎么用这个东西"。

返校后的某个晚上，我坐回熟悉的宿舍书桌。

Twitter 的时间线突然被 OpenMind 刷屏。

这一次不是所谓内部爆料。OpenMind 正式公布了 Genesis-4，或者说宣布了极近的发布日期。

页面上写得很清楚：GenChat Pro 用户优先获得访问资格。

我看了一眼自己免费账户旁边那个灰扑扑的"升级 Pro"按钮，再把视线移到发布页上。

Vision 两个字就在最醒目的位置。

我点进订阅页面。

页面最醒目的几个词里，有一个：

Vision。

## 24

Genesis-4 上线那天，我没有像去年看 GenChat 发布时那样激动得一晚上没睡。

我做的第一件事，是把一张控制理论课件里的伯德图直接拖进了对话框。

过去要自己转述幅值曲线在哪里穿过 0 dB、相位曲线怎么变化，现在模型能直接读图，还能指出增益裕度和相位裕度。

当然也不是全对。图上小字标注的一个交叉频率数值它看错了，还把某条渐近线的位置搞反了一次。我把那行圈出来，让它重新看，它改了过来。

我没有再经历一次"大彻大悟"。只是很自然地接受了一个事实：原来以后很多东西不用先翻译成文字了。

Genesis-4 主要向 Pro 用户开放，旗舰模型有使用额度，所以我不会什么问题都拿 4 来问。普通概念解释还是用 3.7，只有真正复杂的推导、代码调试或者需要看图的时候，才切到 4。

几周之后，Sapient 推出了 Sage-2 系列。

三档名字我记得很清楚：Axiom、Thesis、Canon。但我不会特意去研究它们的参数对比，直接按习惯用就行。简单的摘要和改写直接 Axiom，快；课程材料和论文基本用 Thesis，够用又不浪费；真碰上几十页材料、复杂逻辑核查，才舍得切 Canon。

真正让我觉得"换代了"的不是三档本身，而是：我第一次可以把比较大的一批材料交给同一个模型处理，而不需要像以前那样切成很多碎片，一段一段喂进去。

时间很快滑进十月、十一月。

Twitter 时间线上不断冒出新东西：PDF 阅读器、AI 搜索、网页总结、翻译工具、PPT 辅助、笔记整理、各种浏览器扩展。有人每天喊"神器"，也有人嘲笑"又一个 Genesis wrapper"。

我已经不会每个都注册。慢慢形成了一个很朴素的筛选标准：它到底替我少做了哪一步？

校园里的氛围也变了。

大三上学期中段，同学已经不会围观"AI 会写代码吗"。更常见的是："这个报告你用哪个模型？""这篇英文论文丢 Sage 里了吗？""Genesis-4 今天额度又用完了。"

甚至有人开始讨论会员值不值。

去年那种"只有我知道这东西能干什么"的领先感，早就没了。大家都会用。但使用深度开始拉开差距——有人只拿来润色句子，有人已经开始拆任务、切模型、交叉验证。我不需要说自己有多厉害，只是看他们提问的方式，就知道深浅。

十二月，Helix 终于发布了 Hermes-2。

它不像早期 Hermes 那么容易凭空给出一个答案，而是更习惯先检索，再把来源和时间一起列出来。至少我终于能顺着它给出的来源往回核。

至此三家的差异彻底稳定下来：Genesis 是通用大脑，Sage 是阅读和理解工具，Hermes 是现实信息接口。

年底的时候，我桌面上经常同时开着五六个窗口：GenChat、Sage、Hermes、一个 PDF 阅读工具、浏览器扩展、课程资料。

但我已经不会觉得自己在"玩 AI"了。就像以前打开浏览器、Matlab、Word 一样自然。模型迭代的新闻仍然会看，但不会每次更新都兴奋一晚上。

AI 从事件变成了基础设施。

寒假也没什么特别的。回家睡了几天，偶尔翻翻下学期的课表，跟 Aaron 在 Relay 上聊了几次新模型的使用体验。

三月返校，模型又已经换了一轮。

OpenMind 推出 Genesis-4.5，推理、代码、图像和文件处理整体更稳；Sage-2.5 把长上下文进一步扩大，开始能处理整门课程的大量资料、多篇论文和笔记，而不仅是"一章教材"；Hermes-2.5 则把搜索、多模态和长上下文更紧地结合起来。

我没有逐一实测这些更新。只是有一天翻到去年的笔记，突然意识到：去年这个时候，自己还在三个浏览器标签页之间手动搬运几段文字。一年不到，现在随便一个主流旗舰都已经能看图、读文件、吃掉大段材料。

技术迭代的速度，已经快到我不可能再把每一次更新都认真试一遍。

顺手翻了翻去年夏天收藏过的那些"AI 神器"。有的已经停止维护，有的收费以后无人问津，有的功能被 GenChat 官方直接做进去了，还有的产品连网站都打不开了。

不是所有东西都一路向上。很多创业产品只是短暂存在几个月。

四月初，大三下学期的课表贴到了教务系统上。控制理论的后续课、信号处理的进阶课、还有一门编程相关的选修课。

我坐在宿舍书桌前，看着屏幕上一排已经开了半年的 AI 窗口。模型已经足够强了，强到去年想都不敢想。

但我本人并没有因为模型更新就自动获得什么人生结果。

课照样要上，作业照样要交，未来照样不知道往哪走。

工具已经摆在这里了。接下来真正的问题，不再是"AI 还能不能更强"。

而是：我准备用这些东西做什么。

## 25

四月，大三下学期的课表贴出来了。其中有一门航海学院全体学生都要修的大课，声呐设计与仿真，四月份布置了一次分量很重的综合作业——报告、仿真结果和代码，缺一不可。

题目本身不算难，重点是工作量大、细节多。大多数人的目标只是"做完、能跑、报告写齐"。

我也没想搞什么大新闻。只是做的时候，过去一年的使用习惯已经自然长出来了：Hermes 查资料和参数范围，Genesis 帮我搭代码框架和改 bug，Sage 帮我梳理报告逻辑，我自己负责运行、核对、改参数、检查结果。

中间当然也出错。Genesis 在一个函数调用里把两个参数的位置写反了，我跑了两次结果不对，自己先怀疑公式，最后顺着输入检查才找到那一行；Sage 在解释一个边界条件时前提就不对，我翻了教材才反应过来。但这些都不再构成什么剧情危机——检查出来，改过来，继续往下走就是。

交上去的成果，我自己知道比平均水平完整。不是理论高到碾压，而是整体质量在线：仿真图规范，不同参数有对照，代码结构清楚，结果和文字对应得上，报告读起来顺。

过了两周，老师在课堂上讲共性问题。

"孙博这个参数对照做得比较完整。"他随手点了一下我的名字，"这组仿真结果可以参考一下这种呈现方式。"

教室里有几个人回头看我。

然后老师现场问了我一个具体问题："你这个参数为什么这样设？为什么增加这组对照？"

我站起来，正常回答。因为确实理解自己做的东西——为什么选这个范围，为什么要排除那个极端值，某个异常结果是怎么处理的。老师点了点头，没再说什么。

关于 AI，我不主动说。

不是作弊。只是 2024 年校园里对生成式 AI 的态度仍然暧昧。很多人会天然把"用了 AI"理解成偷懒、代写，或者"这还算你自己做的吗"。老师没问，我也没必要举手解释"其实代码很多是 Genesis 帮我写的"。

这件事在同届学生里传了一下。毕竟是全院大课，老师公开点过名，有些人开始记住"孙博"这个人。

下课后陆续有人来问。"你那个图怎么画的？""参数扫描怎么写的？""代码能不能给我参考一下？"都是普通同学层面的交流，没围一群人。

有人知道我平时经常用 AI，半开玩笑问："你这不会全是 GenChat 写的吧？"

我没撒谎，很自然地说："用了啊，代码、查资料都用了不少。最后还是得自己跑和改。"

这句话反而让一部分同学第一次意识到：我和他们的差别，并不是"我偷偷拥有某个更强模型"。大家能用的东西其实差不多，但我明显更知道怎么让模型干活，也更知道怎么检查模型。

我自己也第一次比较明显地感受到一种错位。

老师看到的是"这个学生代码和仿真做得不错"，同学看到的是"这人挺会搞这些东西"。但我知道，真正拉开差距的很大一部分来自自己过去一年积累的那套东西——模型怎么选，任务怎么拆，哪些地方必须自己看，哪些地方可以信。

别人只看到了最后的报告、图和代码，看不到背后那些来回切换、反复核对的过程。

接下来几天，偶尔有人私聊问课程相关问题。我会帮，但没变成免费答疑机器人——简单问题说两句，复杂的就让对方先自己试。

"孙博挺会做仿真""孙博代码搞得不错""他特别会用 AI"，这几个标签开始在一个很小的范围里混在一起传播。

不是什么学院大神，只是第一次形成了可传播的口碑。

然后口碑第一次跨出了同届同学圈。

某天晚上，我收到一个陌生微信好友申请。验证消息很简单：

"你好，我是学院研一的，XX把你推给我的。听说你仿真和数据处理做得挺好，想请你帮我看个东西。"

我点进对方头像，看了两秒，通过了好友。

## 26

学长姓周，研一，做水声实验的。寒暄了两句，他直接说明来意。

他最近在处理一批实验数据，前面已经采回来不少文件，也有一套师兄留下来的脚本。但现在的问题是：数据文件太多，命名不统一，原脚本很乱，有些参数直接写死在代码里，不同批次的配置似乎还有差异。他自己改了几次，越改越乱。

"能不能帮忙把这些数据批量跑出来，主要结果画成图，脚本稍微整理一下？"他补了一句，"后天组会前最好能弄出来。"

这是我第一次遇到一个真正由别人给出的截止时间。

但一开始我并不紧张。课程作业刚被老师点过名，手里又是 Genesis-4.5、Sage-2.5、Hermes-2.5 这些比一年前强得多的模型。这不就是改代码、批处理、画图吗？应该能做。

学长把整个文件夹发了过来。

打开以后，我才发现这和课程作业完全不是一回事。

有些文件叫 test_01，有些叫日期，有些叫实验编号；某几批数据采样率不同；同一个参数在不同脚本里取值不一样；注释已经和实际代码对不上；一些变量名字含义模糊，连学长自己都记不清某几批数据当时是怎么采的。

真实任务最麻烦的地方，往往不是"不会写代码"，而是问题本身就没有整理好。

我开始让模型帮忙。

Genesis 阅读旧代码、帮我重构批处理逻辑、把写死的参数整理出来、改报错；Sage 帮我梳理数据处理流程，检查各步骤之间是否自洽；Hermes 查某些函数和技术细节。模型处理代码的能力明显比去年强很多。

但很快遇到一个 AI 无法解决的问题：这组数据当时到底采用了什么采样配置？

模型不知道，因为文件里没有。我问学长，他说："这个我得问一下当时跟我一起做实验的人。"

模型可以理解已有信息，但不能凭空恢复现实世界里根本没有被记录下来的事实。

几个小时以后，批处理流程终于跑起来了。几十个文件开始自动处理，图一张张生成。曲线漂亮，趋势合理，模型检查代码也没发现明显问题。

我开始松下来。比自己最开始想象得麻烦，但总算搞定了。

第二天再看结果时，我发现一个小异常。

某一批实验数据里，目标峰值的位置和其他批次明显偏了一截。但整条曲线又非常平滑，没有报错，没有 NaN，没有明显异常。Genesis 看代码认为流程可以正常运行，Sage 检查处理步骤也没立刻发现致命问题。

如果只看图，结果甚至"很好看"。

但我心里觉得：这东西不太对。

我开始从输出往输入倒查。查公式，查代码，查原始数据，查文件头。

最终发现：某一批实验数据的采样率和其他批次不一样。大部分数据是一个采样率，那几组采用了另一个。但旧脚本把所有文件默认按照同一个采样率处理。因此时间轴、频率轴和目标位置换算全部产生偏差。

最危险的是：程序没有报错，图也非常漂亮，只是结论是错的。

我看着已经生成的结果目录。之前那一大批图必须重新处理。

这时学长发来微信："怎么样了？我明天下午组会要用。"

截止时间突然真正有了重量。以前的作业搞砸，主要影响我自己。现在有人已经默认我能把东西交出来。

我开始重新整理。Genesis 帮我改数据读取和批处理代码，Sage 帮我重新检查整个处理链，避免只修一个地方又漏掉其他换算，Hermes 查数据格式，我自己盯着原始数据和输出结果。

仍然是我人工中继。我负责决定什么交给谁，哪个结果值得怀疑，什么必须回到原始数据确认，什么信息要去问学长。

时间推进到凌晨两三点。真正的压力感不是什么燃文，只是：这东西明天真的有人要用。

重新处理以后，大部分数据恢复正常。但仍然有两组数据，因为缺少关键实验记录，参数始终无法确认。

我没有猜。

给学长发消息："这两组数据我暂时不建议放进去，实验参数对不上，我没法确定按照哪个配置处理。最好问一下当时做实验的人，确认以后再跑。我现在硬算的话图也能出来，但我不敢保证是对的。"

第二天下午，学长把结果拿去组会了。我照常上课。

晚上学长发消息过来。

"过了。"

然后又补了一句："老师没说图的问题，反而问这套批处理以后能不能直接继续用。"

这一句比"老师夸你厉害"更有效。它意味着我做出来的东西真的进入了别人的实际工作流程。

学长感谢我，说他自己弄这套东西估计两三天都不一定搞完。然后主动转了一笔钱过来。

五百块。

我第一反应是拒绝："不用吧，我其实也是拿 AI 帮着弄的。"

他回得很简单："我管你怎么弄的，东西最后能用就行。模型我也有啊，我又搞不出来。"

这句话让我愣了一下。

我最后收下了钱。

没有立刻产生接单、创业、算月收入的念头。只是第一次意识到：别人愿意付钱的并不是我敲了多少行代码，哪段代码是不是 Genesis 写的。对方真正愿意付钱的是：我把一个麻烦的问题交给你，你最后给我一个能用的结果。

晚上回到宿舍，我看了一眼那笔五百块的转账。

过去一年多，我一直在给各种 AI 会员付钱。这是第一次，AI 放大后的能力反过来给我带回了一笔钱。

第二天照常上课。只是从这一天以后，"会用 AI"第一次不再只是我自己的感觉。

它开始在现实世界里产生了价格。

## 27

过了一两周，周学长又来找我。

不是新订单，也不是要我做新东西。只是那套声呐数据批处理脚本还在继续用，他们后来又采了一批实验数据。这次真正麻烦的不是数据处理，而是每批实验旁边都有很多实验记录：日期、工况、采样率、设备配置、文件编号、备注。

这些记录格式非常不统一。有的是 txt，有的是从 Word 里复制出来的文字，有的甚至就是一段非常随意的自然语言。周学长现在每次都要人工翻这些记录，再把关键信息整理进表格。

"能不能帮我把这些也整理一下？"

这个问题对我来说已经非常自然。把实验说明丢给模型："提取日期、采样率、工况、设备编号和备注。"模型很快就能整理出来。

但当我实际帮他处理几十份记录时，很快意识到一个问题：

如果每一份都要打开文件、复制文字、打开 GenChat、粘贴、提问、复制结果、再写进 Excel，那就非常低效。模型本身能做这件事，麻烦的是人一直在中间搬东西。

我第一次自然想到：能不能让程序自己去问模型？

我打开 OpenMind 的开发者页面。这时才第一次认真确认：GenChat Pro 和 API 是两套收费体系。我每个月已经在交 Pro 会员费，但如果程序调用 Genesis API，仍然需要单独充值，按 token 计费。

以前我只是"用模型"。现在第一次开始考虑：如果我要批量跑几十份、上百份记录，一共要多少钱？

就在这段时间，开发者社区开始频繁讨论一家中国创业公司：近界科技。他们刚刚公开了第一代模型 Nexa-1。

我在 Twitter、GitHub、开发者论坛上反复看到："Nexa-1 开源了。""API 价格有点离谱。""中文挺好。""代码能力比想象中强。"

最先吸引我的不是 benchmark。而是价格。

"这么便宜？"

我没有因为它是国产模型就直接采用。拿几份真实实验记录做了对比测试。同一段输入分别给 Genesis-4.5 和 Nexa-1，要求提取固定字段：date、sampling_rate、condition、device、file_id、note。

结果很合理：Genesis 对复杂、模糊的记录理解更稳；Nexa 偶尔会误解某些上下文。但对于这种中文实验记录的信息抽取任务，Nexa 已经完全够用，而且成本低很多。

我第一次非常明确地做出一种不同于"谁最强就用谁"的选择：这个任务没必要用 Genesis。

然后我直接问 Genesis："Python 怎么批量调用 Nexa API？"

按照模型给的示例，我注册 API、获取 key、安装 SDK、写第一段调用代码、发出第一个请求。

第一次成功返回结果时，有一点小的新鲜感。过去一直是自己打开网页问模型，现在变成自己的 Python 程序在问模型。但对 2024 年的开发者来说这只是普通技术，重要的是对我个人而言，这是第一次跨过这道门槛。

第一版程序很快跑起来。读取目录里的实验记录，逐个发给 Nexa，要求返回 JSON，最后整理成 CSV。

然后问题立刻出现。

有时候 Nexa 会在 JSON 前面说一句"当然可以，以下是结果："，导致程序解析失败；有时日期写成 2024-05-12，有时写成 2024/5/12；有时模型看到"采样率未记录"，却根据上下文猜一个可能值；API 超时以后程序直接停掉。

几十份记录里总会冒出各种奇怪情况。

我开始一点一点给模型调用加约束。

输出必须只包含 JSON；字段名称固定；缺失信息必须返回 null；禁止根据上下文猜测缺失值；JSON 解析失败自动重试；API 超时后重试；连续失败的文件单独记录；保存原始模型输出方便追查；最终结果人工抽查。

不是什么前沿框架。想法非常朴素：既然要让程序自己跑，就不能让模型想怎么答就怎么答。聊天时答错一句我能看出来，程序批量跑的时候，它答歪了我可能根本不知道。

Nexa 也不是完美的。有些记录一次就抽取正确，有些模糊表达仍然会理解错。有一次它很自信地补出了原文没有的信息，我发现后把规则进一步收紧：不知道就是不知道。

经过反复修改，程序终于达到一个可用状态。一百份左右的实验记录中，大部分可以自动完成初步整理，十几份被标记为需要人工检查，少数信息缺失严重的文件直接留空。

原本需要人一份一份翻、复制、填表的工作，现在变成：先让程序批量跑，然后人只检查异常项和关键字段。

周学长看到脚本以后问："所以以后新实验记录直接丢进这个文件夹，它就能先帮我整理？"

"差不多。"我补了一句，"最后还是得看一遍。"

这句话要保留。因为它代表我现在的基本态度：自动化可以扩大效率，但不能取消人的终审。

以前我使用 AI 的基本单位是一次对话。遇到一个问题，打开模型，问，得到答案。

这一次开始不一样。我第一次让模型成为自己程序中的一个步骤。不是自己每次亲自问，而是输入来了，程序调用模型，模型返回结果，程序继续处理。

AI 开始从"聊天对象"变成"工具链里的一个组件"。

这一节结束时，Nexa 在我工具链中的位置也很务实：复杂任务还是 Genesis 更稳，长材料还是 Sage，实时搜索还是 Hermes。但这种中文文本抽取、简单代码、批量低成本任务，Nexa 很合适。

不是因为"国产"，而是因为够用，而且便宜。

晚上，我关闭聊天网页。终端里那段脚本还在一份一份处理剩下的实验记录。屏幕不断出现：

success
success
review_required
success

我第一次不需要亲手把每一个问题复制进聊天框。

过去一年多，我一直在学习怎么更好地"问 AI"。

现在第一次，我开始考虑怎么让 AI 自己进入一个流程。
