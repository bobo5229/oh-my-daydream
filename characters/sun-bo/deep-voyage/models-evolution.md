# 《深潜航道》架空大模型演进路线图

本文档梳理从故事开篇（2022 年 11 月底）至 2024 年底期间，全球架空大语言模型的技术演进脉络、三大核心阵营发展路线，以及在主角孙博学习工作流中的生态定位与实战表现。

---

## 一、三大阵营全局格局概览

| 阵营 / 实验室     | 底层哲学 / 核心风格                     | 主打模型序列                                                                                     | 代表特征                                 | 孙博心中的生态位                            |
| :----------- | :------------------------------ | :----------------------------------------------------------------------------------------- | :----------------------------------- | :---------------------------------- |
| **OpenMind** | 探索式先驱、奔放、代码与通用任务强               | Genesis-3 (160B) → **GenChat** (2022.11) → **Genesis-3.7** (2023.04) → *Genesis-4 (传闻热议中)* | 对话极其自然、代码补全与框架搭建极快，但容易自信胡说、出现边界与常数幻觉 | **“基准原点与丈量尺”**：速度快、出框架、搭原型、代码首选     |

## 三、各模型技术特性与实战边界总结

### 1. OpenMind 序列：Genesis-3 / GenChat / Genesis-3.7
- **擅长领域**：
  - 代码框架生成、算法原型实现、语法报错快速定位；
  - 角色扮演、非正式语境与上下文语义接续；
  - 任务拆解与发散性方案提供。
- **实战翻车点 / 局限**：
  - **边界陷阱**：数组初值误赋、除零未校验、极值点跳步；
  - **假定常数幻觉**：信号滤波设计中随手将指标写死为经验参数（如将 50 dB 的 $\beta=5.0$ 强套给 40 dB 需求）；
  - 遇到需要严格定理证明的数学问题容易输出空洞的哲学辩证法。

### 2. Sapient 序列：Sage / Sage-1.3
- **擅长领域**：
  - 知识体系结构化归纳（快速梳理课程大纲与公式树状关联）；
  - 逻辑一致性校验、对抗性质询推演；
  - 复杂物理概念的多层次降维解释（如将拉氏变换阻尼比层层退化为高中简谐振动）。
- **实战翻车点 / 局限**：
  - **概念强行杂交（幻觉新形态）**：把名称相似但属于不同体系的概念强行拼凑推导（如在自动控制“奈奎斯特稳定判据”下擅自嫁接信号系统的“奈奎斯特-香农采样定理推论”）；
  - 缺乏多模态图形能力，对电路原理图、几何曲线无法直接感知。

### 3. Helix 序列：Hermes-1 / Hermes-1.2
- **擅长领域**：
  - 经典教材出处、定理原始出处溯源（如流体力学经典文献、奥本海姆教材原书参数）；
  - 生僻专业术语的背景考据与发音/释义体系；
  - 多档分级调用（Epigram 用于轻量速查，Epic 用于深度文献检索）。
- **实战翻车点 / 局限**：
  - **文献凭空捏造**：早期极为严重的引用幻觉，生成看似无比真实的学者姓名、期刊期号与 DOI 链接（直接引发数模灾难）；
  - 需要配合极严苛的“反向要求官方数据库真实链接/ISBN”的防御性 Prompt 才能压制幻觉。

## 四、主角孙博的方法论演进

从 2022 年底的“好玩段子/OJ 作业神器”，到 2023 年中的“学习生活默认基础设施”，孙博的使用体系经历了四个阶段：

1. **单点盲从期（2022.11 - 2022.12）**：单模型使用，被偶尔的 Accepted 惊艳，随后撞上低级边界 Bug。
2. **多模型盲目流水线期（2023.01 - 2023.03）**：自创多模型接力，却因模型间“串通伪造证据”在数模比赛中彻底崩盘。
3. **批判审校与工程规范期（2023.04）**：引入海外社群经验，建立五大防失控准则，以物理事实与代码编译为唯一判据。
4. **无声基础设施期（2023.05 - 2023.06）**：剥离噱头与躁动，作为无限耐心助教融入硬核工科日常；清楚认识到当前 2023 年模型尚无多模态视觉的客观边界，把控人类的终审权。
5. **多模态直接交付期（2023.09 - 2024.03）**：视觉能力出现后，孙博开始把现实中的课件、图表、截图直接交给 AI，不再需要手动文字描述；长上下文爆发后，他开始把整门课程讲义、多个文档作为知识环境整体交给模型，让 AI 理解背景再回答问题。
6. **复杂思考伙伴期（2024.09 起）**：推理型模型出现后，AI 不再只是解释、整理和辅助，开始在部分复杂数学、代码、科学和规划任务中成为真正的"思考伙伴"。孙博感受到时代变化，但仍清楚 AI 不会直接把他变成各领域专家。

## 五、2024 年底全球 AI 格局状态

截至 2024 年底，大模型已经从网页聊天机器人发展成：
**能够理解图像、大量文件、搜索互联网、调用部分工具并进行较复杂推理的通用 AI 助手。**

但仍没有全面进入成熟 Agent 时代：
- 尚未出现成熟的 CLI Agent 类工具
- 不能自己接管完整代码仓库、自动完成完整软件项目
- 不能长时间无人监督执行复杂现实任务
- 不能稳定自主浏览网页完成多阶段工作

这些能力留给 2025 年的 Agent / Coding Agent 阶段。

## 七、贯穿全书的技术事实

**模型越来越强，但幻觉不会因此从故事中消失。**

模型能力越强，幻觉可能越不明显、越难察觉：
- 早期（2023 上半年）：明显的"编论文、编数据"，容易识别
- 中期（2023 下半年—2024 上半年）：错误引用、错误工具调用，需要仔细核查
- 后期（2024 下半年）：引用真实材料却得出错误结论，更隐蔽

因此孙博的判断能力、人类终审和真实世界验证始终有价值。
